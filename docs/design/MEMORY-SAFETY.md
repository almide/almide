# Memory Safety — What Is Proven, What Is Trusted

The measurements page ([docs/benchmarks/README.md](../benchmarks/README.md)) carries the
one-paragraph form of this account; this page is the full one. The audited-theorem count
it refers to is computed and asserted by `proofs/check.sh` (against
`proofs/TRUSTED_BASE.md`, `proofs/receipt.sh`, and the measurements page), so it is
quoted there rather than repeated here.

You write no ownership annotations, no lifetimes, no `free` — memory management is decided by [Perceus](https://www.microsoft.com/en-us/research/publication/perceus-garbage-free-reference-counting-with-reuse/)-style ownership inference in the compiler: garbage-collector-free, pause-free. The inference computes where every heap value is introduced, duplicated, and consumed; what differs per target is only the *execution mechanism* for those decisions. A compiler that ships proofs owes you the boundary, so here it is:

**What "memory safe" means.** One definition, kernel-checked: [`proofs/MemorySafe.v`](../../proofs/MemorySafe.v) (#4013). Over a heap trace (each allocation, store, load, reference increment and decrement, naming its block), `MemorySafe` is four clauses: every load and store lies inside its live block (spatial), nothing touches a freed block and no allocation hands out a live one (temporal), every byte read was written since allocation (initialization), and every access uses the representation the block was allocated with (type). A trace checker is proven sound and complete for it. The proofs below reach the **temporal** clause (`rc_check_gives_temporal`) and, for the bounds certificate the structural wasm leg emits per build over every `xs[i]` / `b[i]` access (#3345 may elide a check; the certificate re-derives it), the **spatial** clause ([`proofs/SpatialCert.v`](../../proofs/SpatialCert.v), `accepts_spatial`; that the certificate's events are the bytes' accesses is trusted); at the source level, a typed core of Almide is proven to run MemorySafe on all four clauses ([`proofs/CoreSafe.v`](../../proofs/CoreSafe.v), `typed_core_memory_safe`, #4014 — a core, not yet tied to the lowering); the two per-build certificates composed on one trace give its spatial, temporal and type clauses, and all four given the constructor discipline as a stated hypothesis ([`proofs/Certified.v`](../../proofs/Certified.v), `certified_with_bounds_cert`, `certified_memory_safe`); no build emits a trace yet, so the theorem this definition is for — the per-build checker accepting an artifact implies the artifact is `MemorySafe` — is open: #4005 (spatial over MIR), #4006 (native), #1696 (the structural wasm leg). The plan and every remaining gap: #4011.

- **The kernel-proven checker — proven, over the witnessed MIR.** The ownership certificate a **kernel-proven checker re-verifies** (Rocq/Coq spine, axiom-clean and independently re-checked by `coqchk`) establishes that the witnessed MIR is RC-balanced — no double-free, no leak in the modeled fragment — name-total, and capability-bounded. Those MIR witnesses are now judged only by `proofs/gate.sh` and `proofs/corpus-wall.sh`: since #2761 no wasm byte comes from MIR lowering, so `almide verify app.almd` judges the structural leg's certificate instead (#4011, below). The WasmEncode/WasmExec/WasmRcDec theorems likewise stand about a *modeled* runtime (the retired incumbent's). The proof is about IR-level Inc/Dec balance, not about the compiler's internals; a certified function can still compute the wrong value, which is what the separate [cross-target contract ledger](../contracts/README.md) and differential gates exist to catch. The exact boundary — which pipeline stages are proven, which are trusted, and what each gate does and does not claim — is the map in **[proven-vs-trusted.md](../contracts/proven-vs-trusted.md)**.
- **WebAssembly, structural leg — checked per build on the certified corpus, recording trusted.** The only wasm renderer (the default since #1599, the sole leg since #2752/#2761 — see [docs/wasm/](../wasm/README.md)) records its certificate AT EMISSION TIME (#1696, closed): an ownership witness per frame, the call modes, name totality and capabilities over the shipped stock-WASI bytes, and the `bounds` witness of every index-operator access (#4005). `proofs/structural-wall.sh` builds every fixture in `crates/almide-wasm/tests/golden/witness-fixtures.txt` (954 of 954 certified) through the product route, pins the shipped file's SHA-256 in the bundle, and has the extracted checker, the Rocq kernel and almide-verify agree on every witness. What stays trusted is that the recorded events are the instructions the bytes contain. Its other evidence is differential (byte-identical to native on the `wasm_cross` corpus) and dynamic (the checked allocator, nightly); its runtime's RC and allocator bytes are checked against the Coq decoder model `StructuralDecode.v` by `proofs/check-structural-bytes.sh`.
- **Native (Rust) — trusted, not proven.** The same decisions are realized by Rust's own ownership machinery: the compiler emits ownership-idiomatic Rust, and every heap value is freed by Rust's scope-end drops. No proof covers this leg today; its evidence is differential (byte-identical output against the wasm leg, on the contract corpus). Sharing one certified Perceus MIR across both renderers is the [native trust-spine ladder](../roadmap/active/native-trust-spine.md) ([#764](https://github.com/almide/almide/issues/764)); shared scalar and list ops already render on both targets from the same MIR.

## The gap table (2026-10-24, #4011)

One row per clause of `MemorySafe` ([`proofs/MemorySafe.v:165`](../../proofs/MemorySafe.v); the clauses are `spatial_ev` :126, `temporal_ev` :132, `init_ev` :141, `type_ev` :147). Each cell says what is **proven** (a kernel-checked, axiom-clean theorem), what is **checked per build** (a gate that judges each build's artifact or certificate, and how), and what is **trusted** (nothing checks it). "Per build" on the structural leg means the CI build of the certified corpus (`proofs/structural-wall.sh`, trust-spine workflow); `almide build` itself does not run a checker; `almide verify app.almd` builds the program by the same route, writes the same bundle (`crates/almide-wasm/src/witness_bundle.rs`), pins it to the built `app.wasm` by SHA-256 when the file is present, and has `almide-verify` judge it (#4011).

The incumbent v1 wasm leg is gone (#2761); its column is not kept. The native leg's verified renderer (`crates/almide-mir/src/pipeline_native_rungs.rs:321`) is the default with a v0 fallback on a wall (`src/cli/build.rs:289`) and renders 106 of the 958 `spec/wasm_cross` programs (`proofs/native-verified-floor.txt:4`).

The theorem the definition is for, `K(c, a) accepts ⟹ MemorySafe a` for a shipped artifact `a`, needs three more things, in this order: construction-site records for every allocation site, not only list literals (INITIALIZATION and TYPE across the whole trace, #4013 — the checker and its theorem exist); certificates for the heap accesses outside the index operator (#4005); and a translation check that the recorded events are the instructions in the bytes — the one trusted cell every column shares (#1696's recording discipline on wasm, #4006 on native).


Where Rust gives you *zero-cost* abstraction (paid for in ownership annotations), Almide gives you **zero-annotation** abstraction: you write none, and the frees are decided by the compiler and the checker that re-verifies them is proven (its per-build use on shipped wasm bytes is pending the structural leg's certificate).

The design that started this is the Lean 4 **Perceus belt** ([`crates/almide-perceus-belt/`](../../crates/almide-perceus-belt/), 41 theorems as of 2026-08-27, 0 sorry, CI-gated): a model of the ownership pass over a small IR fragment, proving among else that the transform emits a release for every allocation it sees (`allHeapFreed` — at least one `Dec` per heap binding in the modeled fragment; the stronger exact-balance predicate is what the per-build certificate checks on real programs). It is a proof about the *design*, mechanically checked; the per-build certificate above is what covered the *shipping artifact* while the incumbent leg shipped (retired by #2761).
