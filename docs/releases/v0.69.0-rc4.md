# v0.69.0-rc4 — the default native build renders through the certified path, and wasm fixes a use-after-free

**Release candidate 4** (#1484): published as a prerelease for the soak window and excluded from "latest". It follows [v0.69.0-rc3](./v0.69.0-rc3.md). Everything below landed after rc3. It adds no dialect-epoch entry and no new contract; the [v0.69.0-rc1](./v0.69.0-rc1.md) notes still describe the epoch-14 and epoch-15 surface, and the [v0.69.0-rc3](./v0.69.0-rc3.md) notes the C export ABI. The final v0.69.0 is tagged once the soak is clean.

## Behaviour changes

- **The default native build renders certified Rust for the programs on the certified floor** (#4464, #4006 C1, #4349). For each such program the compiler lowers to MIR, writes an ownership certificate per function, a call-binding certificate per program and a bounds certificate for every element access, then renders Rust. The native wall gate checks every certificate, and three independent checkers agree on each ownership and call-binding certificate. The floor is 479 of the 1,017 `spec/wasm_cross` programs, about 47% (#4479, #4484, #4487: new slot kinds, class P write-back moves, empty-list kind typing, and native fs host calls under one trusted row). A discovered region window runs in the arena on this render too, with the arena mark as a certificate object (#4483). Every other program falls back to the standard, uncertified render, as before. Output is the same either way.
  - A heap parameter that the body takes over is now passed by move, and the call-binding certificate records it.
  - The #4349 false reject is fixed, so 17 Result-heavy programs no longer fall back for that reason.
- **Native release binaries carry no debug info** (#2092). A program that uses the runtime used to ship about 1.6 MB of DWARF, so a 400 KB binary weighed 2 MB. The symbol table stays, so backtraces still name their frames. Code and data sections are byte-identical.
- **`almide.lock` is written atomically, and only when it changes** (#4472). A lock with the same content is left alone, and a read-only lock stays read-only.

## Security

- **wasm: a call argument that reassigns a module-level `var` no longer frees memory the call still reads** (#4476, #4478, C-258, C-132). In `xs.contains(reset())`, where `reset()` rebinds the global `xs`, wasm read the freed block, gave wrong answers or trapped. The operand order now counts the writes made inside called fns, and a `mut` place argument is written after the other operands, as on native. The interpreter oracle now agrees with both.

## Correctness

- **A locked git dependency can no longer be re-resolved at its branch head by a parallel `almide test` thread** (#4472). A thread could read the lock while another rewrote it, see it empty, and resolve the dependency at the branch head.
- **A certified native program with a long straight-line `main` no longer crashes the Rust backend** (#4464). The certified program and runtime crates build without debug info.
- **The certified native render covers a few more shapes** (#4464): a Unit lambda in an arity's closure table, the SIGPIPE prelude in `main`, and `string.drop_end`.

## Performance

- **wasm `list.push` on a record field grows the list in place** (#4475, #4477, C-033). Each push used to copy the whole list, so a push loop over a field was quadratic on wasm. Pushes into a global's field, `string.push` and `b.xs = b.xs + [v]` on a global's field also grow in place now.
- **Native fib(35) runs in 2.2 ms, down from 27 ms** (#4456). A small pure scalar recursion is inlined into itself once, so the backend can merge repeated calls. Evaluation order, wrapping and Float rounding are unchanged, and recursion depth only shrinks (C-170, C-196). wasm keeps the accumulator loop.
- **Comparisons that only steer a branch render as a Rust `bool` on the certified native render** (#4481). `recursion_depth_within_limits` went from 1.31x to 0.81x of the standard render, and `base64_encode` from 1.04x to 0.98x.
- **`almide check` and wasm builds load only the stdlib functions a program reaches** (#4328, #4461). Check time for a JSON round-trip program fell from 160 ms to 61 ms.
- **Building that program to wasm takes 84 ms, down from 223 ms** (#4458, #4470). The wasm link loads only what its demands reach, the bundled stdlib is parsed only once a module is reached, and fib builds in 7 ms instead of 35. Native default builds got slightly faster too.
- **Every wasm module that links `string.to_upper` or `to_lower` is about half its size** (#4198, #4463). The Unicode case tables are stored as runs, so a case-mapping program ships at 13,454 B instead of 27,640 B. The mapping data is unchanged.

- **`almide build --release` builds fib in 0.8 s, down from 2.2 s** (#4459, #4489). std's panic backtrace printer is linked precompiled, once per toolchain, instead of being re-optimized in every fat-LTO link. The binaries run the same instructions. The build falls back to the plain fat-LTO profile on a non-Linux host, on a cross build, without the `llvm-tools` component, when either printer function is missing from std's bitcode, when any step or the toolchain probe fails, and for a program with its own `#[global_allocator]`. `ALMIDE_RELEASE_STD_UNSPLIT=1` forces the plain profile.
- **The certified native render fuses list pipelines** (#4006). A `list.map` that feeds another list HOF runs inside that HOF's loop with no intermediate list, `list.range(a, b)` is iterated without being built, and counted loops render as Rust iterators. `range |> map |> fold` went from 3.0x to 0.98x the standard render's instructions, and a record built by `list.map` from 28x to 0.91x.
- **A generated native crate compiles in one non-incremental pass** (#4006). Outside CI, an incremental session ran a certified `map` 1.6x slower.

## Tooling

- **`--host js` serves files, arguments and environment variables from `init()`** (#4438, #4444). A page passes in-memory preopens, `args` and `env`, and reads written files back with `files()`. A preopen is read-only unless marked `writable`, a path that leaves it is refused, and the errno values match stock wasmtime. A module that imports no fs op gets the same glue as before.
- **The cross-target fuzzer gives a stock wasmtime run the grants its component imports** (#4471, #4474). An http or sockets component built since rc3 was refused at load and reported as a divergence. It now gets `-S http` or `-S inherit-network`, as `almide build` prints.

## Gates and evidence

- **The witness floor counts distinct witnessed functions, read from a whole-module leg** (#4466, #4480). It used to count fixture-and-function pairs, so pruning unreached stdlib code looked like lost coverage. A new ledger lists the 1,672 witnessed stdlib functions, and losing any one fails by name. Every stdlib pruning site now honours the keep-whole switch.
- **Native release size is gated** (#2092): four heap-using programs must build with no debug sections and stay within 10% of their baseline.
- **Perf gates:** a fib row pins the self-inlining against its ablation; the compile-time gate measures in parse speed and pins the JSON program's wasm build; the case-mapping program has its own size rung; seven new wasm growth rows pin field pushes; and the nightly runs the small native perf gate's bool-render negative control.
- New fixtures `list_push_field_in_place` (C-033), `arg_call_rebinds_global` (C-258, C-132) and `fan_trap_waits_for_slow_element_below` (C-200).
