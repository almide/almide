# v0.68.0-rc1 — domain kernels leave the stdlib, and fan.min replaces fan.race

**Release candidate 1** (#1484): published as a prerelease for the soak window, excluded from "latest". It carries everything that landed on `develop` since v0.67.1; the final v0.68.0 is tagged once the soak is clean.

This candidate opens **dialect epoch 14**, which removes and renames surface without a deprecation window where a ruling said so. Two changes reach written code: the vendor- and model-specific domain kernels leave the stdlib for packages, and the fan selection forms are renamed (`fan.race` becomes `fan.min(clock)`, `fan.any` is gone). Every removed spelling is a diagnostic that names where it went. Behind those changes, every public stdlib function has now been inspected on both targets.

## Breaking at epoch 14

- **33 vendor- and model-specific functions leave the stdlib for packages.** The provider streaming clients (OpenAI, Anthropic), the Qwen3 blocks, the Q1_0/Q8_0 quantised kernels and the transformer building blocks now live in `almide/llm` and `almide-graphics/nn` (module `nn.kernels`), and the `mem` module is removed. A call to a removed function gives a diagnostic that names its new package, or tells you to delete the call. The cheatsheet and `llms.txt` say where each one went (#3797, #3806).
- **`fan.race` is now `fan.min(clock) { … }` / `fan.min(clock, xs, f)`, and the clock is required** (ADR-0028). The clock's type says what "least" is measured on: `compute` picks the branch with the least deterministic compute within the budget, and ties go to source order. Writing `fan.min` without a clock is a parse error (#3808).
- **`fan.any` is removed.** To take the first `Ok` in source order, write `a() ?? b() ?? fallback`. Over a list, write `list.find_map(xs, (x) => f(x)?) ?? fallback`. Both already work with effect callbacks on both targets. Each old spelling (`fan.race` in all four forms, `fan.any { }`, `fan.any(xs, f)`) is E027 and names its replacement. `fan.bounded` and `fan.timeout` keep their names (#3808).
- **`testing.assert_throws` is replaced by `testing.assert_aborts(expected, () => …)`** (ADR-0029). The closure runs in a child process on native and in a fresh instance on wasm (C-384, with the new codes E098 and E099). The new Process capability admits it (#3806, #3808).
- **The pre-#3338 native callback aliases are removed**, as their deprecation promised. The epoch gate now fails when a deprecation is overdue (#3806).

## Language surface

- **`fan { }` takes a record form with named arms.** It types as the plain record literal and lowers to the tuple-form fan destructured into a record. It formats one field per line, and a fan nested inside an arm settles correctly (#3808, issue #1388).
- **Identifiers may be non-ASCII.** The lexer classifies identifiers by UAX #31 XID classes and stores them in NFC. A caseless name is decided type-side or value-side by how its module declares it. Module names and import aliases stay ASCII and are refused at parse time otherwise (C-387, #3808, issue #1456).
- **The parser recovers from foreign-language idioms with one error each and continues parsing.** Examples are `return EXPR`, `let mut`, a brace-style `if`, `===`/`!==`, `elif`, the `c ? a : b` ternary, `&&`/`||`/prefix `!`, match arms written with `->`/`:`/`case`, top-level `def`/`function`/`func`/`fun`/`proc`, `const`/`val`, `println!`/`assert_eq!`-style macros, `int`/`i64`/`string`-style type names, and Rust closures (#3746).
- **An interpolation hole whose expression starts on the line after `${` is accepted**, in plain strings and in heredocs (#3746, issue #2810).
- **An unbraced `then`/`else` branch can be any assignment statement**, including a nested target (#3808, issue #3757).
- **`if` and `match` over `Result` values join against a `let`/`var` annotation.** An effect fn no longer reports E041 when its branches are `Result` values bound to a `Result`-annotated let (#3808, issue #3777).
- **`Duration` and `Compute` can be named in a type annotation** (they were E029 before) (#3773).

## fan

- **When a `fan { }` arm reaches an `@ordered` stdlib fn, the block runs in arm order on native too.** That covers `env.set`, the fs writes, stdin reads and process spawning, so native and wasm observe the same state (ADR-0024 D3, C-004) (#3808).
- **Both meters follow one charge table.** A loop-free wrapper's entry and string interpolation are no longer charged on native's default route, so a `fan.bounded` verdict and a `fan.min` winner agree across targets (C-204, C-294) (#3808).
- **When several elements trap inside `fan { list.map }`, the lowest-index trap is the one reported**, not the first trap in time. A light `fan.map` now pays its bookkeeping once per block of elements instead of once per element (C-200) (#3808).
- **Fixes from the fan semantics audit:**
  - a winner of type Float, List or record compiles;
  - an empty `fan.bounded`/`fan.timeout` body is a Unit block on every target;
  - wasm `fan.timeout` honours replay and uses a monotonic clock.

  The audit itself, a cross-language comparison and the acceptance tests also land (#3785, #3786).
- **Native fan runs in parallel for more programs.**
  - Values of type `String` and `List`/`Set`/`Map`/`Result` now qualify (#3569).
  - So does a row kernel that keeps a scalar `var` beside a heap parameter (#3724).
  - So does a `fan.map` whose effect callback only fans out over proven-pure work (#3775).
  - Native meters `fan.race`/`bounded` regions even when the whole program falls off the v1 render (#3683).
  - `fs.fold_lines_chunked` runs sequentially when its accumulator or callback holds an Rc (#3681).
  - `fs.fold_lines_chunked` bounds its thread count (#3711).
- **The native fan runtime was rebuilt for speed:**
  - threads now stay resident and take elements in blocks, through one shared pool that the caller also takes work from (#3759, #3767);
  - offers are published to polling threads that steal blocks (#3774);
  - the cost model was recalibrated per leg (#3763, #3765).

  On the fan floor ledger (`docs/benchmarks/fan-floor.md`, #3766, #3764), every row is now at or under the fastest of Rayon, Go and Zig on the two GCE machines measured: 0.48–0.92x on Intel and 0.47–0.85x on AMD. Before, 22 of 24 rows were 1.06–5.05x (#3775).
- **wasm fan workers take list-of-scalar captures and receive work in blocks.** The embedded host's threads stay resident for the whole run (#3730, #3732, #3748).

## Correctness

- **wasm `error.message` no longer frees a payload it only borrowed** (a use-after-free). The block that `error.context` leaked is released too (#3610).
- **Programs that passed `check` but failed the native build now compile.** The cases fixed:
  - a `Bytes`/`Matrix` fold accumulator, and wrapping a runtime result (#3581, #3582);
  - a `Bytes` `if`/`match` passed to an Almide-compiled fn (#3609);
  - a hoisted `list.set` value in an effect fn (#3594);
  - a `Result` payload of `some`/`ok`/`err` in an effect fn (#3632);
  - two modules declaring a top-level `let` with the same name (#3728);
  - `matrix.concat_cols` on a parameter, and never auto-`?` on a call argument (#3675);
  - a closure value passed to a runtime `Fn` slot (#3693);
  - unrolled matmul, a mut-param call on a captured var, and ordering over opaque stdlib types (#3773).
- **`list.sort`/`min`/`max` over `Matrix` or `Value` is E030 at check time.** Before, the native build produced invalid Rust (#3589). wasm now orders `Bytes`, `Result` and `Unit` elements the way native does instead of walling (#3593).
- **Native tail recursion runs in constant stack for every return type**, including records, variants, `Set` and `Bytes` (#3563).
- **Defects found by the sandboxed effect fuzz campaign are fixed:**
  - a wasm leak on every failed `fs.read_lines`/`list_dir`/`walk`;
  - `fs.copy` of a directory;
  - a Unit effect inside a Unit let (#3621).
- **wasm leaks are released:**
  - host-leaf call results (#3624);
  - the staging blocks of `io.read_n_bytes`/`read_byte` (#3629, #3631);
  - the staging blocks of `fs.read_bytes`/`read_bytes_if_exists`/`stat` (#3680).
- **Cross-target value fixes:**
  - wasm `bytes.read_string_at`/`read_string_be` decode lossily, so a String never holds invalid UTF-8 (#3566);
  - every bytes float writer writes the canonical NaN on both legs (C-210, #3701);
  - wasm `json.to_map` keeps one entry per repeated key (C-380, #3702);
  - wasm `json.remove_path` at the root returns a tagged Null (#3806);
  - rope rotation and multi-head attention no longer walk heads that have no pair or no column (#3583);
  - several native divergences: NaN appends, an empty rope, hidden-width multiplication, and `fold_lines_range` on a directory (#3675);
  - a self or mutual tail call that forwards a `mut` param stays a tail call on wasm (#3675, #3693).
- `almide fix` sees imported modules, and the `!` inside an effect-call `??` fallback is named in the diagnostic (#3527).

## wasm and hosts

- **`process.stdin_lines` runs on every wasm leg** (#3629). **`net.tcp_*` runs on the embedded wasm lane**, built on one native core with classified errors (#3693). **The full-response http client** runs on the WASI 0.3 component (#3675). unix/shm get interim embedded host ops (C-382, C-383) (#3806).
- **The http client frames its own body on every lane** and drops a caller's `Content-Length` (C-385). **`http.serve` refuses** non-final statuses, header names that are not tokens, and control bytes in header values, and drops a handler's framing fields. All of this behaves the same on every host (C-367, C-375) (#3806).

## Performance

- **The native Almide `String` is now a shared refcounted buffer by default** (ADR-0013 stage 2). The steps that led there:
  - one `AlmideString` alias in the generated code (#3716);
  - the `AlmideStr` crate, with a Miri job (#3717);
  - literals rendered through the alias (#3719);
  - the runtime ABI spelled through it (#3746);
  - the switch itself, which also removes `ALMIDE_SHARED_STR` (#3806).

  The migration plan and the GCE A/B procedure are recorded in #3720 and #3715.
- **`--release` on x86_64 targets the x86-64-v3 baseline (AVX2 + FMA) by default.** `--target-cpu portable` (or any rustc CPU name) overrides it. Other architectures keep rustc's generic CPU (#3740). An earlier `native` default was reverted after the spelling-ratio gate caught a 1.25x x86 regression (#3727, #3734).
- **In-place edits come from one `@reuse` declaration** at each stdlib function, and both legs derive their in-place path from it. When the source is at its last use, these functions now write in place:
  - `list.set`/`swap`/`update` and `bytes.set` (#3598);
  - `set.insert`/`remove` (#3603, #3713);
  - `map.update` (#3708);
  - chained `map.set`/`upsert`/`update` on wasm (#3729);
  - `string.push` (#3675);
  - `map.delete`/`remove`, `map.merge` and `bytes.copy_within`/`fill`/`clear` (#3675).

  `@implements` registers self-hosted bodies without a name list (#3587, #3626). Push/set loops in a fold callback or before a self tail call stay linear (#3682).
- **Quadratic paths are linear:**
  - wasm prepend accumulators (`[e] + acc`, and the same push inside a fold callback) (#3529, #3531);
  - wasm `list.flatten` (#3536);
  - `option.collect` and wasm `map.from_list` (#3553);
  - wasm `set.from_list` and `list.unique`/`unique_by`, plus native `list.unique` (#3703, #3706);
  - `string.take_end`/`drop_end`/`ends_with` (#3612);
  - `http.wrap` and `http.with_headers` (#3773);
  - `map.delete`/`set.remove` are amortized O(1) (#3693);
  - `value.merge` on wasm (#3675).
- **Smaller wins:**
  - the enumerate spelling fuses on both legs (#3592);
  - a native region alloc is a bump on x86 (#3597);
  - `Int % literal` is a magic-number multiply (#3771);
  - `option.is_some`/`is_none` borrow their argument (#3723);
  - `option.collect` reserves its result once (#3725);
  - wasm `list.intersperse` allocates once (#3596), and wasm `flat_map` with a literal tail reserves its result (#3714);
  - wasm string compare runs eight bytes at a time (#3714);
  - wasm `option.zip`/`result.partition` take credits correctly (#3546);
  - a read-only `if`/`match` selection of live locals borrows instead of cloning, and an if-arm's temporary moves into the join on the v1 native render (#3731, #3808);
  - wasm `matrix.fma`/`fma3` touch only the operands' overlap (#3808);
  - an owned list used as a `for` head moves (#3746).

## Stdlib inspection

- **Every public stdlib function is inspected on both targets.** `proofs/stdlib-inspection.toml` has 0 uninspected rows out of 999. Each row has a GCE stamp on five criteria: native/wasm parity, complexity, allocation, a 200-program fuzz campaign and the diamond. Generic functions are measured at both Int and String, and every probe runs the success path (#3797, #3806, #3772, #3773).
- **How the inspection works:**
  - the ledger and harness (#3541);
  - a stamp is voided when its implementation's fingerprint changes (#3547);
  - a counted complexity judge, based on instructions and bytes moved and fitted over five sizes (#3568, #3576, #3613, #3721);
  - effect functions are inspected in a seeded sandbox world (ADR-0027, #3616, #3617, #3627);
  - the generator was widened to Bytes, sized numbers, Set, Matrix, Value, the import-only modules and the nominal types (#3551, #3562, #3580, #3602, #3606, #3614);
  - harness fixes (#3545, #3710, #3712).
- Stamping batches: #3572, #3578, #3601, #3607, #3675, #3693.
