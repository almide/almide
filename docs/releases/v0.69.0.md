# v0.69.0 — the redesigned stdlib replaces its old spellings, and untrusted input is bounded by default

The final release of the train that soaked as [v0.68.0-rc1](./v0.68.0-rc1.md) and [v0.68.0-rc2](./v0.68.0-rc2.md). No v0.68.0 final was tagged: the standard-library redesign landed after rc2 as a second dialect epoch, so the release takes the next minor version. It carries two dialect epochs:

- **Epoch 14** (shipped in rc1 and rc2): the vendor-specific streaming clients move to package `almide/llm` and the model-specific kernels to module `nn.kernels` of package `almide-graphics/nn` (rc1 and rc2 named it `almide/nnlib`), `fan.race` becomes `fan.min(clock)`, `fan.any` is removed, and `testing.assert_throws` becomes `testing.assert_aborts`.
- **Epoch 15** (new since rc2): the standard-library redesign. Functions that are not on the redesigned surface are removed, the remaining ones are named by one rule per role, the map callbacks take the entry as one `(K, V)` tuple, and every module that reads outside input bounds it.

Every removed spelling is now a diagnostic that names its replacement. The rc1 and rc2 notes describe the epoch-14 surface, its correctness fixes and its performance work. Everything below landed after rc2.

Release blockers are 0 at the tag. The public stdlib interface diff against v0.67.1 is breaking: 628 signatures are removed or changed and 927 are added. Every removal and every incompatible change is declared in epoch 14 or epoch 15 of `proofs/dialect-epochs.toml`.

## Breaking changes

- **About 600 stdlib spellings are removed or renamed** (epoch 15, R-L0-30, R-L0-40). Most have a direct replacement with the same answer, for example:
  - `fs.write` → `fs.write_text`, `map.entries` → `map.to_list`, `string.chars` → `string.to_list` and `value.str` → `value.string`.
  - `math.fmax` → `float.max`, `int.to_float(n)` → `float.from(n)`, `float.to_int(x)` → `int.from_saturating(x)` and `int64.to_int8(x)` → `int8.from_wrapping(x)`.
  - `list.get_or(xs, i, d)` → `list.get(xs, i) ?? d` and `error.context(r, msg)` → `result.map_err(r, (e) => "${msg}: ${e}")`.
  - `bytes.set_u8` → `bytes.put_u8` and `bytes.cmp` → `bytes.compare`.
  - The operator forms replace `matrix.add`, `sub`, `mul` and `div`, and `Bytes + Bytes` concatenates.
- **Modules that left whole or in part:**
  - The `error` module is removed; use interpolation and `result.map_err`.
  - The types `bytes.Endian`, `path.SafePath` and `json.JsonPath` are removed. The byte order is in the function name (`bytes.get_u32_le`), and `value.root()`, `value.key` and `value.index` build a `value.Path`.
  - Five more `matrix` kernels move to module `nn.kernels` of package `almide-graphics/nn`: `linear_row`, `linear_row_no_bias`, `conv1d`, `linear_f32_row_no_bias` and `select_rows_f32`. Write `import nn.kernels` and call `kernels.linear_row(…)` with the same arguments.
- **Map callbacks take the entry as one `(K, V)` tuple** (R-map-09, #4004). `map.filter`, `any`, `all`, `count` and `find` hand the callback the entry as one tuple, and `map.fold` hands it the accumulator and that tuple, the same element `map.to_list` yields:
  - `map.filter(m, ((k, v)) => v > 0)` and `map.fold(m, 0, (acc, (k, v)) => acc + v)`.
  - A two-parameter lambda `(k, v) => …` still checks: its parameters read as the tuple's elements.
  - `map.fold(m, init, (acc, k, v) => …)` is E004. Write `map.fold(m, init, (acc, (k, v)) => …)`.
  - A named function passed as one of these callbacks takes the tuple, `fn keep(e: (String, Int)) -> Bool`, where it took the key and the value.
- **`regex` takes a compiled `Regex`.** Build one with `regex.new(pat)`, or with `regex.compile(pat)` when you want a `Result`. A literal pattern that the engine refuses is E102 at check time. `regex.captures` answers `List[String?]`.
- **System modules use typed handles:**
  - `io` has `Stdin`, `Stdout` and `Stderr` handles and the generic `io.read`, `write` and `close`. `io.read_line` returns `String?`.
  - `net.TcpStream` and `net.TcpListener` are opaque types.
  - Unix sockets and shared memory move to the new `unix` module.
  - `process` replaces the `exec_*`, `run_in` and `spawn` forms with a `ProcessCommand` record, `output`, `run`, and a `start` / `poll` / `wait` / `stop` handle.
  - `http` request and response values are one `HttpMessage` with headers as `List[(String, String)]`, with `http.send` and `http.start(req, limits)`.
- **Some answers change:**
  - `matrix.get` returns `Option[Float]`, and `matrix.from_bytes_f16_le`, `f32_le` and `f64_le` return `Option[Matrix]` (C-282, C-341).
  - `datetime.from_parts` returns `Result` and refuses an out-of-range field with the same rules as `parse_iso`.
  - `int.wrap_add`, `wrap_mul`, `rotate_left` and `rotate_right` take no width and work on the 64-bit Int (R-int-12). Rewrite `int.wrap_add(a, b, bits)` as `int.wrap(int.wrap_add(a, b), bits)`, and a rotation at width 8, 16 or 32 as the sized module's `rotate_left` on the sized value. A three-argument call is an arity error.
  - `env.set` is fallible.
  - `zlib.inflate`, `decompress` and `gunzip` are plain functions.
  - `hash.fnv1a32` and `hash.sha256_hex` take `Bytes`.
  - `args.positional` and `args.positional_at` take the names of the options the program reads, and the argument after a named `--option` is its value, not a positional: `args.positional(["out"])` on `--out report.txt input.txt` is `["input.txt"]` (#4144, C-181). A call without the list is an arity error.
  - `args.flag(name)` no longer answers to `-<first letter>`; only `--name` sets it. `--` ends option parsing: the flag and option readers ignore what follows it, and the positional readers include it (#4144).
  - A negative count or range bound reads as 0 in `list`, `string`, `bytes` and `matrix`.
  - `http.decode_json[T](req)` takes its input type as a type argument and decodes strictly.
- **Effects and permissions are stricter:**
  - An effect fn passed as a value is an effect: `list.map(xs, fs.read_text)` from a pure fn is E006.
  - `[permissions] allow` uses finer categories: `FS` for files, `Proc` for processes, `Net.fetch` and `Net.listen` for the network, `Time` for the clock, and `IO.stdout`, `IO.stderr` and `Abort` for output and aborts.
  - `allow = []` now allows nothing.
  - `process.env`, `process.pid`, `process.sleep`, `io.write` and `net.tcp_is_open` are `effect fn`s.
- **Raw-memory functions need an explicit import.** They move to the new `ffi` module and need `import ffi` in the file that calls them (E100). The five `bytes` raw-pointer functions are deprecated in its favour.

## Migration

1. **Run `almide check`.** A call to a removed spelling is an error (E002, or the module-not-found error for a removed module), and its hint gives the replacement call from the epoch-15 ledger. Removed spellings are not rewritten automatically, so apply each hint by hand. Most of them are a one-name change with the same arguments.
2. **Run `almide fix`** for the spellings that are still deprecated (E052) rather than removed:
   - `regex.full_match` → `regex.is_full_match`.
   - `int.pop_count` → `int.count_ones`, `int.bit_width` → `int.bit_length` and `float.sign` → `float.signum`.
   - The `bytes` raw-pointer functions → `ffi.*`. `almide fix` offers this rewrite only in a file that already has `import ffi`.
   - `almide fix` also wraps a literal regex pattern in `regex.new(…)`.
   - A named argument spelled with an old parameter name is E004, and its hint names the new parameter. Positional calls are unchanged.
3. **Fix the calls whose shape changed.** These are check errors with a hint, not removed spellings:
   - `map.fold(m, init, (acc, k, v) => …)` → `(acc, (k, v)) => …`, and a named map callback takes the `(K, V)` tuple.
   - `matrix.get` and the `matrix.from_bytes_*_le` loaders return an Option: add `?? default` or match on it.
   - `datetime.from_parts` returns `Result` and `env.set` is fallible: propagate with `!` in an effect fn, or fall back with `??`.
   - A regex operation takes a `Regex`: pass `regex.new(pat)`, not the pattern text (`almide fix` wraps a literal pattern).
   - `int.wrap_add(a, b, bits)` → `int.wrap(int.wrap_add(a, b), bits)`, and `int.rotate_left(a, n, 8)` → the sized module's `rotate_left`.
   - `args.positional()` → `args.positional(["<option>", …])`, naming every option the program reads.
   - `http.decode_json(req, decode)` → `http.decode_json[T](req)` with `T` declared `: Decode`.
   - `hash.fnv1a32` and `hash.sha256_hex` take `Bytes`: pass `bytes.from_string(s)`.
   - A pure fn that passes an effect fn as a value (`list.map(xs, fs.read_text)`) must become an `effect fn` (E006).
4. **Update `almide.toml`:**
   - If a manifest used `IO` for file access, add `FS`. If it used `Env` for `process.*`, add `Proc`.
   - A program that prints or asserts needs `IO` and `Abort`.
   - Grant native-code dependencies by name with `[permissions] native = ["<dep>"]`.
   - List git dependency owners outside `github.com/almide` under `[trust] owners`, or run `almide trust <owner>`.
5. **Packages:** the neural-network kernels are module `nn.kernels` of `almide-graphics/nn`: run `almide add almide-graphics/nn@v0.2.0 --trust github.com/almide-graphics`, write `import nn.kernels` and call `kernels.gelu(m)`. A program that imported `nnlib` from rc1 or rc2 moves to this package. `almide/llm` must be on a release that uses the epoch-15 spellings.

The complete list, one entry per spelling with its replacement, is in `proofs/dialect-epochs.toml` (epochs 14 and 15). The redesign record is in `docs/roadmap/stdlib-redesign/`.

## Stdlib

- **New modules:**
  - `deque` (`Deque[A]` with push and pop at both ends) and `heap` (`Heap[A]`, min-first, with key and comparator orders).
  - `bool`, with `parse`, `compare` and `to_string`.
  - `uuid` (v4, v7, parse and the byte conversions), `unix`, `ffi`, and `secret`.
- **Number families are complete across the eight sized integers.** Each type has `compare`, `min`, `max`, `clamp`, `floor_div`, `modulo`, `pow`, `is_even` and `is_odd`, the bitwise operations and bit counts, wrapping arithmetic, rotation, `bit_length` and `parse`.
  - `float32` and `float64` have the floating-point requirements: total-order compare, classifiers, roundings, `signum`, bits and constants.
  - An executable matrix gate checks each family.
- **New functions in existing modules:**
  - `list` gains the `_by` and `_with` cells for sort, min, max and binary search, plus `unzip` and `range_step`. `set` and `map` gain sequence algorithms.
  - `string` gains its Text and Container functions.
  - `math` gains the inverse trigonometric and hyperbolic functions, `hypot`, `cbrt`, `expm1` and `log1p`.
  - `hash` gains `crc32`, `adler32` and `sha512`, and HMAC-SHA256 and HMAC-SHA512 over `Secret[Bytes]` keys and tags with constant-time verification. The stdlib has no MD5 or SHA-1.
  - `url` gains `encode_form`, `decode_form`, `parse_query` and `resolve` (RFC 3986 §5).
  - `path` gains `components`, `relative_to` and `with_extension`.
  - `env` gains `vars`, `remove` and `secret`, which reads a variable as `Option[Secret[String]]`.
  - Also new: `random.Rng` (a seeded generator), `datetime.now_ms`, `args.has_flag`, `matrix.zip_with` and `matrix.concat_rows`.
- **`fs.open_root`** opens a rooted file-system family that refuses any path leaving its root, on both targets.
- **An auto-imported module is loaded only when a source reaches it**, so a program that does not use a module does not check it.

## Security hardening

This release closes a security review of the toolchain and the stdlib. Each fix has a contract or a gate with a recorded negative control. The status of each row is in `docs/roadmap/active/security-by-construction.md`.

- **Toolchain and supply chain:**
  - Git dependencies are fetched only from trusted owners.
  - Native code in a dependency, and `@inline_rust`, need an explicit grant.
  - Native builds check rustc against a minimum version.
  - A Unicode bidirectional control character in source is E101.
  - Release builds ignore the environment switches meant for development.
- **Installer, updater and caches:**
  - Self-update uses the in-tree HTTPS client and refuses an implicit downgrade, and the install scripts require HTTPS.
  - `almide install` writes only a plain name inside its bin directory, and it applies the trust check and the native-code grant.
  - Build caches live under a private per-user directory, and a cached binary runs only when its digest matches.
  - The output name of `almide build` must be a plain name.
- **Editor and agent integrations:**
  - The `almide mcp` tools confine path arguments to the project and pass them as arguments, never as flags.
  - The read-only `almide mcp` tools never fetch dependencies or write `almide.lock`.
  - The language server takes its workspace root as an absolute path and stays inside it.
  - `almide fmt` on a directory skips `.git`, `target` and `node_modules`, and neither `fmt` nor `test` follows symlinks.
- **Manifests:**
  - `almide.toml` and `almide.lock` are read only as regular files of bounded size.
  - Control and bidirectional characters in manifest text are refused.
  - The compiler version requirement is enforced on every build.
- **Effects and permissions:**
  - Effects carried by function values, and effect methods called through protocol bounds, are checked.
  - The capability categories are finer, and `[permissions] fs` limits file access to the granted directories on native and on the embedded wasm host.
- **Untrusted input:**
  - `json.parse` follows RFC 8259 and I-JSON strictly, and its nesting is bounded at 1000.
  - `url.parse`, `url.resolve` and the HTTP client's URL splitter read URLs the way browsers do.
  - `base64` decoding accepts only the canonical form.
  - `datetime.parse_iso` bounds the year.
  - Case mapping never folds a non-ASCII letter into ASCII.
  - Number parsing accepts only finite ASCII-trimmed decimal text.
  - The regex engine is linear time (a Pike VM) and refuses deep nesting.
  - A map whose hash index is flooded with colliding keys falls back to an index ordered by key on both targets, so the flood no longer degrades every lookup.
- **http.serve:**
  - Request heads that RFC 9112 does not allow are answered with 400.
  - The router reads one canonical path.
  - Connections are served by a 64-slot pool with a 10-second head deadline.
  - A handler error is answered with a fixed 500 body and logged on the server.
  - A runtime abort in a handler fails only that request.
  - Responses carry `X-Content-Type-Options: nosniff`.
  - A typed request decode refuses unknown keys at every depth.
- **Runtime limits:**
  - `zlib` output is bounded at 256 MiB, with `_max` variants for a larger bound.
  - The whole-file `fs` readers accept only regular files of at most 1 GiB.
  - Network reads and received descriptors are bounded.
  - Native fan threads are bounded at one per CPU.
  - The embedded wasm host meters every store against one memory budget, which follows the environment's memory limit, and it checks every guest pointer.
  - Out of memory is never contained.
- **Complexity:** substring and byte search, `value.merge`, `pick` and `omit`, `json.set_path`, `path.normalize`, `math.factorial`, `bigint` text conversion and `pow`, `url.parse_query`, `string.from_utf16`, `list.range_step`, `math.choose` (#4212) and wasm `map.remove` and `set.remove` no longer have quadratic or unbounded cases.
- **Secrets and randomness:**
  - The new `Secret[A]` type prints redacted and compares in constant time. A `Codec` type that holds a `Secret` derives only decode (E023 on encode).
  - `bytes` and `string` have `is_equal_constant_time`.
  - Codec fields take `@skip` and `@skip_decode`, and `T.decode_strict` refuses unknown keys.
  - `random` draws from OS entropy on every target.
- **Error texts:**
  - Runtime error texts escape control and bidirectional characters in the paths, commands, hosts and other values they quote.
  - An HTTP error that quotes a URL masks its password.
  - `process.kill` uses kill(2) directly and checks its pid and signal.

## Correctness

- **wasm: a module global passed into a function's result call keeps its value** (#4115).
- **Integer narrowing:** `MIN / -1` in constant folding keeps the C-002 guard (#4161), and unary minus on `Int8`, `Int16` and `Int32` is narrowed (#4163).
- **A raw address that outlives a rebound block is refused** (#4153, #4169).
- **Derived `Codec.decode`** returns err on a short tuple-variant payload instead of aborting, and it reports the same error path on both targets (#4164, #4165).
- **Native and wasm agree:**
  - `io.read_all`, `read_line` and binary `io.write` (#4138, #4142).
  - `http.query_params` (#4117).
  - `env.set` (#4200).
  - Deeply nested `regex.compile` (#4195).
  - Net handles shared across fan arms (#4199).
  - The interpolation of HTTP values and `JsonPath` (#4204, C-432).
- **Native:**
  - JSON key interning is bounded (#4202).
  - Children started with `process.start` and never waited on are stopped when the program exits (#4214, C-437).
- **Checker:**
  - A protocol bound whose type is resolved after the call is judged after solving. For example, `list.sum` at a non-numeric element is now a check error instead of a build panic (#4235).
  - A container, tuple or function type at a `Numeric`, `Integer` or `Text` bound is refused.
  - An effect fn value in a plain fn slot is refused at check time (#4173).
  - A named record literal is checked against the type it builds.
  - E033 applies only to a bundled module's own opaque type, not to a user type with the same bare name.
  - A declared generic type without its type arguments is E093.
  - `==` between scalars of different kinds is E037.
  - A built-in protocol name cannot be redeclared in any module (#4190).
  - A record update or a destructuring pattern on another module's opaque record, such as `Secret`, is E033.
  - A fn declared `-> Never` whose body completes with a value is refused.
  - A `Matrix` operator pairing with no matrix operation behind it is refused at check time instead of lowering to a scalar operation.
  - `json.stringify` on a `Codec` record, where a `Value` is expected, is a check error that points at the type's own `encode`, instead of a Rust build failure (#4272).
  - A user type named like a stdlib type, such as `Secret`, stays the user's type in a package and in the `Codec` derive (#4273).
- **Modules and packages:** a dependency's bare import of its own module resolves to its package even when the root project has a module of the same name, instead of reporting a circular import (#4270).
- **Code generation and lowering:**
  - A piped `!` on a plain value is a no-op (#4215).
  - An unqualified call to an `@intrinsic` sibling uses its symbol (#4216).
  - Runtime symbols do not collide with Almide-bodied functions (#4217).
  - A generic caller's type parameters are kept apart from the callee's (#4218).
  - `path.join` onto `/` keeps the root.
  - `Int64` and `Float64` operators work.
  - Unary minus on a `Matrix` works.
  - An undefined method on a clock receiver is reported.
- **A pure fn returning `Result` keeps its `mut` parameter's buffer on the err path as an effect fn does**, and a match on a borrowed map read binds its payloads by reference. A rejection path that trapped on wasm now agrees with native, and the native build no longer fails with `AlmideStr: Borrow<&AlmideStr>` (#4274).
- **Passing an immutable binding to `bytes.as_mut_ptr` is rejected at check time** (#3975, issue #3966, C-062).

## Tooling

- **The module interface and the stdlib signature indexes show the `mut` parameter modifier and declared aliases** (#3889).
- **`almide build --print-release-rustflags`** prints the release codegen flags (#3882).
- **Release titles and bodies are published from `docs/releases/<tag>.md`** (#3884).
- A dependency checkout at the locked commit is reused instead of cloned again.

## Gates and evidence

- New nightly gates run every cross-target program's generated Rust under Miri and AddressSanitizer, and they run the wasm corpus under a checked allocator with re-injected historical bugs.
- The MemorySafe proofs cover a typed core of the language. The bounds and init witnesses are anchored to the shipped wasm bytes, and a native wall judges every certificate the verified native renderer emits.
- Runtime `unsafe` is gated line by line, and the unused `burn` backend is deleted.
- PR CI checks a commit-rotated slice of the heavy corpus gates, and pushes run the whole corpus.
- ADR-0030 makes compile cost a contract.
