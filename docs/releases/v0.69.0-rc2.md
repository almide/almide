# v0.69.0-rc2 — filesystem access is rooted, and the wasm memory-safety witnesses gain RC and bounds checks

**Release candidate 2** (#1484): published as a prerelease for the soak window and excluded from "latest". It follows [v0.69.0-rc1](./v0.69.0-rc1.md) and carries no new dialect epoch, so the rc1 notes still describe the epoch-14 and epoch-15 surface. Everything below landed after rc1. The final v0.69.0 is tagged once the soak is clean.

Two release blockers are open at the tag (#4386, #4399). On an RC tag the blocker gate prints them and does not fail.

## Breaking changes

- **Rust host ABI:** a `Region` parameter of an `@extern(rust)` function is now passed as `(base: *mut u8, len: usize)` (#4353).
- **Rooted filesystem access** (#4293): filesystem calls resolve under a root, and on Windows rooted access is refused until its implementation lands.
- **Input types state their role** (E110): a decode input says which type it decodes.
- **Compile cost has budgets** (ADR-0030, E111–E113): a program over its compile-cost budget is refused at check time.

## Security

- **HTTP:** the `Content-Type` comes from the body's type, and an owned header that would override it is refused.
- **WASI 0.3:** `net` TCP, UDP and host lookup run on the component (C-448).
- **`fs.append_bytes` is a true append** on every target, and never a read followed by a rewrite (#4382, C-447).
- **FFI host boundary** (ADR-0031 amendments):
  - `ffi.slice` is new.
  - A `Region` can cross `@extern(rust)` as `(base, len)`.
  - A `Region` can cross the wasm host boundary (#4354, C-446).
- **Capabilities:** each embedded-host op family declares its own capabilities (#4338), so the capability witness charges TCP, Unix and UDP ops to `Net`. A closure's capabilities are charged to the function that creates it, and the certificate records the callee's reach as parametric.
- **Runtime `unsafe`** goes from 103 to 102 lines, and each remaining line states its invariant (#4342).

## Correctness

- **An inclusive range ending at `Int` max** no longer miscompiles (#4355).
- **Native:** the accumulator tail-recursion rewrite is fixed (#4385), and so is the typing of bundled effect functions (#4375).
- **`matrix.mul` on native is bitwise equal to the scalar and wasm order.** It no longer fuses multiply-add on AVX, and runs at 1.10–1.18x the fused speed (#4344, C-303).
- **Error texts:** an invalid `ProcessChild` handle is quoted the same way on native and wasm (C-418).
- **Interpreter oracle:**
  - It now runs `fs.append_bytes`, `uuid.v7` and `http_response_headers`, so run-parity votes on 996 fixtures, with 15 unsupported.
  - It runs `value.set_path` (#4401).

## Gates and evidence

- **wasm memory-safety witnesses:**
  - A per-helper certificate (#4278).
  - An RC event check.
  - Loop-exit bounds (#4280).
  - Field bounds with `FieldCert` (#4013, #4279).
  - String byte reads, certified on their own tests (#4281).
  - A release before an abort is matched like any other call.
- **Native:** a per-PR Miri and AddressSanitizer slice, and the `AlmideBox` Stacked Borrows fix (#4303).
- **Tests:** every stdlib function is tested on both targets (1322 of 1322).
- **`embedded_cross` fixtures:** they are checked first, and a non-zero check exit must be declared (#4350).

## Dependencies

wasmtime 50.0.1 (RUSTSEC-2026-0420, 0422, 0423 and 0424), and the toolchain is Rust 1.97.0.
