# v0.57.2 release notes — DRAFT (apply at tag time)

Working draft for the next release off `develop` (everything after the
v0.57.1 tag). Paste the summary into `gh release edit v0.57.2 --notes` and
fold the one-paragraph form into llms.txt's Meta rows; delete this file in
the same commit. The recommended path is `v0.57.2-rc1` first — this release
carries two behaviour changes (below) and a large compiler-internals batch,
which is exactly the class the RC channel (#1484) exists for.

## Behaviour changes (release-note REQUIRED)

- **Dependency resolution is now MVS, as the spec always documented**
  (#1458). Per package (name + major), the MAXIMUM requested version wins
  across the whole requirement graph, in either declaration order — the
  resolver previously kept whichever requirement the walk met first, so a
  diamond could silently select the older version. If a build selected a
  version by declaration-order accident, it may now select a newer one.
- **A corrupt `almide.lock` is an error, not a silent re-resolve** (#1465).
  The lock reader is now the `toml` crate: a ref containing `,`/`}`/`"`
  round-trips, a malformed entry names the dependency and the missing field,
  and `fetch_all_deps` propagates instead of quietly refetching the world.

## Fixed — cross-target correctness

- **Float equality family** (C-289, the 2026-08-16 nightly finding):
  `list.unique/dedup/contains/index_of` over `List[Float]` now compare with
  f64 `==` on the wasm leg (`-0.0 == 0.0`, `NaN != NaN`) instead of raw slot
  bits. The constant folder had masked the divergence for literal inputs.
- **Tail-position `if`/`match` mixing `none` with `some(record/list)`**
  (C-287, #1495) lowers on wasm — the almide/dfa scanner-return shape; the
  arm router now mirrors the bind-position payload router.
- **`list.enumerate` over rich-variant lists** (C-288, #1496) runs on wasm
  with an exact recursive pair drop; unnameable element classes still wall
  honestly as `list.enumerate_x`.
- **Mono instantiations over module-qualified types** (#1496): the dotted
  type name is sanitized at the single mint point, so a fallible-HOF
  instance over `pkg.Type` links instead of walling as a phantom registry
  gap (also un-walled `[T: Codec]` bounds across module boundaries).

## Fixed — performance / behaviour parity

- **The whole sort family is O(n log n) and stable** (#1459): `sort`,
  `sort_str`, `sort_by` (+`_rc`), `sort_by_float` (+`_rc`), `sort_by_keys`,
  `sort_by_str_key` (+`_rc`), `sort_float`, and the compound
  tss/tsstr/lint/oint sorts replace selection/insertion sorts on the wasm
  leg. Measured: `sort` n=20k 150 ms → 1.66 ms; plain sorts gain the
  stability native always had.

## Fixed — diagnostics and recovery

- **A broken expression-bodied fn keeps its declaration** (#1489): the
  parser recovers with an Error body, so the signature survives and every
  later diagnostic in the file still fires.
- **Every parse error carries a hint** (#1471): a corpus-wide gate enforces
  non-empty hint content, and markerless parse errors get a floor hint
  (unclosed-delimiter guidance on EOF).
- **Or/as/range patterns get targeted hints** (#1461): `Red | Green =>`,
  `pat @ name`, `1..<5 =>` each name the Almide form instead of a bare
  "Expected FatArrow".
- **E054** (#1464): the fmt AST-conservation refusal is a coded diagnostic
  (`almide explain E054`), and the LSP logs the reason instead of dropping it.

## Release / quality infrastructure

- **Release-blocker gate** (#1482): `I-unsound`/`I-miscompile`/
  `I-divergence`/`regression` labels block a final tag mechanically
  (`scripts/count-release-blockers.sh --gate` in the release workflow);
  taxonomy in `docs/project/ISSUE-TAXONOMY.md`.
- **RC channel** (#1484): `vX.Y.Z-rcN` tags publish as prereleases.
- **Interface differ** (#1488): `scripts/check-interface-diff.sh` classifies
  the public surface between refs (identical/additive/breaking) and refuses
  an undeclared breaking release. This release measures **identical** against
  v0.57.1.
- **LLM-surface gate** (#1483 floor): ```` ```almide check ```` fences in
  llms.txt/CHEATSHEET must compile in CI — the first run caught the
  cheatsheet's own Complete example missing `import process`.
- **Fuzz streak scored from the night verdict** (#924): a reclaimed runner
  costs coverage, not the streak; an evidence-free night fails as infra.
