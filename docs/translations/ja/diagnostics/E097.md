# E097 — `type`、`protocol`、`test` の前にある `pub`

[English](../../../diagnostics/E097.md) | [日本語](./E097.md) | [简体中文](../../zh-CN/diagnostics/E097.md)

> 原文: [E097.md @ 9a95b285](https://github.com/almide/almide/blob/9a95b28519b90ae535dc9918bfed04805dc4675c/docs/diagnostics/E097.md)。これは読者向けの非規範的な翻訳です。CLI に埋め込まれる診断解説は英語原文のままです。

Almide のトップレベル宣言は、別の指定がなければ公開です。`mod` はプロジェクト内、`local` はファイル内に範囲を狭めます。`pub` が受け入れられるのは、`fn` またはトップレベルの `let` / `var` の前で、その既定を明示する場合だけです。`type` と `protocol` はなくても公開で、`test` ブロックには可視性自体がないため、これらの前の `pub` は E097 です。

```almide
pub type Point = { x: Int, y: Int }   // ← E097: `pub` does not apply to `type`
```

これは Rust や TypeScript の作者が型を公開するとき最初に書きがちな宣言です。E097 以前、パーサーは `type` キーワードで「Expected Fn (got Type 'type')」と止まり、トークンは示しても変更方法を示しませんでした。

## 修正

`pub` を削除します。インポートする側からは従来どおり型が見えます。

```almide
type Point = { x: Int, y: Int }
```

型の可視性を既定より狭めるには、適用可能な修飾子を使います。

```almide
mod type Pair = { a: Int, b: Int }    // this project only
local type Tag = { name: String }     // this file only
```

`pub protocol Shape { … }`（`pub` を削除）と `pub test "…" { … }`（`pub` を削除）にも同じ規則が適用されます。

## 診断の形

```
error[E097]: `pub` does not apply to `type` — remove `pub`
  in pub type
  here: pub type Point = { x: Int, y: Int }
  hint: A `type` is public by default — importers see it without a modifier. Remove `pub`; to narrow it, write `mod type` (this project) or `local type` (this file).
  try: delete the highlighted text (machine-applicable — `almide fix` applies it)
```

fix-it は字句解析器のトークン位置から取得した `pub` キーワードと、その後ろの空白に結び付いているため、`almide fix <file>` はその範囲だけを削除します。パーサーはその後、`pub` がないものとして宣言を読むため、ファイルの残りも検査され、このキーワードが生むエラーは E097 だけです。

## Fix-it 判定

**mechanical** — `pub type T = …` と `type T = …` は同じ公開型を宣言し、`pub protocol` / `pub test` もキーワードなしで同じ意味です。（`mechanical` = 無人の修正ツールが書き換えを適用可能、`conditional` = 修正案にレビューが必要、`not-fixable` = 自動書き換えは存在しません。#1486 の適用可能性の原則。）
