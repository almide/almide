# E027 — fan コンビネーターの廃止記録：置き換え先を示す廃止済みの書き方

[English](../../../diagnostics/E027.md) | [日本語](./E027.md) | [简体中文](../../zh-CN/diagnostics/E027.md)

> 原文: [E027.md @ 9a95b285](https://github.com/almide/almide/blob/9a95b28519b90ae535dc9918bfed04805dc4675c/docs/diagnostics/E027.md)。これは読者向けの非規範的な翻訳です。CLI に埋め込まれる診断解説は英語原文のままです。

E027 は fan の表面構文の移行コードです。廃止された各表記には、置き換え先をヒントで示します。

## `fan.race` → `fan.min(clock)`、`fan.any` → `??` / `list.find_map`（dialect epoch 14）

ほかのエコシステムで `race` は「最初に完了するもの」（JS の `Promise.race`、Haskell の `race`、`select`）、`any` は「順序の保証なし」（`Promise.any`、`findAny`、Rayon の `find_any`）を意味します。Almide の2つの形式はいずれの選び方でもなかったため、dialect epoch 14 で両方の名前を廃止しました（ADR-0028、2026-10-18 採択）。

| 以前 | 現在 | 選ぶもの |
|---|---|---|
| `fan.race { a(), b() }`、`fan.race(budget) { … }`、`fan.race(xs, f)`、`fan.race(budget, xs, f)` | `fan.min(compute.ms(5)) { a(), b() }` / `fan.min(compute.ms(5), xs, f)` — clock 引数は必須 | 予算内で決定的な計算量の消費が最小だった Ok。同点ならソース順 |
| `fan.any { a(), b() }` | `a() ?? b() ?? fallback` | ソース順で最初の Ok。`??` の右辺は左辺が失敗したときだけ実行されるため、それより後の候補は実行されない |
| `fan.any(xs, f)` | `list.find_map(xs, (x) => f(x)?) ?? fallback` | リスト順で最初の Ok。`?` は要素の Err を `none` に変換し、その要素を飛ばす |
| `fan.first_ok`（epoch 14 の暫定草案名） | 同じ2つの書き方 | — |

`fan.any` は改名ではなく削除されました。候補を順に試すことは定義上逐次処理であり、ほかの言語でも並行処理ライブラリには置いていません（Rust の `Iterator::find_map`、OCaml の `List.find_map`、Elixir の `Enum.find_value` はすべてリスト関数です）。`fan.min` の clock 引数は、何について「最小」を測るかを示します。なければ `fan.min { 3, 5 }` は最小の値に読めるため、clock なし形式は E027 ではなく構文解析エラーです。

```almide
effect fn main() -> Unit = {
  let w = fan.race { solve_fast(), solve_slow() } ?? -1   // ← E027: write fan.min(compute.ms(5)) { … }
  let f = fan.any { fetch_a(), fetch_b() } ?? -1           // ← E027: write fetch_a() ?? fetch_b() ?? -1
}
```

実時間による選択 — `fan.min(duration.ms(n)) { … }`、最初に完了する arm、arm は I/O 可、敗者は次の計量箇所または I/O 境界でキャンセルし終了を待つ — は採択済み（ADR-0028）で、後続変更（#3788）で入ります。それまでは E027 ではなく型エラーです。

## 以前の削除

`fan.timeout(ms, thunk)` は完全に削除され、`fan.race` / `fan.any` / `fan.settle` の thunk リスト形式は決定的なブロックヘッドに置き換えられました。旧形式のどれを呼んでも、関数ごとの移行ヒント（「changed signature: the thunk-list form was removed; ... is now a block head」）付きの E027 を返します。

`fan.timeout` 自体は 0.29.0 で廃止されました（契約 C-006）。実時間のタイムアウトには、ターゲット間で可搬な意味がありません。ネイティブなら実スレッドと `recv_timeout` で強制できますが、wasm には時計、スケジューラー、スレッドがないため、thunk は常に最後まで実行され、タイムアウトは一度も起きませんでした。また、標準ライブラリの中で、結果がプログラムと入力の関数にならない唯一の表面 API でもありました。締切に達するかどうかは、ネイティブ同士の2回の実行でもマシンの負荷に依存しました。どちらの性質も、ターゲット間で観測可能な出力がバイト単位で一致するという言語の中核的な約束に反します。

```almide
effect fn main() -> Unit = {
  let r: Result[Int, String] = fan.timeout(5000, () => slow())   // ← E027
}
```

## 修正

プログラムを呼び出すホスト境界で締切を強制します。

```bash
timeout 5 ./app          # POSIX
wasmtime run app.wasm    # + host-side deadline of your choice
```

Almide 内では処理を直接実行するか、決定的な `fan.bounded(compute.ms(n)) { … }`、またはオラクル層の `fan.timeout(duration.ms(n)) { … }`（呼び出しに代わったブロックヘッド）で制限します。

```almide
effect fn main() -> Unit = {
  let r: Result[Int, String] = fan.bounded(compute.ms(5)) { slow() }
}
```

## E027 が扱う3つの廃止

`fan.timeout`（0.29.0）、`fan.race(thunks)`（0.42.0）、上記 epoch 14 の組です。最初の2つは、同じ理由を別の形で述べたものです。実時間の締切も実時間の競争も、結果をマシンのタイミングの関数にします。一方、Almide のモデルは決定的なデータ並列です。`fan` は並列実行しても、観測可能な振る舞いはリスト順の逐次評価として定義されます（[並行処理に対する立場](../../../roadmap/active/concurrency-stance.md)を参照）。オラクル層（`fan.timeout(duration…)` と、今後の `fan.min(duration…)`）では、タイミングを記録済みのホスト入力として受け入れ、暗黙の入力にはしません。

`fan.race(thunks)` には、廃止メッセージが示すもう1つの問題がありました。実際には競争していませんでした。脱糖は `fan.race([t0, t1, …])` を t0 の本体に置き換え、残りを評価しなかったため、正確には `thunks[0]()` でした。

移行：

| 削除されたもの | 意図していたもの | 使用するもの |
|---|---|---|
| `fan.timeout(...)` | 締切 | プログラムを呼び出すホスト境界（`timeout 5 ./app`）、または `fan.timeout(duration.ms(n)) { … }` |
| `fan.race(ts)` | thunk[0] の結果 | `ts[0]()` — 直接呼び出す |
| `fan.race(ts)` / `fan.any { … }` | 最初に成功する候補 | `a() ?? b() ?? fallback` |
| `fan.race { … }` | 決定的な計算量の最小 | `fan.min(compute.ms(n)) { … }` |

## Fix-it 判定

**not-fixable** — このエラーは、自動書き換えでは判断できない意味上／設計上の問題を示します。（`mechanical` = 無人の修正ツールが書き換えを適用可能、`conditional` = 提案された修正にレビューが必要、`not-fixable` = 自動書き換えは存在しません。#1486 の適用可能性の原則。）
