# E055 — Result に対する `?.`

[English](../../../diagnostics/E055.md) | [日本語](./E055.md) | [简体中文](../../zh-CN/diagnostics/E055.md)

> 原文: [E055.md @ 9a95b285](https://github.com/almide/almide/blob/9a95b28519b90ae535dc9918bfed04805dc4675c/docs/diagnostics/E055.md)。これは読者向けの非規範的な翻訳です。CLI に埋め込まれる診断解説は英語原文のままです。

オプショナルチェーン演算子は定義上 Option 専用です（ADR-0005：`o?.f ≡ option.map(o, (v) => v.f)`）。Result は Option ではありません。

```almide
type Item = { n: Int }
fn g(r: Result[Item, String]) -> Int? = r?.n   // ← E055
```

## 代わりの書き方

まず変換するか取り出します。エラーには次の選択肢が含まれます。

```almide
(r?)?.n          // `r?` converts Result → Option (err → none), then chain
(r ?? { n: 0 }).n       // unwrap with a fallback, then access directly
match r { ok(v) => some(v.n), err(_) => none }
```

このコードができる以前、この誤用はコードなしの単なる `error:` 行であり、`almide explain`、フィクスチャハーネス、網羅性ゲートから見えませんでした（#1107 D2）。

## Fix-it 判定

**conditional** — 変換（`(r?)?.f`）か取り出し（`?? fb`）かは意図によります。（`mechanical` = 無人の修正ツールが書き換えを適用可能、`conditional` = 提案された修正にレビューが必要、`not-fixable` = 自動書き換えは存在しません。#1486 の適用可能性の原則。）
