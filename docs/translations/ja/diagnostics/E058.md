# E058 — ハッシュ化できない Map キー

[English](../../../diagnostics/E058.md) | [日本語](./E058.md) | [简体中文](../../zh-CN/diagnostics/E058.md)

> 原文: [E058.md @ 9a95b285](https://github.com/almide/almide/blob/9a95b28519b90ae535dc9918bfed04805dc4675c/docs/diagnostics/E058.md)。これは読者向けの非規範的な翻訳です。CLI に埋め込まれる診断解説は英語原文のままです。

ハッシュ化できない `Map` キー型です。`Float`（IEEE-754 の等値性により検索に使えない）、`Map`、またはフィールドのどこかにそれらを含むレコード／バリアントが該当します。

```
error[E058]: type 'Float' is not hashable — cannot be used as a Map key (it contains a Float)
```

```almide
fn main() -> Unit = {
  let m: Map[Float, Int] = [:]   // ← E058: Float keys have no stable equality
  println(int.to_string(map.len(m)))
}
```

この規則はフロントエンドで働き、両ターゲットを一致させます。以前はハッシュ化できないキーが `check` を通り、ネイティブでは rustc の `Hash` 制約で失敗する一方、wasm では異なるキーが暗黙に同一視されていました（#598）。

型の中の**関数**（名前付きレコード内の関数型フィールドを含む）によって禁止されるキーは、キー内のクロージャの分類である [E016](../../../diagnostics/E016.md) として、独自の文面で報告します。

修正は、ハッシュ化可能なデータ（`String`、`Int`、`Bool`、またはそれらのレコード／バリアント）をキーとし、ハッシュ化できない値を値側に置くことです。

```almide
fn main() -> Unit = {
  let m: Map[String, Float] = [:]   // Float as VALUE — allowed
  println(int.to_string(map.len(m)))
}
```
