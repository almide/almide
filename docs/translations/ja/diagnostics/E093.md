# E093 — 型引数の数が型の宣言と一致しない

[English](../../../diagnostics/E093.md) | [日本語](./E093.md) | [简体中文](../../zh-CN/diagnostics/E093.md)

> 原文: [E093.md @ 9a95b285](https://github.com/almide/almide/blob/9a95b28519b90ae535dc9918bfed04805dc4675c/docs/diagnostics/E093.md)。これは読者向けの非規範的な翻訳です。CLI に埋め込まれる診断解説は英語原文のままです。

角括弧で書く型（`Pair[Int]`、`Cell[Int, String]`）は、宣言にあるパラメーターごとに型を1つ渡します。数が異なる場合、意味を持ちません。余分な引数で置き換える文字がないか、何も与えられない文字が残るためです。以前はこれが `almide check` を黙って通り、余分な引数が捨てられるか、ジェネリック別名が不透明な名前のままとなり、タプルのインデックスやリスト呼び出しで無関係なエラーにより拒否されていました。E093 は型を書いた場所で個数を報告します。

```almide
type Pair[T] = (T, T)

fn first(p: Pair[Int, Int]) -> Int = p.0   // ← E093: 'Pair[T]' takes 1 type argument, but is applied to 2
```

ジェネリック別名、ジェネリックレコード／バリアント、そして引数を取らないパラメーターなしの型を含む、すべての宣言済み型に適用されます。

```almide
type Score = Int

fn bump(s: Score[Int]) -> Score = s + 1    // ← E093: 'Score' takes no type arguments, but is applied to 1
```

組み込みのジェネリック型も同じ数え方です（#3408）。`List`、`Option`、`Set` は1引数、`Map` と `Result` は2引数、組み込みのスカラー（`Int`、`String` など）は0引数です。個数は、組み込み型名を認識する唯一の場所であるリゾルバーの組み込み表から取得します。

```almide
fn total(xs: List[Int, Int]) -> Int = 0     // ← E093: 'List[T]' takes 1 type argument, but is applied to 2

type Index = { names: Map[String] }          // ← E093: 'Map[K, V]' takes 2 type arguments, but is applied to 1
```

角括弧なしの表記は型適用ではなく、E093 にはなりません。

## 修正

宣言されたパラメーターごとに型を1つ書きます。メッセージは宣言（`Pair[T]`）を示します。パラメーターなしの型なら角括弧を外します。

```almide
type Pair[T] = (T, T)

fn first(p: Pair[Int]) -> Int = p.0
```

正しい個数の引数を適用したジェネリックな透過的別名は、各引数を代入した本体です（`Pair[Int]` は `(Int, Int)`）。非ジェネリック別名がその本体であるのと同様です。`docs/specs/language.md` の「Type Alias」を参照してください。

## Fix-it 判定

**not-fixable** — どの引数が余分か、不足する引数をどのパラメーターに与えたかったかは作者の意図です。メッセージは宣言されたパラメーターを示し、注釈を書き換えません。
