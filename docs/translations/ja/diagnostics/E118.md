# E118 — メディア型の所有者が未許可、一意でない、または型がリテラルでない

[English](../../../diagnostics/E118.md) | [日本語](../../ja/diagnostics/E118.md) | [简体中文](../../zh-CN/diagnostics/E118.md)

> 原文：[`docs/diagnostics/E118.md`](https://github.com/almide/almide/blob/9a95b28519b90ae535dc9918bfed04805dc4675c/docs/diagnostics/E118.md)、固定コミット `9a95b285`。読者向けの非規範的な翻訳であり、CLI の診断出力は英語のまま。

`Body` 型は、そのレスポンスを配信する Content-Type を示す（ADR-0032）。型は `@media_owns(...)` によってメディア型を所有でき、`http.typed` がバイト列にその型のラベルを付けることを防ぐ。ブラウザーがスクリプトを実行する型、すなわち `stdlib/html.almd` が `@script_capable` と宣言するパターン（HTML、XHTML、SVG、XML）を所有することは、ユーザーにスクリプトを提示する権限であるため、検査される（D7）。

- スクリプト実行可能な型を所有する依存パッケージは、ルートの `almide.toml` が、そのパッケージにソース指定で当該型を許可した場合にだけビルドできる。

  ```toml
  [trust]
  media = { "almide/svg" = ["image/svg+xml"] }
  ```

- パッケージが宣言していない型への許可、または依存関係にないパッケージへの許可は拒否される。
- 標準ライブラリ、依存パッケージ、アプリケーションの2つの所有者のパターンが同じメディア型を指し得る場合は拒否する。これにより型の所有者は1つになる。
- `Body` 型の media fn は文字列リテラルであり、スクリプト実行可能なものは、その fn 自身の `@media_owns` が対象としていなければならない。したがって、型は許可されたものだけを配信する。

アプリケーション自身の型には許可は不要である（開発者が書いたものだから）。それらも他の所有者とともに `almide deps` で一覧表示される。

```almide
type Chart: Body = { markup: String }

fn Chart.media_type(self) -> String = "image/svg+xml"   // ← E118
```

```
error[E118]: `Chart.media_type` serves `image/svg+xml`, which runs script in a browser, without owning it
```

```
error[E118]: dependency `svg` (almide/svg) owns `image/svg+xml`, which runs script in a browser, and ./almide.toml does not grant it
```

## 修正

media fn の `@media_owns(...)` で型が配信するものを宣言し、メディア型をリテラルで書く。スクリプト実行可能な型を所有する依存パッケージには、その型を安全に構築すると信頼できる場合に限り、`[trust] media` で許可を与える。HTML は `html.*` のものであり、そのビルダーでページを構築する。

## Fix-it 判定

**not-fixable**：パッケージにスクリプト配信の権利を与えることは、信頼に関する判断である。（`mechanical` = 無人の修正ツールが書き換えを適用できる。`conditional` = 提案された修正はレビューが必要。`not-fixable` = 自動書き換えが存在しない。#1486 の適用可能性の原則。）
