# E087 — scoped 領域で許可されない操作

[English](../../../diagnostics/E087.md) | [日本語](../../ja/diagnostics/E087.md) | [简体中文](../../zh-CN/diagnostics/E087.md)

> 原文：[`docs/diagnostics/E087.md`](https://github.com/almide/almide/blob/9a95b28519b90ae535dc9918bfed04805dc4675c/docs/diagnostics/E087.md)、固定コミット `9a95b285`。読者向けの非規範的な翻訳であり、CLI の診断出力は英語のまま。

`scoped { … }` ブロック内または `scoped fn` 本体内では、認められた部分集合だけが実行される（docs/specs/scoped.md）。E087 は構文を名指しし、allocation 領域外に何を保持し得るかと、その規則を要求した宣言を示す。

```
error[E087]: `cache.remember` is not permitted in a scoped function
  = may retain `tree` outside the allocation region (a call across the module boundary)
  = required by the `scoped` declaration of `count`
  hint: compute with scalar operators and `scoped fn` helpers inside the scope
```

拒否対象：`scoped` を宣言していない呼び出し先、モジュールレベルの束縛（global）、ホスト資源（`println`、`effect fn`）、未知の間接呼び出し（lambda、関数値、値へのメソッド呼び出し）、ブロック外からキャプチャしたヒープ値、部分集合外の型（`String`、`List`、`Map`、Result）、領域を早期に離れる制御転送（`!`、`?`、`guard`）。

```almide check-fail=E087
type Tree = Leaf | Node(Tree, Tree)

scoped fn make(depth: Int) -> Tree =
  if depth == 0 then Leaf else Node(make(depth - 1), make(depth - 1))

fn remember(t: Tree) -> Int = 1

scoped fn summarize(depth: Int) -> Int = remember(make(depth))

effect fn main() -> Unit = println(int.to_string(scoped { summarize(2) }))
```

## 修正

呼び出し先を `scoped` と宣言する（本体も同じ規則で検査される）か、スコープ内で処理し、スカラーを外へ出す。

```almide check
type Tree = Leaf | Node(Tree, Tree)

scoped fn make(depth: Int) -> Tree =
  if depth == 0 then Leaf else Node(make(depth - 1), make(depth - 1))

scoped fn remember(t: Tree) -> Int =
  match t {
    Leaf => 1,
    Node(l, r) => remember(l) + remember(r),
  }

scoped fn summarize(depth: Int) -> Int = remember(make(depth))

effect fn main() -> Unit = println(int.to_string(scoped { summarize(2) }))
```

global はブロック外で読み、値をパラメーターとして渡す。出力は値を返し、スコープの後で表示する。

## Fix-it 判定

**conditional** — ヒントは許される形（呼び出し先を `scoped` と宣言する、値を渡す、エフェクトを外へ移す）を示すが、どれに当たるかはコードの目的に依存する。
