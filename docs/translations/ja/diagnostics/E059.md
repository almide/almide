# E059 — 反復できない for の対象

[English](../../../diagnostics/E059.md) | [日本語](./E059.md) | [简体中文](../../zh-CN/diagnostics/E059.md)

> 原文: [E059.md @ 9a95b285](https://github.com/almide/almide/blob/9a95b28519b90ae535dc9918bfed04805dc4675c/docs/diagnostics/E059.md)。これは読者向けの非規範的な翻訳です。CLI に埋め込まれる診断解説は英語原文のままです。

コレクションではない値を対象にした `for` ループです。

```
error[E059]: `for` cannot iterate `Int` — the loop head must be a List or a Map
```

```almide
fn main() -> Unit = {
  for x in 5 { println(int.to_string(x)) }   // ← E059: 5 is one Int, not a sequence
}
```

この規則以前、ループの対象は `Unknown` として推論をすり抜け、コード生成時に COMPILER BUG の表示付きで失敗していました（#1521）。check は成功して build は失敗する、受理の一致に関する問題です。

反復できる対象は `List`（`for x in xs`）、範囲（`for i in 0...n` — 範囲はリストとして実体化されます）、`Map`（`for (k, v) in m`、タプル分解）です。

この例の修正は範囲を使うことです。

```almide
fn main() -> Unit = {
  for x in 0...5 { println(int.to_string(x)) }
}
```

## Fix-it 判定

**not-fixable** — このエラーは、自動書き換えでは判断できない意味上／設計上の問題を示します。（`mechanical` = 無人の修正ツールが書き換えを適用可能、`conditional` = 提案された修正にレビューが必要、`not-fixable` = 自動書き換えは存在しません。#1486 の適用可能性の原則。）
