# E053 — 未知の属性

[English](../../../diagnostics/E053.md) | [日本語](./E053.md) | [简体中文](../../zh-CN/diagnostics/E053.md)

> 原文: [E053.md @ 9a95b285](https://github.com/almide/almide/blob/9a95b28519b90ae535dc9918bfed04805dc4675c/docs/diagnostics/E053.md)。これは読者向けの非規範的な翻訳です。CLI に埋め込まれる診断解説は英語原文のままです。

コンパイラが読み取らない属性名です。属性は構文解析されますが、その後は何も起こりません。

```almide
@deprecatd(since = 3, use = "shout")   // ← E053: one transposed letter
fn yell(s: String) -> String = shout(s)
```

この警告ができる以前は、この行は問題なくコンパイルされ、誰にも何も伝えませんでした。作者が非推奨化は有効だと考えている間も、`yell` のすべての呼び出し元に警告が出ませんでした。架空の属性にも同じことが当てはまりました。`@inline`、`@cache`、`@unsafe` はすべて受け入れられ、何も作用しませんでした。

## 語彙

コンパイラが読み取る名前は、`crates/almide-frontend/src/attr_vocab.rs` の `KNOWN_ATTRS` という1つの一覧にあります。

ここに複製した一覧ではなく、そのレジストリーで現在の完全な語彙を確認してください。フィールド属性には、後述する独自の小さなレジストリーがあります。

近い綴りなら候補を提示し、どれとも大きく違う名前なら一覧全体を提示します。誤った候補は正しい指示のように読めてしまうためです。

## 宣言されているが読み取られない属性

2つ目の一覧 `DECLARED_BUT_UNREAD` は、文法が受け入れるものの**まだどのコードも読まない**属性を記録します。コーパスにすでに含まれるため警告は出しませんが、既知の集合に黙って混ぜず明記しています。「受け入れられるが作用しない」状態を、誤って放置できないようにすることこそ、この診断の目的だからです。

現在この一覧は空です。`@rewrite` は最初のコーパス実行から almide#1450 で記録が訂正されるまでここにありました。この属性はビルド時の2つの生成器（egg の融合規則とコード生成の脱糖フォールバック。両方とも `stdlib/matrix.almd` を対象）が読んでおり、AST の利用箇所を grep するだけでは見つからなかったのです。

## エラーではなく警告である理由

即座に拒否すると、古いツールの属性を含むファイルが壊れます。現在は適切に行う仕組みがあります。将来の dialect epoch で E053 をエラーへ昇格し、[`proofs/dialect-epochs.toml`](../../../../proofs/dialect-epochs.toml) に破壊的変更を記録し、[E052](../../../diagnostics/E052.md) で各呼び出し元に何を書くべきか伝えます。この警告はその第一歩であり、永久に留まる場所ではありません。

## レコードのフィールドではエラー（#4108、epoch 15）

レコードフィールドには同じファイル内の `KNOWN_FIELD_ATTRS` という、より小さな独自の語彙があります。`@builtin` と `@location`（WGSL ステージ I/O）、`@skip` / `@skip_decode`（Codec のフィールドスキップ系）です。それ以外のフィールド属性は警告ではなく**エラー**です。この位置で読み取られない属性があると、作者は保護されていないフィールドを保護されていると考えてしまいます。

```almide
type User: Codec = { name: String, @serde(skip) is_admin: Bool = false }   // ← E053 (error)
```

epoch 15 より前はこれが問題なくコンパイルされ、`User.decode` はリクエスト本体から `is_admin` を設定し続けていました。他のエコシステムの表記には、対応する Almide 表記をヒントで示します。`@serde(skip)`、`@json_ignore`、`@transient`、`@ignore` → `@skip`、`@skip_deserializing`、`@readonly`、`@read_only` → `@skip_decode`、`@redact`、`@sensitive`、`@secret` → 型 `Secret[String]`（`import secret`）。フィクスチャ：`tests/diagnostics/e053-unknown-field-attribute-*`。

## 既知の属性の不正な引数

既知の属性でも、引数をコンパイラが読めない場合は同じコードで**エラー**になります。警告ではありません（#1518）。`use =` も `note =` もない `@deprecated(since = 2)` は以前、暗黙に捨てられていました。そのため、作者が呼び出し元に情報を伝えていると思っても、非推奨化は登録されませんでした。読めない非推奨指定は指定なしより悪い状態です。作者は古い名前を持ち込んでいるのではなく、動作を要求しているため、上記の互換性の理由は当てはまりません。

```almide
@deprecated(since = 2)                       // ← E053 (error): no use=, no note=
@deprecated(since = 2, use = "new_api")      // registers
@deprecated(since = 2, note = "unsound")     // registers
```
