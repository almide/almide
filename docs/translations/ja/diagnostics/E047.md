# E047 — 文字列リテラル内の不正なエスケープ

[English](../../../diagnostics/E047.md) | [日本語](../../ja/diagnostics/E047.md) | [简体中文](../../zh-CN/diagnostics/E047.md)

> 原文：[`docs/diagnostics/E047.md`](https://github.com/almide/almide/blob/9a95b28519b90ae535dc9918bfed04805dc4675c/docs/diagnostics/E047.md)、固定コミット `9a95b285`。読者向けの非規範的な翻訳であり、CLI の診断出力は英語のまま。

文字列リテラル中の `\` はエスケープの開始。Almide が定義するものは次のとおり。

| エスケープ | 使用場所 | 意味 |
|---|---|---|
| `\n` `\t` `\r` | `"…"` `'…'` `"""…"""` | 改行、タブ、復帰 |
| `\\` | すべて | リテラルのバックスラッシュ一つ |
| `\"` | `"…"` `"""…"""` | 二重引用符 |
| `\'` | `'…'` | 単一引用符 |
| `\$` | `"…"` `"""…"""` | リテラルの `$`（`${…}` の穴を抑制） |
| `\xNN` | すべて | `0x00..0xFF` 内のコードポイント。16 進数字ちょうど二桁 |
| `\u{…}` | すべて | 任意の Unicode スカラー値。16 進数字一〜六桁 |

それ以外は E047。raw 文字列（`r"…"`、`r"""…"""`）にはエスケープ層自体がなく、`r"\q"` はバックスラッシュと q であり、E047 を報告しない。

```almide
let a = "bad:\q"          // ← E047: unknown escape sequence `\q`
let b = "bad:\u{110000}"  // ← E047: `\u{110000}` is not a Unicode scalar value
```

以前は両方とも `almide check` を黙って通過し、綴りそのものを値としていた。`"bad:\q"` は六文字 `b a d : \ q`、`"\u{110000}"` は十文字のソーステキストだった。これは整数リテラルについて E024 が禁止する暗黙の再解釈と同じである。表記どおりの値でないリテラルは、コンパイラがそのまま通すのではなく、問題として示すべきものである。

## 修正

**未知のエスケープ** — バックスラッシュをエスケープするか、意図したエスケープを使う。

```almide
let path = "C:\\Users"    // a literal backslash is \\
let tab  = "col1\tcol2"   // \t, not \T
```

正規表現パターンは通常の文字列なので、正規表現のクラスはバックスラッシュを二重に書くか、二重化が不要な raw 文字列を使う。

```almide
regex.find(regex.new("\\d+"), s)     // the regex \d+
regex.find(regex.new(r"\d+"), s)     // same, no doubling
```

ここで `regex.new` はパターンを、`find` が受け取る Regex 値にコンパイルする。

**範囲外のコードポイント** — Unicode スカラー値の範囲は `U+0000..U+D7FF` と `U+E000..U+10FFFF`。サロゲート範囲 `D800..DFFF` は UTF-16 符号化上のもので、文字を表さない。`U+10FFFF` より大きいものは存在しない。

```almide
let ok  = "\u{10FFFF}"    // the highest codepoint there is
let nul = "\u{0}"         // NUL — `\0` is not an Almide escape
```

## Fix-it 判定

**not-fixable** — 自動書き換えでは判断できない意味・設計上の問題を報告している。（`mechanical` = 無人の修正ツールが書き換えを適用できる。`conditional` = 提案された修正はレビューが必要。`not-fixable` = 自動書き換えが存在しない。#1486 の適用可能性の原則。）
