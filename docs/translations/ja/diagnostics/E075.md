# E075 — 実行時長でのヒープ構築は不可

[English](../../../diagnostics/E075.md) | [日本語](../../ja/diagnostics/E075.md) | [简体中文](../../zh-CN/diagnostics/E075.md)

> 原文：[`docs/diagnostics/E075.md`](https://github.com/almide/almide/blob/9a95b28519b90ae535dc9918bfed04805dc4675c/docs/diagnostics/E075.md)、固定コミット `9a95b285`。読者向けの非規範的な翻訳であり、CLI の診断出力は英語のまま。

`@bounded` 属性（ALS §B、bounded プロファイル）は、属性を付けた関数内でチェッカーが受理する範囲を制限する。時間と記憶領域が静的に有界であること、閉じた非循環の呼び出しグラフ、ケイパビリティで制限されたエフェクトである。E075 は、`@bounded` 関数内で、長さが実行時の値となるヒープ構築（`string.repeat(s, n)`、`list.with_capacity(n)`、および同種の関数）を拒否する。

```
error[E075]: ... is not admissible in a @bounded function
```

```almide check-fail=E075
@bounded
fn pad(n: Int) -> String = string.repeat("x", n)

fn main() -> Unit = println("bounded")
```

## 修正

構築する長さをすべてコンパイル時のサイズにする。リテラル、またはリテラルに束縛された `let` を使う。

```almide
@bounded
fn pad3() -> String = string.repeat("x", 3)

fn main() -> Unit = println("bounded")
```

この規則が適用されるのは `@bounded` 関数の内部だけであり、属性を取り除くと、この拒否もなくなる（プロファイルはサブセットであって方言ではない：ALS-B2）。

## Fix-it 判定

**conditional** — 診断のヒントは許容される形式を示す。拒否された形式をどの表記に置き換えるかは、そのコードが何をしていたかによる。
