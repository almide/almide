# E117 — `http.typed` は安全なモジュールが所有しないリテラルのメディア型を受け取る

[English](../../../diagnostics/E117.md) | [日本語](../../ja/diagnostics/E117.md) | [简体中文](../../zh-CN/diagnostics/E117.md)

> 原文：[`docs/diagnostics/E117.md`](https://github.com/almide/almide/blob/9a95b28519b90ae535dc9918bfed04805dc4675c/docs/diagnostics/E117.md)、固定コミット `9a95b285`。読者向けの非規範的な翻訳であり、CLI の診断出力は英語のまま。

`http.typed(media_type, bytes)` は、宣言したメディア型のレスポンス本体を構築する（ADR-0032）。メディア型はここで読むため、文字列リテラルであり、正しい形式の `type/subtype`（`;` の後にパラメーター）であり、ブラウザーがスクリプトを実行する型であってはならない。それらは `stdlib/html.almd` が `@script_capable` と宣言するパターン、すなわち `text/html` と XHTML（`html` が所有）、`image/svg+xml`（アプリケーションの `[trust]
media` 許可のもとで almide/svg などのパッケージが所有）、すべての `*/xml` と `+xml` サブタイプ（所有者はまだない、#4310）である。また、標準ライブラリが `@media_owns(…)` で所有する型も不可である。`http.typed` を値として名前で指定しても E117 となる。

```almide
import http

fn page(s: String) -> HttpResponse =
  http.response(200, http.typed("text/html", bytes.from_string(s)))   // ← E117
```

```
error[E117]: `http.typed`: `text/html` runs script in a browser and is owned by `html`: build the body with the `html` builders, whose type serves it
```

## 修正

```almide
import html
import http

fn page(s: String) -> HttpResponse = http.response(200, html.escape(s))
```

実行時に型を選ぶプログラムは、選択する場所で型をそれぞれ明記する：`match ext { "css" => http.typed("text/css", b), … }`。

## 理由

チェッカーが判定できる引数はリテラルだけである。ここで判定することで、実行時にはメディア型リストが存在しない。所有される集合は、安全なモジュールの宣言を合わせたものである。

## Fix-it 判定

**not-fixable**：ページに必要なビルダーや、プログラムが配信するリテラル型は、プログラムに関する判断である。（`mechanical` = 無人の修正ツールが書き換えを適用できる。`conditional` = 提案された修正はレビューが必要。`not-fixable` = 自動書き換えが存在しない。#1486 の適用可能性の原則。）
