# E007 — effect fn の外にある `fan` ブロック

[English](../../../diagnostics/E007.md) | [日本語](./E007.md) | [简体中文](../../zh-CN/diagnostics/E007.md)

> 原文: [E007.md @ 9a95b285](https://github.com/almide/almide/blob/9a95b28519b90ae535dc9918bfed04805dc4675c/docs/diagnostics/E007.md)。これは読者向けの非規範的な翻訳です。CLI に埋め込まれる診断解説は英語原文のままです。

`fan { ... }`（並行実行ブロック）は `effect fn` 内でのみ使用できます。並行処理はエフェクトです。

## よくある例

```almide
fn parallel_work() -> Int = fan { a; b; c }    // E007: fan in pure fn
```

## 診断

```
error[E007]: fan block can only be used inside an effect fn
  hint: Mark the enclosing function as `effect fn`
```

## 修正

- 外側の関数を `effect fn` にします。
  ```almide
  effect fn parallel_work() -> Int = fan { a; b; c }
  ```

## 理由

`fan` は分岐を並行実行し、結果を集約します。タイミング、スケジューリング、分岐内の I/O は観測可能なエフェクトです。`fan` を `effect fn` 内に限定することでエフェクトの境界を正しく保ちます。純粋な `fn` のシグネチャは「観測可能な順序や I/O への依存がない」ことを意味する必要があります。
