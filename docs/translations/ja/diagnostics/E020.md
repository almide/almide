# E020 — 型宣言の競合

[English](../../../diagnostics/E020.md) | [日本語](../../ja/diagnostics/E020.md) | [简体中文](../../zh-CN/diagnostics/E020.md)

> 原文：[`docs/diagnostics/E020.md`](https://github.com/almide/almide/blob/9a95b28519b90ae535dc9918bfed04805dc4675c/docs/diagnostics/E020.md)、固定コミット `9a95b285`。読者向けの非規範的な翻訳であり、CLI の診断出力は英語のまま。

チェッカーが、一つのモジュール内で同一の型識別子に対する競合する宣言を検出した。異なるパッケージは同名の別個の型を所有できる。canonicalizer が識別子を修飾し、ローカル型は import された単独名を隠せるが、その import された型を再定義することにはならない。

## よくある例

```almide
type Config = { name: String }
type Config = { host: String, port: Int }   // E020: 'Config' declared more than once

fn main() -> Unit = println("ok")
```

## 修正

重複宣言を削除するか、別の型を意図している場合はモジュール内の一方の型を改名する。

```almide
type AppConfig = { name: String }
type DepConfig = { host: String, port: Int }

fn main() -> Unit = println("ok")
```

## Fix-it 判定

**not-fixable** — 自動書き換えでは判断できない意味・設計上の問題を報告している。（`mechanical` = 無人の修正ツールが書き換えを適用できる。`conditional` = 提案された修正はレビューが必要。`not-fixable` = 自動書き換えが存在しない。#1486 の適用可能性の原則。）
