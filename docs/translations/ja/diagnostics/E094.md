# E094 — 型別名が循環している

[English](../../../diagnostics/E094.md) | [日本語](./E094.md) | [简体中文](../../zh-CN/diagnostics/E094.md)

> 原文: [E094.md @ 9a95b285](https://github.com/almide/almide/blob/9a95b28519b90ae535dc9918bfed04805dc4675c/docs/diagnostics/E094.md)。これは読者向けの非規範的な翻訳です。CLI に埋め込まれる診断解説は英語原文のままです。

型別名は本体の別の名前です。`type Coord = Pos` は `Pos` と同じ意味になります。直接、他の別名経由、または型引数経由で自身へ戻る別名には、表すべき本体がないため、型を表しません。以前はこれが `almide check` を黙って通る（`type Tree = List[Tree]`）か、不透明な名前として残り、すべての使用箇所が無関係なエラーで拒否されていました。E094 は循環中で最初に宣言された別名で循環を報告します。

```almide
type Coord = Pos

type Pos = Coord                  // ← E094: type aliases form a cycle: Coord → Pos → Coord
```

型引数を介した循環も循環です。

```almide
type Tree = List[Tree]            // ← E094: type alias 'Tree' refers to itself (Tree → Tree)
```

宣言順は循環ではありません。後ろで宣言する型を別名にできます（`type Pair2 = (Int, Int)` より前に `type First = Pair2` を置く場合）。

## 修正

いずれかの別名に、元へ戻らない本体を与えます。または再帰型を名目的な型にします。レコードやバリアントは自身を参照できます。

```almide
type Tree = { kids: List[Tree] }

fn size(t: Tree) -> Int = list.len(t.kids)
```

## Fix-it 判定

**not-fixable** — 循環に必要なのがレコードか、バリアントか、別の本体かは作者の意図です。メッセージは循環に含まれる別名を示します。
