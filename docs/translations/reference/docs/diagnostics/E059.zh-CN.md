# E059 — for 的迭代对象不可迭代

[![English](https://img.shields.io/badge/English-d0d7de?style=flat-square)](E059.md) [![日本語](https://img.shields.io/badge/%E6%97%A5%E6%9C%AC%E8%AA%9E-d0d7de?style=flat-square)](E059.ja.md) [![简体中文](https://img.shields.io/badge/%E7%AE%80%E4%BD%93%E4%B8%AD%E6%96%87-24292f?style=flat-square)](E059.zh-CN.md)



> 原文：[E059.md @ 9a95b285](https://github.com/almide/almide/blob/9a95b28519b90ae535dc9918bfed04805dc4675c/docs/diagnostics/E059.md)。这是供读者参考的非规范性翻译。CLI 内嵌的诊断说明仍使用英文原文。

对不是集合的值使用 `for` 循环：

```
error[E059]: `for` cannot iterate `Int` — the loop head must be a List or a Map
```

```almide
fn main() -> Unit = {
  for x in 5 { println(int.to_string(x)) }   // ← E059: 5 is one Int, not a sequence
}
```

在此规则之前，循环头会以 `Unknown` 穿过推断，直到代码生成时才以 COMPILER BUG 标志报告失败（#1521）——check 成功、build 失败，属于接受一致性问题。

可迭代的对象包括 `List`（`for x in xs`）、范围（`for i in 0...n`——范围会具体化为列表），以及 `Map`（`for (k, v) in m`，元组解构）。

此处的修复是使用范围：

```almide
fn main() -> Unit = {
  for x in 0...5 { println(int.to_string(x)) }
}
```

<a id="fix-it-verdict"></a>

## Fix-it 判定

**not-fixable** — 此错误报告的是自动重写无法决定的语义／设计问题。（`mechanical` = 无人值守的修复器可以应用重写；`conditional` = 建议的修复需要审查；`not-fixable` = 不存在自动重写。遵循 #1486 的适用性原则。）
