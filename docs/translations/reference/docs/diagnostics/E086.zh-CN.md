# E086 — 值将比其 scoped allocation 活得更久

[![English](https://img.shields.io/badge/English-d0d7de?style=flat-square)](E086.md) [![日本語](https://img.shields.io/badge/%E6%97%A5%E6%9C%AC%E8%AA%9E-d0d7de?style=flat-square)](E086.ja.md) [![简体中文](https://img.shields.io/badge/%E7%AE%80%E4%BD%93%E4%B8%AD%E6%96%87-24292f?style=flat-square)](E086.zh-CN.md)



> 原文：[`docs/diagnostics/E086.md`](https://github.com/almide/almide/blob/9a95b28519b90ae535dc9918bfed04805dc4675c/docs/diagnostics/E086.md)，固定提交 `9a95b285`。这是面向读者的非规范性译文；CLI 诊断输出仍为英语。

`scoped { … }` 块声明其存储结束的位置。E086 拒绝在块内构建的值仍需在块后使用的程序：包括块本身的值，以及写入块外声明的绑定。

```
error[E086]: `tree` would outlive its scoped allocation
  = allocated at analysis.almd:8:16
  = scope ends at analysis.almd:10:3
  hint: compute and return the scalar summary inside the scope
```

`allocated at` 行指出值构建的位置（块值是名称时，为绑定它的 `let`），`scope ends at` 指出结束大括号。两者都是读者定位错误所需的事实；`hint:` 行给出唯一操作。

```almide check-fail=E086
type Tree = Leaf | Node(Tree, Tree)

scoped fn make(depth: Int) -> Tree =
  if depth == 0 then Leaf else Node(make(depth - 1), make(depth - 1))

fn analysis(depth: Int) -> Tree =
  scoped {
    let tree = make(depth)
    tree
  }

effect fn main() -> Unit = println("${analysis(2)}")
```

<a id="the-fix"></a>

## 修复

在作用域内计算摘要，让标量跨越边界。

```almide check
type Tree = Leaf | Node(Tree, Tree)

scoped fn make(depth: Int) -> Tree =
  if depth == 0 then Leaf else Node(make(depth - 1), make(depth - 1))

scoped fn count(t: Tree) -> Int =
  match t {
    Leaf => 1,
    Node(l, r) => 1 + count(l) + count(r),
  }

fn analysis(depth: Int) -> Int =
  scoped {
    let tree = make(depth)
    count(tree)
  }

effect fn main() -> Unit = println(int.to_string(analysis(2)))
```

写入外部绑定是同一规则的另一面：将写入设为块的值（`total = scoped { … }`），而不是从块内写出。

stage 1 允许跨越边界的类型为 `Int`、`Float`、`Bool`、`Unit`。`String` 和 `T!` 会被拒绝，而不是静默复制。设计中的 detach 规则（由已分离字节构建的新 String 可以离开）尚未在 structural wasm 路径实现；只有一条路径遵守的规则比拒绝更糟（docs/specs/scoped.md）。

<a id="fix-it-verdict"></a>

## Fix-it 判定

**conditional** — 应跨越边界的摘要由作者选择；编译器指出值与边界，绝不擅自创造 fold。
