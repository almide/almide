# E117 — `http.typed` takes a literal media type no safe module owns

[![English](https://img.shields.io/badge/English-24292f?style=flat-square)](E117.md) [![日本語](https://img.shields.io/badge/%E6%97%A5%E6%9C%AC%E8%AA%9E-d0d7de?style=flat-square)](E117.ja.md) [![简体中文](https://img.shields.io/badge/%E7%AE%80%E4%BD%93%E4%B8%AD%E6%96%87-d0d7de?style=flat-square)](E117.zh-CN.md)

`http.typed(media_type, bytes)` builds a response body of a declared media
type (ADR-0032). The media type is read here, so it must be a string literal,
a well-formed `type/subtype` (parameters after `;`), and not a type a
browser runs script in, the patterns `stdlib/html.almd` declares
`@script_capable` — `text/html` and XHTML (owned by `html`), `image/svg+xml`
(owned by a package such as almide/svg under the application's `[trust]
media` grant), every `*/xml` and `+xml` subtype (no owner yet, #4310) — nor a
type the stdlib owns with `@media_owns(…)`. Naming `http.typed` as a value is
E117 too.

```almide
import http

fn page(s: String) -> HttpResponse =
  http.response(200, http.typed("text/html", bytes.from_string(s)))   // ← E117
```

```
error[E117]: `http.typed`: `text/html` runs script in a browser and is owned by `html`: build the body with the `html` builders, whose type serves it
```

## Fix

```almide
import html
import http

fn page(s: String) -> HttpResponse = http.response(200, html.escape(s))
```

A program that chooses the type at run time writes each one where it is
chosen: `match ext { "css" => http.typed("text/css", b), … }`.

## Why

A literal is the only argument the checker can judge, and judging it here
means no media-type list exists at run time: the owned set is the union of
the safe modules' declarations.

## Fix-it verdict

**not-fixable**: which builder a page needs, or which literal types a program
serves, is a decision about the program. (`mechanical` = an unattended fixer
may apply the rewrite; `conditional` = a suggested fix needs review;
`not-fixable` = no automatic rewrite exists. #1486's applicability doctrine.)
