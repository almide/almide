# E114 — ジェネリック fn が拡大する型で自分自身に到達する

[![English](https://img.shields.io/badge/English-d0d7de?style=flat-square)](E114.md) [![日本語](https://img.shields.io/badge/%E6%97%A5%E6%9C%AC%E8%AA%9E-24292f?style=flat-square)](E114.ja.md) [![简体中文](https://img.shields.io/badge/%E7%AE%80%E4%BD%93%E4%B8%AD%E6%96%87-d0d7de?style=flat-square)](E114.zh-CN.md)



> 原文：[`docs/diagnostics/E114.md`](https://github.com/almide/almide/blob/9a95b28519b90ae535dc9918bfed04805dc4675c/docs/diagnostics/E114.md)、固定コミット `9a95b285`。読者向けの非規範的な翻訳であり、CLI の診断出力は英語のまま。

ジェネリック fn は、呼び出される型ごとに1回コンパイルされる。自身の型パラメーターから構築した型で、直接または他のジェネリック fn を通じて自身を呼ぶ fn には、再帰の各段階で新しいインスタンスが必要となり、最後のインスタンスが存在しない（#4287）。

```almide
fn depth[T: Hash](x: T, n: Int) -> Int =
  if n <= 0 then 0 else 1 + depth((x, x), n - 1)   // ← E114
```

```
error[E114]: `depth` calls itself at a growing type: its `T` is `(T, T)` at this call
  hint: A generic fn is compiled once for each type it is called at, so a recursion whose type grows with every call needs an instance for every level and never ends. Recurse at the type `depth` was called with: collect the values in a `List[T]`, or count the levels in an `Int`.
```

同じコードは、複数の fn を経由する循環にも適用する（`wrap[T]` が `unwrap([x])` を呼び、`unwrap[U]` が `wrap(y)` を呼ぶ）。メッセージは循環が通る fn を示す。

同じ型での再帰は通過し、型パラメーターの名前を変えるだけ、または交換するだけの循環（`f[A, B]` が `f(b, a)` を呼ぶ）も通過する。必要なインスタンス数が有限だからである。

<a id="fix"></a>

## 修正

その fn が呼び出されたときの型で再帰する。

```almide
fn depth[T: Hash](xs: List[T], n: Int) -> Int =
  if n <= 0 then 0 else 1 + depth(xs + xs, n - 1)
```

<a id="why"></a>

## 理由

この検査の導入前は、プログラムが `almide check` を通過し、単相化が1つのインスタンスを作り、その内部に誤った型の自己呼び出しを残していた。最初のエラーはバックエンドから発生し、`--target wasm` なら E082、ネイティブなら rustc の E0308 だった。規則は拡大型循環の検査である。ジェネリック呼び出しの循環で型パラメーターがどこかの辺で大きくなる場合は拒否し、パラメーターを変更せず渡す循環は拒否しない。

フィクスチャ：`tests/diagnostics/e114-self-recursion-at-growing-type`、`e114-mutual-recursion-at-growing-type`、`e114-cycle-grows-through-option`。

<a id="fix-it-verdict"></a>

## Fix-it 判定

**not-fixable**：再帰に代わりに何を持たせるかは、プログラムに関する判断である。（`mechanical` = 無人の修正ツールが書き換えを適用できる。`conditional` = 提案された修正はレビューが必要。`not-fixable` = 自動書き換えが存在しない。#1486 の適用可能性の原則。）
