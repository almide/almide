# E077 — bounded 配置内不得进行 Float 运算（暂定）

`@bounded` 属性（ALS §B，bounded 配置）限制检查器在标注函数内允许的内容：静态有界的时间与存储、封闭无环的调用图、受能力约束的 effect。E077 拒绝 `@bounded` 函数内的 Float 运算符（算术或比较），或对 Float 实参进行计算的标准库调用。

```
error[E077]: ... is not admissible in a @bounded function
```

```almide check-fail=E077
@bounded
fn scale(x: Float) -> Float = x * 2.0

fn main() -> Unit = println("bounded")
```

## 修复

在该配置内只进行 Int 算术；可以保存和传递 Float 值，但不能对它们计算。在认证所针对的基座具备 Float 指令集之前，此规则是暂定的（ALS-B10）。

```almide
@bounded
fn scale_deci(x: Int) -> Int = x * 2

fn main() -> Unit = println("bounded")
```

此规则仅约束 `@bounded` 函数内部；移除属性就会取消这一拒绝（配置是子集而非方言：ALS-B2）。
