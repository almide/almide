# E072 — `@bounded` ループ内では `break`/`continue` 不可

[![English](https://img.shields.io/badge/English-d0d7de?style=flat-square)](E072.md) [![日本語](https://img.shields.io/badge/%E6%97%A5%E6%9C%AC%E8%AA%9E-24292f?style=flat-square)](E072.ja.md) [![简体中文](https://img.shields.io/badge/%E7%AE%80%E4%BD%93%E4%B8%AD%E6%96%87-d0d7de?style=flat-square)](E072.zh-CN.md)



> 原文：[`docs/diagnostics/E072.md`](https://github.com/almide/almide/blob/9a95b28519b90ae535dc9918bfed04805dc4675c/docs/diagnostics/E072.md)、固定コミット `9a95b285`。読者向けの非規範的な翻訳であり、CLI の診断出力は英語のまま。

`@bounded` 属性（ALS §B、bounded プロファイル）は、属性を付けた関数内でチェッカーが受理する範囲を制限する。時間と記憶領域が静的に有界であること、閉じた非循環の呼び出しグラフ、ケイパビリティで制限されたエフェクトである。E072 は、`@bounded` 関数の回数指定ループ本体からの早期脱出を拒否する。

```
error[E072]: ... is not admissible in a @bounded function
```

```almide check-fail=E072
@bounded
fn first_over(limit: Int) -> Int = {
  var found = 0
  for i in 0..<100 {
    if i * i > limit then break
    found = i
  }
  found
}

fn main() -> Unit = println("bounded")
```

<a id="the-fix"></a>

## 修正

回数指定ループの出口は1つである（MISRA の規律）。すべての反復を実行し、早期脱出の代わりに分岐で選択する。

```almide
@bounded
fn count_under(limit: Int) -> Int = {
  var found = 0
  for i in 0..<100 {
    found = if i * i > limit then found else i
  }
  found
}

fn main() -> Unit = println("bounded")
```

この規則が適用されるのは `@bounded` 関数の内部だけであり、属性を取り除くと、この拒否もなくなる（プロファイルはサブセットであって方言ではない：ALS-B2）。
