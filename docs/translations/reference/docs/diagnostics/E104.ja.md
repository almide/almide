# E104 — スキップするレコードフィールドに既定値がない

[![English](https://img.shields.io/badge/English-d0d7de?style=flat-square)](E104.md) [![日本語](https://img.shields.io/badge/%E6%97%A5%E6%9C%AC%E8%AA%9E-24292f?style=flat-square)](E104.ja.md) [![简体中文](https://img.shields.io/badge/%E7%AE%80%E4%BD%93%E4%B8%AD%E6%96%87-d0d7de?style=flat-square)](E104.zh-CN.md)



> 原文：[`docs/diagnostics/E104.md`](https://github.com/almide/almide/blob/9a95b28519b90ae535dc9918bfed04805dc4675c/docs/diagnostics/E104.md)、固定コミット `9a95b285`。読者向けの非規範的な翻訳であり、CLI の診断出力は英語のまま。

`@skip` と `@skip_decode` は、導出された `T.decode` の対象からフィールドを外す。入力がそのフィールドを設定することはない（#4108）。それでもデコーダーはレコードを構築する必要があるため、そのフィールドには使うべき既定値が必要である。

```almide
type User: Codec = { name: String, @skip_decode is_admin: Bool }   // ← E104
```

```
error[E104]: field 'is_admin' is `@skip_decode` but has no default
  hint: A skipped field is never read from input, so `T.decode` needs a value for it. Give it one: `@skip_decode is_admin: <Type> = <default>`.
```

## 修正

```almide
type User: Codec = { name: String, @skip_decode is_admin: Bool = false }
```

## 理由

serde（`#[serde(skip)]` には `Default` が必要）、kotlinx（`@Transient` には初期化子が必要）、Swift（`CodingKeys` から外したプロパティには初期値が必要）は、いずれも同じ宣言を拒否する。デコーダーが読み取れないフィールドは、どこかから値を得る必要があり、残る場所は宣言だけだからである。

この検査は Codec の有無を問わず、すべてのレコードフィールドに対して行う。この属性が意味を持つのは Codec の導出時だけだが、代替値のない skip はどこに書いても誤りである。フィクスチャ：`tests/diagnostics/e104-skip-without-default`。

## Fix-it 判定

**not-fixable**：正しい既定値はフィールドによる。（`mechanical` = 無人の修正ツールが書き換えを適用できる。`conditional` = 提案された修正はレビューが必要。`not-fixable` = 自動書き換えが存在しない。#1486 の適用可能性の原則。）
