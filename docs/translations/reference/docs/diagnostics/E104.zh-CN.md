# E104 — 跳过的记录字段没有默认值

[![English](https://img.shields.io/badge/English-d0d7de?style=flat-square)](E104.md) [![日本語](https://img.shields.io/badge/%E6%97%A5%E6%9C%AC%E8%AA%9E-d0d7de?style=flat-square)](E104.ja.md) [![简体中文](https://img.shields.io/badge/%E7%AE%80%E4%BD%93%E4%B8%AD%E6%96%87-24292f?style=flat-square)](E104.zh-CN.md)



> 原文：[`docs/diagnostics/E104.md`](https://github.com/almide/almide/blob/9a95b28519b90ae535dc9918bfed04805dc4675c/docs/diagnostics/E104.md)，固定提交 `9a95b285`。这是供读者参考的非规范性译文，CLI 诊断输出仍为英文。

`@skip` 和 `@skip_decode` 将字段排除在派生的 `T.decode` 之外，输入永远不能设置它（#4108）。解码器仍须构造记录，因此该字段需要可采用的默认值。

```almide
type User: Codec = { name: String, @skip_decode is_admin: Bool }   // ← E104
```

```
error[E104]: field 'is_admin' is `@skip_decode` but has no default
  hint: A skipped field is never read from input, so `T.decode` needs a value for it. Give it one: `@skip_decode is_admin: <Type> = <default>`.
```

<a id="fix"></a>

## 修复

```almide
type User: Codec = { name: String, @skip_decode is_admin: Bool = false }
```

<a id="why"></a>

## 原因

serde（`#[serde(skip)]` 需要 `Default`）、kotlinx（`@Transient` 需要初始化器）和 Swift（未列入 `CodingKeys` 的属性需要初始值）都会拒绝同一声明：解码器不能读取的字段必须从某处获得值，而剩下的唯一位置就是声明。

检查针对每个记录字段运行，无论是否有 Codec。该属性只对 Codec 派生有意义，但没有回退值的 skip 写在哪里都是错误。测试样例：`tests/diagnostics/e104-skip-without-default`。

<a id="fix-it-verdict"></a>

## Fix-it 判定

**not-fixable**：正确默认值取决于字段。（`mechanical` = 无人值守的修复工具可以应用改写；`conditional` = 建议的修复需要审查；`not-fixable` = 不存在自动改写。#1486 的适用性原则。）
