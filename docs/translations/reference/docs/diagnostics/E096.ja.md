# E096 — `mut` 引数を持つ fn を関数値として使う

[![English](https://img.shields.io/badge/English-d0d7de?style=flat-square)](E096.md) [![日本語](https://img.shields.io/badge/%E6%97%A5%E6%9C%AC%E8%AA%9E-24292f?style=flat-square)](E096.ja.md) [![简体中文](https://img.shields.io/badge/%E7%AE%80%E4%BD%93%E4%B8%AD%E6%96%87-d0d7de?style=flat-square)](E096.zh-CN.md)



> 原文: [E096.md @ 9a95b285](https://github.com/almide/almide/blob/9a95b28519b90ae535dc9918bfed04805dc4675c/docs/diagnostics/E096.md)。これは読者向けの非規範的な翻訳です。CLI に埋め込まれる診断解説は英語原文のままです。

`mut` 引数を宣言する fn は呼び出せますが、関数値にはできません。呼び出しではない単独の参照は拒否されます。`let`、別の fn への引数、レコードフィールド、リスト要素、戻り値が該当し、モジュール修飾された fn（`counter.bump`、`list.push`）も同様です。

`mut` 引数は呼び出し元の `var` へ書き戻します（C-226）。この約束は fn のシグネチャの一部ですが、関数型には置く場所がありません。`bump` の値は `(St) -> Unit` となり、それを介した呼び出しは `s` を通常の引数として渡します。このエラー以前、その呼び出しは wasm では書き込みを失い、ネイティブではビルドに失敗していました。

```almide
type St = { count: Int }

fn bump(mut s: St) -> Unit = {
  s.count = s.count + 1
}

effect fn main() -> Unit = {
  var s = St { count: 0 }
  let f = bump          // ← E096
  f(s)
  println(int.to_string(s.count))
}
```

<a id="diagnostic"></a>

## 診断

```
error[E096]: fn 'bump' has a `mut` parameter 's' and cannot be used as a function value
  in bump used as a value
  hint: A `mut` parameter writes back to the caller's `var`, and a function value cannot carry that. Call it directly (`bump(s)` with `var s`), or pass a lambda that names the `var` (`() => bump(s)`). If 'bump' only changes its own copy, drop `mut` from 's' and rebind it with `var` inside the body
```

エラーは参照を指します。ヒントの呼び出しと lambda は fn 自身の引数名を使います。`list.push` では `var xs` とともに `list.push(xs, x)`、および `(x) => list.push(xs, x)` と表示します。標準ライブラリ fn の `mut` は外せないため、最後の文は付けません。

参照が関数型の引数を埋める引数である場合（`list.map(groups, grow)`）、名前で指定できる呼び出し元の `var` はありません。各呼び出しは要素を受け取ります。この場合のヒントは、そのパラメーターの引数数に合い、自分で束縛する名前を使って、各 `mut` 引数をローカルの `var` にコピーする lambda を提案します。

```
error[E096]: fn 'grow' has a `mut` parameter 'xs' and cannot be used as a function value
  hint: A `mut` parameter writes back to the caller's `var`, and a function value cannot carry that. Pass a lambda that copies into a local `var`: `(item) => { var copy = item; grow(copy); copy }`. If 'grow' only changes its own copy, drop `mut` from 'xs' and return the new value
```

fn が `Unit` を返し、パラメーターが値を返すことを期待する場合（`list.map` の `(A) -> B`）、lambda はコピーで終わり、新しい値が結果になります。それ以外は呼び出しで終わります。2引数の場所で標準ライブラリ fn を使う `list.fold(xs, init, list.push)` には、`(a1, a2) => { var copy = a1; list.push(copy, a2); copy }` を提案します。

<a id="fix"></a>

## 修正

- 書き込みを反映したい場所で fn を直接呼びます。`var s` に対する `bump(s)` です。
- コールバック引数ではヒントの lambda を渡します。要素をローカルの `var` にコピーし、それを fn に渡して呼び、コピーを返します。
  ```almide
  let grown = list.map(groups, (item) => { var copy = item; grow(copy); copy })
  ```
- 関数値が必要な場所では、書き込み先の `var` を名前で指定する lambda を渡します。lambda が `s` をキャプチャするため、そこへ書き込まれます。
  ```almide
  let tick = () => bump(s)
  tick()
  ```
- fn が引数を自分の作業用コピーとしてだけ変更し、呼び出し元に書き戻す必要がないなら、その引数に `mut` は不要です。外して本体内で再束縛し、新しい値を返します。
  ```almide
  fn next(x: Int) -> Int = {
    var y = x
    y = y + 1
    y
  }
  ```
  `next` は通常の `(Int) -> Int` 値になります（`xs |> list.map(next)`）。

<a id="why"></a>

## 理由

参照渡しと関数値を両立する言語は、そのモードを関数型に入れます。Swift は `(inout Int) -> Void`、Rust は `fn(&mut i32)` と書きます。Almide の関数型にはそのモードがないため、値にすると書き込みを忘れなければなりません。Koka のローカル `var` は逆の方針で、他の関数へ一切渡せません。Almide は変換だけを拒否するので、直接呼び出しと `var` を名前で指定する lambda は意味を保ちます。
