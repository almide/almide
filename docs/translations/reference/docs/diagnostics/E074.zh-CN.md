# E074 — `@bounded` 调用 `@bounded`（或一阶纯标准库函数）

`@bounded` 属性（ALS §B，bounded 配置）限制检查器在标注函数内允许的内容：静态有界的时间与存储、封闭无环的调用图、受能力约束的 effect。E074 拒绝在 `@bounded` 函数中调用非 `@bounded` 的用户函数、创建或调用闭包，或进行高阶标准库调用。

```
error[E074]: ... is not admissible in a @bounded function
```

```almide check-fail=E074
fn helper(x: Int) -> Int = x + 1

@bounded
fn uses_plain(x: Int) -> Int = helper(x)

fn main() -> Unit = println("bounded")
```

## 修复

给被调用方标注 `@bounded`，或使用纯标准库模块的一阶成员。函数值是间接被调用方，该配置的静态调用图无法追踪。

```almide
@bounded
fn helper(x: Int) -> Int = x + 1

@bounded
fn uses_bounded(x: Int) -> Int = helper(x)

fn main() -> Unit = println("bounded")
```

此规则仅约束 `@bounded` 函数内部；移除属性就会取消这一拒绝（配置是子集而非方言：ALS-B2）。
