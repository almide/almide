# E012 — 定義の重複

[![English](https://img.shields.io/badge/English-d0d7de?style=flat-square)](E012.md) [![日本語](https://img.shields.io/badge/%E6%97%A5%E6%9C%AC%E8%AA%9E-24292f?style=flat-square)](E012.ja.md) [![简体中文](https://img.shields.io/badge/%E7%AE%80%E4%BD%93%E4%B8%AD%E6%96%87-d0d7de?style=flat-square)](E012.zh-CN.md)



> 原文：[`docs/diagnostics/E012.md`](https://github.com/almide/almide/blob/9a95b28519b90ae535dc9918bfed04805dc4675c/docs/diagnostics/E012.md)、固定コミット `9a95b285`。読者向けの非規範的な翻訳であり、CLI の診断出力は英語のまま。

モジュール内の二つの宣言（またはファイル内の二つの test ブロック）が同じ名前を持っている。各名前はそのスコープ内で一意でなければならない。

<a id="common-cases"></a>

## よくある例

```almide
fn greet(name: String) -> String = "hi ${name}"
fn greet(who: String) -> String = "hello ${who}"    // E012: duplicate fn
```

```almide
test "basic" { assert(1 == 1) }
test "basic" { assert(2 == 2) }                     // E012: duplicate test
```

<a id="diagnostic"></a>

## 診断

```
error[E012]: function 'greet' is defined twice in this module
  hint: Rename one of the definitions, or remove the earlier one. Almide requires each function name to be unique within a module.
```

補助の `note` が最初の定義を指し、両方の場所を確認できる。

<a id="fix"></a>

## 修正

- 実際の動作を表すように一方を改名する。
  ```almide
  fn greet(name: String) -> String = "hi ${name}"
  fn greet_formal(who: String) -> String = "hello ${who}"
  ```
- 一方が残存コードなら、古い方／不要になった方を削除する。
- テストの場合は、両アサーションを含む一つの `test` ブロックに統合するか、異なるケースを表す名前を付ける。
  ```almide
  test "basic — 1 equals 1" { assert(1 == 1) }
  test "basic — 2 equals 2" { assert(2 == 2) }
  ```

<a id="a-builtins-name"></a>

## 組み込み関数の名前

出力や中止の組み込み関数（`println`、`eprintln`、`panic`、`assert`、`assert_eq`、`assert_ne`）と同名のトップレベル `fn` または `let` も同じエラーになる。組み込み関数はどこでも定義済みであり、その名前の単独呼び出しは常に組み込み関数に到達するため、その宣言が実行されることはない。

```almide
fn println(s: String) -> Unit = io.print(redact(s) + "\n")   // E012: redefines the builtin 'println'
```

```
error[E012]: top-level fn 'println' redefines the builtin 'println'
  hint: Every call to `println(…)` reaches the builtin, never this declaration. Give it another name (e.g. `my_println`) and call that
```

ラッパーを改名（`log_line`、`say`）し、その名前で呼ぶ。組み込み関数と同名のローカル `let` やパラメーターは、他のローカル束縛と同じく、そのスコープ内で組み込み関数を隠す。

<a id="why-no-overloading"></a>

## オーバーロードがない理由

Almide は意図的に名前のオーバーロードを拒否する。他言語では、オーバーロード解決が LLM の混乱の大きな原因になる。同じソース行でも、引数の型、import、解決規則によって異なる実装に解決され得るからである。オーバーロードがなければ各呼び出し位置は曖昧でなく、`greet(x)` は常にスコープ内の唯一の `greet` を意味する。

関連する二つの動作が必要なら、異なる名前（`greet_en`、`greet_formal` など）にするか、区別するパラメーターを明示的に受け取る。
