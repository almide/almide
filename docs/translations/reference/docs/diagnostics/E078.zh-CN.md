# E078 — 计数循环内不得提前退出

[![English](https://img.shields.io/badge/English-d0d7de?style=flat-square)](E078.md) [![日本語](https://img.shields.io/badge/%E6%97%A5%E6%9C%AC%E8%AA%9E-d0d7de?style=flat-square)](E078.ja.md) [![简体中文](https://img.shields.io/badge/%E7%AE%80%E4%BD%93%E4%B8%AD%E6%96%87-24292f?style=flat-square)](E078.zh-CN.md)



> 原文：[`docs/diagnostics/E078.md`](https://github.com/almide/almide/blob/9a95b28519b90ae535dc9918bfed04805dc4675c/docs/diagnostics/E078.md)，固定提交 `9a95b285`。这是供读者参考的非规范性译文，CLI 诊断输出仍为英文。

`@bounded` 属性（ALS §B，bounded 配置）限制检查器在标注函数内允许的内容：静态有界的时间与存储、封闭无环的调用图、受能力约束的 effect。E078 拒绝 `@bounded` 函数的计数循环体内的 `!` 传播或 `guard`。

```
error[E078]: ... is not admissible in a @bounded function
```

```almide check-fail=E078
@bounded
effect fn sum_first(xs: List[Int]) -> Int! = {
  var acc = 0
  for i in 0..<3 { acc = acc + list.get(xs, i)! }
  ok(acc)
}

fn main() -> Unit = println("bounded")
```

<a id="the-fix"></a>

## 修复

在循环外进行传播或 guard；循环内用 `??` 提供默认值。循环中途退出会跳过每次迭代的清理，并削弱严格的迭代次数约束。

```almide
@bounded
fn sum_first(xs: List[Int]) -> Int = {
  var acc = 0
  for i in 0..<3 { acc = acc + (list.get(xs, i) ?? 0) }
  acc
}

fn main() -> Unit = println("bounded")
```

此规则仅约束 `@bounded` 函数内部；移除属性就会取消这一拒绝（配置是子集而非方言：ALS-B2）。
