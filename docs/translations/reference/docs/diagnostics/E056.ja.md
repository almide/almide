# E056 — Option に対する `?` は何もしない（警告）

[![English](https://img.shields.io/badge/English-d0d7de?style=flat-square)](E056.md) [![日本語](https://img.shields.io/badge/%E6%97%A5%E6%9C%AC%E8%AA%9E-24292f?style=flat-square)](E056.ja.md) [![简体中文](https://img.shields.io/badge/%E7%AE%80%E4%BD%93%E4%B8%AD%E6%96%87-d0d7de?style=flat-square)](E056.zh-CN.md)



> 原文: [E056.md @ 9a95b285](https://github.com/almide/almide/blob/9a95b28519b90ae535dc9918bfed04805dc4675c/docs/diagnostics/E056.md)。これは読者向けの非規範的な翻訳です。CLI に埋め込まれる診断解説は英語原文のままです。

`?` は Result を Option に変換します（`r? ≡ result.to_option(r)`、err → none）。すでに Option である値には何も変換せず、式は恒等です。それでも何かをしているように読めます。

```almide
fn f(o: Int?) -> Int? = o?    // ← E056: `o?` is exactly `o`
```

この警告以前は、何もしない操作が黙って検査を通り（#1107 D3）、`?` が「取り出す」という誤った一般化を教えていました。そうではありません。取り出すのは `?? fallback`、`match`、または effect fn 内の `!` です。

## 代わりの書き方

```almide
fn f(o: Int?) -> Int? = o          // the identity, spelled as one
let v = o ?? 0                     // if you meant to unwrap
```
