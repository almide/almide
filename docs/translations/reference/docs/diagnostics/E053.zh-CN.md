# E053 — 未知属性

[![English](https://img.shields.io/badge/English-d0d7de?style=flat-square)](E053.md) [![日本語](https://img.shields.io/badge/%E6%97%A5%E6%9C%AC%E8%AA%9E-d0d7de?style=flat-square)](E053.ja.md) [![简体中文](https://img.shields.io/badge/%E7%AE%80%E4%BD%93%E4%B8%AD%E6%96%87-24292f?style=flat-square)](E053.zh-CN.md)



> 原文：[E053.md @ 9a95b285](https://github.com/almide/almide/blob/9a95b28519b90ae535dc9918bfed04805dc4675c/docs/diagnostics/E053.md)。这是供读者参考的非规范性翻译。CLI 内嵌的诊断说明仍使用英文原文。

编译器不读取的属性名。属性能解析，但之后什么也不会发生。

```almide
@deprecatd(since = 3, use = "shout")   // ← E053: one transposed letter
fn yell(s: String) -> String = shout(s)
```

在此警告出现之前，这一行会干净地编译，却不告诉任何人任何信息：作者以为弃用声明已生效，而 `yell` 的所有调用方都没有收到警告。任何自创属性也一样——`@inline`、`@cache`、`@unsafe` 都被接受，却全都不起作用。

<a id="the-vocabulary"></a>

## 词汇表

编译器读取的名称集中在一个列表中，即 `crates/almide-frontend/src/attr_vocab.rs` 中的 `KNOWN_ATTRS`。

请查阅该注册表获取当前完整词汇，而不是依赖此处复制的列表。字段属性有自己较小的注册表，见下文。

拼写接近时会给出建议；与所有名称都相差很远时则给出整个列表，因为错误的建议会被当作权威答案。

<a id="declared-but-unread"></a>

## 已声明但未读取

第二个列表 `DECLARED_BUT_UNREAD` 记录语法接受、但**尚无代码读取**的属性。它们不会触发警告——语料集已经包含它们——但会被明确记下，而不是悄悄混入已知集合；因为“接受但不生效”正是这项诊断要避免意外保留的状态。

它目前为空。`@rewrite` 从首次运行语料集起一直在此，直到 almide#1450 纠正了记录：该属性由两个构建时生成器读取（egg 融合规则和代码生成脱糖回退，两者都处理 `stdlib/matrix.almd`），单纯搜索 AST 消费方无法发现。

<a id="why-a-warning-and-not-an-error"></a>

## 为什么是警告而不是错误

直接拒绝会破坏携带旧工具属性的文件。语言现在已有正确处理它的机制：在未来的 dialect epoch 将 E053 升为错误，用 [`proofs/dialect-epochs.toml`](../../../../../proofs/dialect-epochs.toml) 记录破坏性变更，并由 [E052](../../../../diagnostics/E052.md) 告诉每个调用方该怎么写。此警告是这条路径的第一步，而非永久停留点。

<a id="on-a-record-field-an-error-4108-epoch-15"></a>

## 在记录字段上：错误（#4108，epoch 15）

记录字段有自己更小的词汇表，即同一文件中的 `KNOWN_FIELD_ATTRS`：`@builtin` 和 `@location`（WGSL 阶段 I/O），以及 `@skip` / `@skip_decode`（Codec 字段跳过系列）。字段上的任何其他属性都是**错误**，而不是警告。在此位置，未被读取的属性意味着作者认为字段受到保护，实际却没有：

```almide
type User: Codec = { name: String, @serde(skip) is_admin: Bool = false }   // ← E053 (error)
```

在 epoch 15 之前，这会干净地编译，而 `User.decode` 仍会从请求体设置 `is_admin`。其他生态的写法会得到指出 Almide 对应写法的提示：`@serde(skip)`、`@json_ignore`、`@transient`、`@ignore` → `@skip`；`@skip_deserializing`、`@readonly`、`@read_only` → `@skip_decode`；`@redact`、`@sensitive`、`@secret` → 类型 `Secret[String]`（`import secret`）。夹具：`tests/diagnostics/e053-unknown-field-attribute-*`。

<a id="malformed-arguments-on-a-known-attribute"></a>

## 已知属性的参数格式错误

已知属性的参数若无法被编译器读取，会携带同一代码，但属于**错误**而非警告（#1518）：没有 `use =` 也没有 `note =` 的 `@deprecated(since = 2)` 过去会被悄然丢弃，作者以为调用方收到信息，弃用声明实际上却从未注册。无法读取的弃用声明比没有声明更糟；上述兼容性理由不适用，因为作者正在请求行为，而不是携带过时名称。

```almide
@deprecated(since = 2)                       // ← E053 (error): no use=, no note=
@deprecated(since = 2, use = "new_api")      // registers
@deprecated(since = 2, note = "unsound")     // registers
```
