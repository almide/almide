名前で呼び出した関数がスコープ内にない。

## よくある例

```almide
foo()                                  // foo is not defined
list.lengt(xs)                         // typo: should be list.len
my_module.something()                  // forgot to import my_module
```

## 他言語のイディオムの思い込み（`try:` 断片付き）

### 解決できないメソッド形式の呼び出し

Almide は、レシーバーの型とスコープ内の関数から解決できる場合に `s.to_upper()` のような UFCS 呼び出しをサポートする。未知または曖昧なメソッド名には修正が必要である。明示形の `string.to_upper(s)` と `s |> string.to_upper` はメソッド探索に依存しない。`s.to_upper` だけでは呼び出しではない（[E013](../../../../diagnostics/E013.md) を参照）。

### `int.gt(a, b)` / `int.lt` / `int.eq` などの比較関数

Almide は比較に演算子を使い、`int.gt` は存在しない。

```
try:
    // Almide uses operators, not comparison functions:
    //   int.gt(a, b)   →  a > b
    //   int.lt(a, b)   →  a < b
    //   int.gte(a, b)  →  a >= b
    //   int.lte(a, b)  →  a <= b
    //   int.eq(a, b)   →  a == b
    //   int.neq(a, b)  →  a != b
```

`almide fix` はこの書き換えを自動適用する（`int.gt(n, 0)` → `n > 0`）。

### `int.sqrt(n)`（存在しない — `math.sqrt` のみ）

```
try:
    // Almide has math.sqrt; int.sqrt doesn't exist.
    // Convert → sqrt → (optionally) convert back:
    let root_f = math.sqrt(float.from(n))          // Float
    let root_i = int.from_saturating(root_f)       // Int (truncates)
```

### その他のよくある名前の違い

| ユーザーの記述 | Almide での記述 | 自動修正可能か |
|---|---|---|
| `list.size` | `list.len` | レビューが必要な提案 |
| `list.head(xs)` | `list.first(xs)` | レビューが必要な提案 |
| `string.substring` | `string.slice` | レビューが必要な提案 |
| `string.to_uppercase` | `string.to_upper` | レビューが必要な提案 |
| `string.from_chars` | `list.join(chars, "")` | ヒントのみ |

## 修正（一般）

- 綴りを確認する。曖昧一致による「Did you mean ...?」提案はレビューが必要であり、名前が近いだけで machine-applicable にはならない。
- import を確認する。自動 import 集合の正本は `crates/almide-types/src/stdlib_info.rs` の `AUTO_IMPORT_BUNDLED`。例えば `bytes` と `datetime` は自動 import されるが、`env`、`io`、`random`、`regex`、`testing` は明示的な import が必要。
- `list.count` と `list.push` は実在する関数であり、存在しない名前の別名ではない。`list.len` や `+` に書き換えず、シグネチャを確認する。
- 自分のモジュールでは `import self.<sub>` を使って `<sub>.fn()` として呼ぶか、選択 import の `import self.<sub>.{fn1, fn2}` を使う。
- 標準ライブラリモジュールの正本となる API 一覧は、`almide ide outline @stdlib/<module>` を実行して確認する。

## Fix-it 判定

**mechanical** — dialect epoch で削除された綴りで、台帳の書き換えが呼び出しの引数一覧を保持する場合（`ffi.address(b)` → `ffi.region(b)`、`proofs/dialect-epochs.toml`）、編集は呼び出し先の改名だけで完了する。その他の E002 はすべて **conditional**。最も近い名前の提案は通常正しいが、推測である。（`mechanical` = 無人の修正ツールが書き換えを適用できる。`conditional` = 提案された修正はレビューが必要。`not-fixable` = 自動書き換えが存在しない。#1486 の適用可能性の原則。）
