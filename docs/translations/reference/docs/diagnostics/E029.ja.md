# E029 — 未知の型名

[![English](https://img.shields.io/badge/English-d0d7de?style=flat-square)](E029.md) [![日本語](https://img.shields.io/badge/%E6%97%A5%E6%9C%AC%E8%AA%9E-24292f?style=flat-square)](E029.ja.md) [![简体中文](https://img.shields.io/badge/%E7%AE%80%E4%BD%93%E4%B8%AD%E6%96%87-d0d7de?style=flat-square)](E029.zh-CN.md)



> 原文: [E029.md @ 9a95b285](https://github.com/almide/almide/blob/9a95b28519b90ae535dc9918bfed04805dc4675c/docs/diagnostics/E029.md)。これは読者向けの非規範的な翻訳です。CLI に埋め込まれる診断解説は英語原文のままです。

注釈またはレコードリテラルに現れる型名はすべて、宣言済み（またはインポート済み）の型でなければなりません。以前、未宣言の名前は制約のないまま単一化を通過していました。`type Inner` がなくても `let xs: List[Inner] = []` や `Inner { x: 1 }` が型検査に通り、その後ネイティブビルドで rustc の `E0412`/`E0422`/`E0425` により失敗していました（check は受理し build は失敗するという受理の隔たり。差分ファジングの seed 20260718、index 940 が、変異で消された `type` 宣言により発見したものです）。

```almide
fn main() -> Unit = {
  let xs: List[Inner] = []          // ← E029: unknown type 'Inner'
  let n = Inner { x: 1, y: 10 }     // ← E029: unknown type 'Inner'
}
```

## 修正

型を宣言します（または綴りを修正／不足している import を追加します）。

```almide
type Inner = { x: Int, y: Int }

fn main() -> Unit = {
  let xs: List[Inner] = [Inner { x: 1, y: 10 }]
  println("${list.len(xs)}")
}
```

ジェネリックパラメーターは仕組み上、対象外です。スコープ内のジェネリック（`fn
f[T](x: T)`）は注釈時に型変数へ解決され、名目的な名前にはなりません。組み込みの動的 `Value` 型も常にスコープ内にあります。

## Fix-it 判定

**mechanical** — dialect epoch で廃止された型表記（`RawPtr` → `Handle`、`proofs/dialect-epochs.toml`）の場合、型名の変更だけで修正は完了します。それ以外の E029 はすべて **not-fixable** — 自動書き換えでは判断できない意味上／設計上の問題を報告します。（`mechanical` = 無人の修正ツールが書き換えを適用可能、`conditional` = 提案された修正にレビューが必要、`not-fixable` = 自動書き換えは存在しません。#1486 の適用可能性の原則。）
