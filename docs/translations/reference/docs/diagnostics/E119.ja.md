# E119 — `@export(c)` fn に貸し出された Region が呼び出しの外へ逃れる

[![English](https://img.shields.io/badge/English-d0d7de?style=flat-square)](E119.md) [![日本語](https://img.shields.io/badge/%E6%97%A5%E6%9C%AC%E8%AA%9E-24292f?style=flat-square)](E119.ja.md) [![简体中文](https://img.shields.io/badge/%E7%AE%80%E4%BD%93%E4%B8%AD%E6%96%87-d0d7de?style=flat-square)](E119.zh-CN.md)



> 原文：[`docs/diagnostics/E119.md`](https://github.com/almide/almide/blob/9a95b28519b90ae535dc9918bfed04805dc4675c/docs/diagnostics/E119.md)、固定コミット `9a95b285`。読者向けの非規範的な翻訳であり、CLI の診断出力は英語のまま。

`@export(c)` fn の `Region` パラメーターは、C の呼び出し元のバッファーを `(const uint8_t *ptr, size_t len)` として参照する。`@region(out = p)` で指定したパラメーターは `(uint8_t *ptr, size_t len)` となる。呼び出し元はその1回の呼び出しの間だけバッファーを貸し出し、呼び出しが戻ると直ちに解放できる。Region のコピーは、呼び出しを超えて生存してはならない（ADR-0031 amendment A2）。

```almide
import ffi

var kept: Region = ffi.region(bytes.new())

@export(c, "keep")
fn keep(buf: Region) -> Int = {
  kept = buf   // ← E119
  ffi.len(buf)
}
```

```
error[E119]: a Region lent to @export(c) fn 'keep' escapes its call: it is stored in the top-level var `kept`
  hint: a lent Region views the C caller's buffer only for the call: copy what you need out with `ffi.read` / `ffi.to_bytes` and keep the Bytes (ADR-0031 amendment A2)
```

この検査は、コピーが fn 本体から外へ出る各経路を拒否する。

- トップレベルの `var`（またはそのフィールド・要素）への格納。
- 返却（fn の戻り型が Region を保持する）。
- クロージャーによるキャプチャー。
- コンテナー（`[buf]`、`some(buf)`、レコード）またはスライス（`ffi.slice(buf, 0, 4)!`）へ入れた後に、上記のいずれかを行うこと。

ローカルの `let` / `var` 束縛を追跡し、チェッカーの型を読むため、`let n = ffi.len(buf)`（`Int`）は問題ない。Region を別の fn に渡す呼び出しは追跡しない。その場合は代わりに実行時に検出する。呼び出しが戻るときにコピーが1つでも保持されていれば、ラッパーがプロセスを停止する。

## 修正

必要なバイト列をコピーし、`Bytes` を保持する。

```almide
import ffi

var kept: Bytes = bytes.new()

@export(c, "keep")
effect fn keep(buf: Region) -> Int = {
  kept = ffi.read(buf, 0, ffi.len(buf))!
  ffi.len(buf)
}
```

## Fix-it 判定

**not-fixable**：どのバイト列をどの形式で保持するかは、プログラムに関する判断である。（`mechanical` = 無人の修正ツールが書き換えを適用できる。`conditional` = 提案された修正はレビューが必要。`not-fixable` = 自動書き換えが存在しない。#1486 の適用可能性の原則。）
