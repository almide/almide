# E071 — 计数循环内不得分配

`@bounded` 属性（ALS §B，bounded 配置）限制检查器在标注函数内允许的内容：静态有界的时间与存储、封闭无环的调用图、受能力约束的 effect。E071 拒绝在 `@bounded` 函数的计数循环内构造列表／映射／字符串、拼接、push 或创建闭包。

```
error[E071]: ... is not admissible in a @bounded function
```

```almide check-fail=E071
@bounded
fn squares() -> List[Int] = {
  var xs: List[Int] = []
  for i in 0..<8 { xs = xs + [i * i] }
  xs
}

fn main() -> Unit = println("bounded")
```

## 修复

在循环前分配，让每次迭代都不分配：累积标量、写入预先定好大小的存储，或将构造移到循环外。

```almide
@bounded
fn sum_of_squares() -> Int = {
  var acc = 0
  for i in 0..<8 { acc = acc + i * i }
  acc
}

fn main() -> Unit = println("bounded")
```

此规则仅约束 `@bounded` 函数内部；移除属性就会取消这一拒绝（配置是子集而非方言：ALS-B2）。
