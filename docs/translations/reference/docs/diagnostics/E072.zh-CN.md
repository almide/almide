# E072 — `@bounded` 循环内不得使用 `break`/`continue`

[![English](https://img.shields.io/badge/English-d0d7de?style=flat-square)](E072.md) [![日本語](https://img.shields.io/badge/%E6%97%A5%E6%9C%AC%E8%AA%9E-d0d7de?style=flat-square)](E072.ja.md) [![简体中文](https://img.shields.io/badge/%E7%AE%80%E4%BD%93%E4%B8%AD%E6%96%87-24292f?style=flat-square)](E072.zh-CN.md)



> 原文：[`docs/diagnostics/E072.md`](https://github.com/almide/almide/blob/9a95b28519b90ae535dc9918bfed04805dc4675c/docs/diagnostics/E072.md)，固定提交 `9a95b285`。这是供读者参考的非规范性译文，CLI 诊断输出仍为英文。

`@bounded` 属性（ALS §B，bounded 配置）限制检查器在标注函数内允许的内容：静态有界的时间与存储、封闭无环的调用图、受能力约束的 effect。E072 拒绝从 `@bounded` 函数的计数循环体中提前退出。

```
error[E072]: ... is not admissible in a @bounded function
```

```almide check-fail=E072
@bounded
fn first_over(limit: Int) -> Int = {
  var found = 0
  for i in 0..<100 {
    if i * i > limit then break
    found = i
  }
  found
}

fn main() -> Unit = println("bounded")
```

<a id="the-fix"></a>

## 修复

计数循环只有一个出口（MISRA 纪律）：执行每次迭代，用分支选择，而不是提前退出。

```almide
@bounded
fn count_under(limit: Int) -> Int = {
  var found = 0
  for i in 0..<100 {
    found = if i * i > limit then found else i
  }
  found
}

fn main() -> Unit = println("bounded")
```

此规则仅约束 `@bounded` 函数内部；移除属性就会取消这一拒绝（配置是子集而非方言：ALS-B2）。
