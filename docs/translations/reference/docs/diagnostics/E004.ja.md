# E004 — 引数の数が不正

> 原文：[`docs/diagnostics/E004.md`](https://github.com/almide/almide/blob/9a95b28519b90ae535dc9918bfed04805dc4675c/docs/diagnostics/E004.md)、固定コミット `9a95b285`。読者向けの非規範的な翻訳であり、CLI の診断出力は英語のまま。

関数呼び出しに渡す引数が少なすぎる、または多すぎる。

## よくある例

```almide
list.map(xs)                  // missing closure
list.join(xs)                 // missing separator
int.pow(2)                    // pow expects (base, exp)
fn f(a, b) = a + b ; f(1)     // missing b
```

## シグネチャのプレースホルダー付き `try:` 断片

```
error[E004]: list.join() expects 2 argument(s) but got 1
  hint: Check the number of arguments
  try:
      // list.join() takes 2 arg(s) — you passed 1
      list.join(<xs: List[T]>, <sep: T>)
```

断片にはすべてのパラメーターの名前と型を `<name: Type>` のプレースホルダーとして示す。LLM が次の再試行でこれらを埋め、正しい呼び出しへ近づける。

## 修正

- 関数のシグネチャを確認する。素早く調べるには：
  - `almide ide doc <module>.<fn>` — シグネチャのみ
  - `almide ide outline @stdlib/<module>` — モジュールの全一覧
  - `docs/CHEATSHEET.md` — よくある例
- 標準ライブラリの任意パラメーターは位置指定のみ。手前の任意引数を飛ばして後ろの必須引数を渡すには、`none` を明示的に渡す。
- UFCS／メソッド形式の連鎖（`x |> f`）では、レシーバー（第 1 引数）はパイプの前の値であることに注意。
