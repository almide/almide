# E089 — 値に定義された文字列表現がない

[![English](https://img.shields.io/badge/English-d0d7de?style=flat-square)](E089.md) [![日本語](https://img.shields.io/badge/%E6%97%A5%E6%9C%AC%E8%AA%9E-24292f?style=flat-square)](E089.ja.md) [![简体中文](https://img.shields.io/badge/%E7%AE%80%E4%BD%93%E4%B8%AD%E6%96%87-d0d7de?style=flat-square)](E089.zh-CN.md)



> 原文：[`docs/diagnostics/E089.md`](https://github.com/almide/almide/blob/9a95b28519b90ae535dc9918bfed04805dc4675c/docs/diagnostics/E089.md)、固定コミット `9a95b285`。読者向けの非規範的な翻訳であり、CLI の診断出力は英語のまま。

`${…}` セグメントは二つの経路のいずれかで表示する。`Display`（数値、`Bool`、`String`）または Almide リテラルの repr（`List`、`Map`、`Set`、`Option`、`Result`、タプル、レコード、バリアント）。どちらもない型は生成するテキストがなく、これまでも生成できなかった。以前そのセグメントは `almide check` を通り、native ビルドで rustc `E0277`（「`std::fmt::Display` を実装していない」）になり、両 wasm 経路もその形を拒否していた。E089 はその失敗を検査時へ移し、修正を示す。

文字列表現がない型：

| 型 | 理由 | 代わりに補間するもの |
|---|---|---|
| `Bytes` | テキストではなく octet | `${bytes.to_list(b)}`、`${bytes.to_string_lossy(b)}`、`${int.to_string(bytes.len(b))}` |
| `Unit` | 内容を持たない | セグメントを削除。`println` など Unit を返す呼び出しにはテキストがない |
| `Matrix` | 数値ブロック | `${matrix.to_lists(m)}`、`${matrix.rows(m)}x${matrix.cols(m)}` |
| 生ポインター | アドレスは安定したテキストではない | 元の `Bytes`、または長さ |
| 関数値 | データではなくコード | 呼び出す：`${f(x)}` |

opaque newtype（`mod type Blob = Bytes`）は対象型の文字列表現を持つ。すべての位置で包む値を表示するため、上表の型を包む newtype にも同じ不足があり、メッセージはラッパー名を示す。

関数値や生ポインターを保持するコンテナー、タプル、レコード、バリアントにも文字列表現はない。repr が保持値を表示しなければならないためである。メッセージは保持するフィールドやケースを示す。コンテナー内の `Bytes`、`Unit`、`Matrix` は表示できる（`[[1, 2]]`、`some(())`、`[matrix.from_lists([[0]])]`）。この三つの不足はトップレベルだけである。

repr を宣言する名前付き型、つまり明示的な `fn T.repr` を持つ型では、フィールドが何を保持していても、その関数が文字列表現の全体となる。すべての renderer で宣言を通じて表示し、個々のフィールドは表示しない。そのため `ffi.Region`（Handle を保持）や任意の `A` に対する `secret.Secret[A]` は補間でき、関数フィールドを持つレコードも `fn T.repr` を宣言すれば補間できる。導出された repr（`deriving Repr`）はフィールドを表示するため該当しない。E089 は repr の宣言がない型だけに適用する。

```almide
effect fn main() -> Unit = {
  let u = ()
  println("u=${u}")            // ← E089: a Unit value has no defined string form
}
```

<a id="through-a-generic"></a>

## ジェネリックを経由する場合

ジェネリック本体はパラメーターを固定して一度検査するため、そのセグメントの型は `T` となる。`show(1)` には適していても `show(bytes)` には不可能である。セグメントは関数に対する要件となり、型引数が分かった各呼び出しをその要件に照らして判定する。

```almide
fn show[T](v: T) -> String = "v=${v}"

effect fn main() -> Unit = {
  println(show(1))                          // fine
  println(show(bytes.from_list([1, 2])))    // ← E089, reported at this call
}
```

メッセージは両端、つまりジェネリック内のセグメントと、それを具体化した呼び出しを示す。要件が複数呼び出しを経由した場合（`wrap` が `show` を呼ぶ）、途中の呼び出しも示す。診断位置は、検査中ファイルにある側へ固定する。

<a id="fix"></a>

## 修正

意図したものを補間する。octet、行、長さ、関数を呼び出した結果など。値自体を表示したく、その型を自分で所有する場合は、`fn T.repr(v: T) -> String` で文字列表現を宣言する。型が何を保持していても適用できる。
