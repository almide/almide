# E080 — or 模式的备选项绑定变量

[![English](https://img.shields.io/badge/English-d0d7de?style=flat-square)](E080.md) [![日本語](https://img.shields.io/badge/%E6%97%A5%E6%9C%AC%E8%AA%9E-d0d7de?style=flat-square)](E080.ja.md) [![简体中文](https://img.shields.io/badge/%E7%AE%80%E4%BD%93%E4%B8%AD%E6%96%87-24292f?style=flat-square)](E080.zh-CN.md)



> 原文：[`docs/diagnostics/E080.md`](https://github.com/almide/almide/blob/9a95b28519b90ae535dc9918bfed04805dc4675c/docs/diagnostics/E080.md)，固定提交 `9a95b285`。这是供读者参考的非规范性译文，CLI 诊断输出仍为英文。

or 模式分支 `a | b | c => body` 在**任一**备选项匹配时都会被选中，因此分支体不能依赖究竟是哪一项匹配。备选项中的变量绑定，在变量未出现的其他备选项中没有唯一的值（或者会在不同路径绑定不同的内部值），因此备选项必须**不含绑定**。

```almide
fn class(x: Option[Int]) -> String = match x {
  some(n) | none => "?",   // ← E080: `n` binds in one alternative only
}
```

通配符没有问题，因为它们不绑定任何值。

```almide
fn class(x: Option[Int]) -> String = match x {
  some(_) | none => "either",
}
```

当分支体需要内部值时，请分开编写分支。

```almide
fn class(x: Option[Int]) -> String = match x {
  some(n) => "got ${n}",
  none => "nothing",
}
```

此规则覆盖任意深度的绑定，包括构造器实参、元组、列表以及记录模式的字段内部。

<a id="fix-it-verdict"></a>

## Fix-it 判定

**conditional** — 将绑定替换为 `_` 是机械操作，但分支体是否需要内部值（因而应该拆分分支）取决于意图。
（`mechanical` = 无人值守的修复工具可以应用改写；`conditional` = 建议的修复需要审查；`not-fixable` = 不存在自动改写。#1486 的适用性原则。）
