# E007 — 位于 effect fn 外的 `fan` 块

`fan { ... }`（并发执行块）只能在 `effect fn` 内使用。并发是一种效应。

## 常见情况

```almide
fn parallel_work() -> Int = fan { a; b; c }    // E007: fan in pure fn
```

## 诊断

```
error[E007]: fan block can only be used inside an effect fn
  hint: Mark the enclosing function as `effect fn`
```

## 修复

- 将外层函数改为 `effect fn`：
  ```almide
  effect fn parallel_work() -> Int = fan { a; b; c }
  ```

## 原因

`fan` 并发运行各分支并汇总结果。时序、调度以及分支内的任何 I/O 都是可观察的效应。强制 `fan` 位于 `effect fn` 内，可以保持效应边界真实可靠：纯 `fn` 签名必须意味着“不依赖可观察的顺序或 I/O”。
