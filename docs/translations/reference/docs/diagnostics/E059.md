# E059 — non-iterable for head

A `for` loop over a value that is not a collection:

```
error[E059]: `for` cannot iterate `Int` — the loop head must be a List or a Map
```

```almide
fn main() -> Unit = {
  for x in 5 { println(int.to_string(x)) }   // ← E059: 5 is one Int, not a sequence
}
```

Before this rule the head fell through inference as `Unknown` and the failure
surfaced at codegen behind the COMPILER BUG banner (#1521) — check-green,
build-dies, the acceptance-parity class.

The iterable heads are a `List` (`for x in xs`), a range (`for i in 0...n` —
ranges materialize as lists), and a `Map` (`for (k, v) in m`, tuple
destructuring).

The fix here: a range.

```almide
fn main() -> Unit = {
  for x in 0...5 { println(int.to_string(x)) }
}
```
