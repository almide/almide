# E076 — `@bounded` effects are capability-bounded

[![English](https://img.shields.io/badge/English-24292f?style=flat-square)](E076.md) [![日本語](https://img.shields.io/badge/%E6%97%A5%E6%9C%AC%E8%AA%9E-d0d7de?style=flat-square)](E076.ja.md) [![简体中文](https://img.shields.io/badge/%E7%AE%80%E4%BD%93%E4%B8%AD%E6%96%87-d0d7de?style=flat-square)](E076.zh-CN.md)

The `@bounded` attribute (ALS §B, the bounded profile) narrows what the
checker admits inside the attributed function: statically bounded time and
storage, a closed acyclic call graph, capability-bounded effects. E076
rejects an effect outside the profile's declared capability (env/fs/http/net/process/random and the other host-reaching modules, or `fan.*` scheduling) in a `@bounded` function.

```
error[E076]: ... is not admissible in a @bounded function
```

```almide check-fail=E076
import env

@bounded
effect fn which_os() -> String = env.os()

fn main() -> Unit = println("bounded")
```

## The fix

A `@bounded` effect fn's declared capability is standard output only (the `println` family).

```almide
@bounded
effect fn report() -> Unit = println("bounded")

fn main() -> Unit = println("bounded")
```

The rule binds only inside `@bounded` functions — removing the attribute
removes the rejection (the profile is a subset, not a dialect: ALS-B2).

## Fix-it verdict

**not-fixable** — the diagnostic's hint names the admissible form; which
spelling replaces the rejected one depends on what the code was doing.
