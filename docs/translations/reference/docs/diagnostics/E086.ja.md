# E086 — 値が scoped allocation より長く生存する

[![English](https://img.shields.io/badge/English-d0d7de?style=flat-square)](E086.md) [![日本語](https://img.shields.io/badge/%E6%97%A5%E6%9C%AC%E8%AA%9E-24292f?style=flat-square)](E086.ja.md) [![简体中文](https://img.shields.io/badge/%E7%AE%80%E4%BD%93%E4%B8%AD%E6%96%87-d0d7de?style=flat-square)](E086.zh-CN.md)



> 原文：[`docs/diagnostics/E086.md`](https://github.com/almide/almide/blob/9a95b28519b90ae535dc9918bfed04805dc4675c/docs/diagnostics/E086.md)、固定コミット `9a95b285`。読者向けの非規範的な翻訳であり、CLI の診断出力は英語のまま。

`scoped { … }` ブロックは、その記憶領域が終わる場所を宣言する。E086 は、内部で構築した値がブロック終了後も必要になるプログラム、つまりブロック自体の値や外側で宣言した束縛への書き込みを拒否する。

```
error[E086]: `tree` would outlive its scoped allocation
  = allocated at analysis.almd:8:16
  = scope ends at analysis.almd:10:3
  hint: compute and return the scalar summary inside the scope
```

`allocated at` 行は値を構築した位置（ブロックの値が名前なら、それを束縛した `let`）を、`scope ends at` は閉じ括弧を示す。どちらも読者がエラー箇所を特定するのに必要な事実であり、`hint:` 行が一つの対処を示す。

```almide check-fail=E086
type Tree = Leaf | Node(Tree, Tree)

scoped fn make(depth: Int) -> Tree =
  if depth == 0 then Leaf else Node(make(depth - 1), make(depth - 1))

fn analysis(depth: Int) -> Tree =
  scoped {
    let tree = make(depth)
    tree
  }

effect fn main() -> Unit = println("${analysis(2)}")
```

## 修正

スコープ内で要約を計算し、スカラーを境界の外へ出す。

```almide check
type Tree = Leaf | Node(Tree, Tree)

scoped fn make(depth: Int) -> Tree =
  if depth == 0 then Leaf else Node(make(depth - 1), make(depth - 1))

scoped fn count(t: Tree) -> Int =
  match t {
    Leaf => 1,
    Node(l, r) => 1 + count(l) + count(r),
  }

fn analysis(depth: Int) -> Int =
  scoped {
    let tree = make(depth)
    count(tree)
  }

effect fn main() -> Unit = println(int.to_string(analysis(2)))
```

外側の束縛への書き込みも同じ規則を反対側から見たもの。内部から書き込むのではなく、ブロックの値として代入する（`total = scoped { … }`）。

stage 1 で境界を越えられるのは `Int`、`Float`、`Bool`、`Unit`。`String` と `T!` は黙ってコピーせず拒否する。設計の detach 規則（切り離したバイトから構築した新しい String は外へ出られる）は structural wasm 経路にまだ実現されておらず、片方の経路だけが守る規則は拒否より悪いためである（docs/specs/scoped.md）。

## Fix-it 判定

**conditional** — 境界を越えるべき要約は作者が選ぶ。コンパイラは値と境界を示し、fold を勝手に作らない。
