# E056 — `?` on an Option is a no-op (warning)

`?` converts a Result to an Option (`r? ≡ result.to_option(r)`, err → none).
On a value that is ALREADY an Option it converts nothing — the expression is
the identity — while reading as if it did something:

```almide
fn f(o: Int?) -> Int? = o?    // ← E056: `o?` is exactly `o`
```

Before this warning the no-op checked silently (#1107 D3), which taught the
false generalization that `?` "unwraps". It does not: unwrapping is
`?? fallback`, `match`, or `!` in an effect fn.

## What to write instead

```almide
fn f(o: Int?) -> Int? = o          // the identity, spelled as one
let v = o ?? 0                     // if you meant to unwrap
```
