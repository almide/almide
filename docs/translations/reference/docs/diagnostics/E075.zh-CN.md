# E075 — 不得构造运行时长度的堆对象

[![English](https://img.shields.io/badge/English-d0d7de?style=flat-square)](E075.md) [![日本語](https://img.shields.io/badge/%E6%97%A5%E6%9C%AC%E8%AA%9E-d0d7de?style=flat-square)](E075.ja.md) [![简体中文](https://img.shields.io/badge/%E7%AE%80%E4%BD%93%E4%B8%AD%E6%96%87-24292f?style=flat-square)](E075.zh-CN.md)



> 原文：[`docs/diagnostics/E075.md`](https://github.com/almide/almide/blob/9a95b28519b90ae535dc9918bfed04805dc4675c/docs/diagnostics/E075.md)，固定提交 `9a95b285`。这是供读者参考的非规范性译文，CLI 诊断输出仍为英文。

`@bounded` 属性（ALS §B，bounded 配置）限制检查器在标注函数内允许的内容：静态有界的时间与存储、封闭无环的调用图、受能力约束的 effect。E075 拒绝 `@bounded` 函数内长度为运行时值的堆构造（`string.repeat(s, n)`、`list.with_capacity(n)` 及同类函数）。

```
error[E075]: ... is not admissible in a @bounded function
```

```almide check-fail=E075
@bounded
fn pad(n: Int) -> String = string.repeat("x", n)

fn main() -> Unit = println("bounded")
```

<a id="the-fix"></a>

## 修复

为每个构造长度提供编译时大小：字面量，或绑定到字面量的 `let`。

```almide
@bounded
fn pad3() -> String = string.repeat("x", 3)

fn main() -> Unit = println("bounded")
```

此规则仅约束 `@bounded` 函数内部；移除属性就会取消这一拒绝（配置是子集而非方言：ALS-B2）。
