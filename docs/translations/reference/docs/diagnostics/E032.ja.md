# E032 — 不変の束縛を `mut` パラメーターに渡した

[![English](https://img.shields.io/badge/English-d0d7de?style=flat-square)](E032.md) [![日本語](https://img.shields.io/badge/%E6%97%A5%E6%9C%AC%E8%AA%9E-24292f?style=flat-square)](E032.ja.md) [![简体中文](https://img.shields.io/badge/%E7%AE%80%E4%BD%93%E4%B8%AD%E6%96%87-d0d7de?style=flat-square)](E032.zh-CN.md)



> 原文：[`docs/diagnostics/E032.md`](https://github.com/almide/almide/blob/9a95b28519b90ae535dc9918bfed04805dc4675c/docs/diagnostics/E032.md)、固定コミット `9a95b285`。読者向けの非規範的な翻訳であり、CLI の診断出力は英語のまま。

呼び出し先が `mut` パラメーターを宣言している箇所に、不変の束縛（`let`、`mut` と宣言されていないパラメーター）または一時式を渡した。変更には、`var` 束縛または `mut` パラメーターを根とする可変の場所が必要である。

すべてのコンテナーのその場書き込み関数は、受け手を `mut` と宣言する。`list.push`、`string.push`、`map.clear`、および `bytes` 書き込み関数群全体（`bytes.push`、`append_*`、`put_*`、`fill`、`clear`、`copy_from`、`copy_within`）が該当する（バイト書き込み関数は dialect epoch 5、#2466 以降）。

履歴上の注意：2026-08 まではこの種類を E007 として報告していた（1つのコードに無関係な2つの意味があった）。現在の E007 は effect の外での fan エラー専用である。

<a id="common-cases"></a>

## よくある例

```almide
fn grow(xs: List[Int]) -> Unit = {
  let ys = xs
  list.push(ys, 1)          // E032: `ys` is immutable
}

fn zero(b: Bytes) -> Unit =
  bytes.fill(b, 0)          // E032: parameter `b` is not `mut`

fn main() -> Unit = {
  bytes.append_u8(bytes.new(), 7)   // E032: a temporary has no binding to write back into
}
```

<a id="diagnostic"></a>

## 診断

```
error[E032]: cannot pass immutable binding 'ys' to `mut` parameter of list.push()
  hint: Declare 'ys' with `var` instead of `let` to allow mutation (a helper that writes its caller's value takes it as a `mut` parameter instead)

error[E032]: cannot pass immutable binding 'b' to `mut` parameter of bytes.fill()
  hint: 'b' is a parameter, and parameters are immutable: declare it `mut b: Bytes` so the write reaches the caller's value (the caller then passes a `var`), or copy it into a local `var` if the caller must not see the write
```

<a id="fix"></a>

## 修正

- ローカルバッファー：束縛を `var` で宣言する。
  ```almide
  var ys = xs
  list.push(ys, 1)
  ```
- 呼び出し元のバッファーを埋める補助関数：パラメーターを `mut` と宣言し、呼び出し位置で `var` を渡す。どのターゲットでも書き込みは呼び出し元に届く。
  ```almide
  fn zero(mut b: Bytes) -> Unit = bytes.fill(b, 0)

  fn main() -> Unit = {
    var b = bytes.from_list([1, 2])
    zero(b)
  }
  ```
- 呼び出し元の値を変更してはならない補助関数：パラメーターをローカルの `var` にコピーし、そのコピーに書き込む。
- フィールド／要素の場合、*根*となる束縛は `var` または `mut` パラメーターでなければならない（`var box` なら `list.push(box.items, x)` が可能）。
- 一時式は `mut` 引数にできない。先に `var` で束縛する。

<a id="why"></a>

## 理由

Almide は値意味論を持つ。`let c = a` はコピーであり、呼び出し先は自ら `mut` と宣言したパラメーター以外を通じて呼び出し元の束縛へ到達できない。`mut` パラメーターは、生成 Rust では `&mut` に、wasm では書き戻しに lowering される。不変または一時的な場所を許すと、rustc が失敗するか、一方のターゲットではコピー、他方では元の値を黙って変更することになる。どちらも「読んだものが実行される」という契約に反する。#2466 以前はバイト書き込み関数が `mut` を宣言していなかったため、通常の `Bytes` パラメーターへ書き込む補助関数がコンパイルでき、native では呼び出し元へ書き込む一方、wasm ではそうならなかった。
