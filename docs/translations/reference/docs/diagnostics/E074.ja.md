# E074 — `@bounded` は `@bounded`（または一階の純粋な標準ライブラリ関数）を呼ぶ

[![English](https://img.shields.io/badge/English-d0d7de?style=flat-square)](E074.md) [![日本語](https://img.shields.io/badge/%E6%97%A5%E6%9C%AC%E8%AA%9E-24292f?style=flat-square)](E074.ja.md) [![简体中文](https://img.shields.io/badge/%E7%AE%80%E4%BD%93%E4%B8%AD%E6%96%87-d0d7de?style=flat-square)](E074.zh-CN.md)



> 原文：[`docs/diagnostics/E074.md`](https://github.com/almide/almide/blob/9a95b28519b90ae535dc9918bfed04805dc4675c/docs/diagnostics/E074.md)、固定コミット `9a95b285`。読者向けの非規範的な翻訳であり、CLI の診断出力は英語のまま。

`@bounded` 属性（ALS §B、bounded プロファイル）は、属性を付けた関数内でチェッカーが受理する範囲を制限する。時間と記憶領域が静的に有界であること、閉じた非循環の呼び出しグラフ、ケイパビリティで制限されたエフェクトである。E074 は、`@bounded` 関数からの非 `@bounded` ユーザー関数呼び出し、クロージャーの作成・呼び出し、高階の標準ライブラリ呼び出しを拒否する。

```
error[E074]: ... is not admissible in a @bounded function
```

```almide check-fail=E074
fn helper(x: Int) -> Int = x + 1

@bounded
fn uses_plain(x: Int) -> Int = helper(x)

fn main() -> Unit = println("bounded")
```

<a id="the-fix"></a>

## 修正

呼び出し先に `@bounded` を付けるか、純粋な標準ライブラリモジュールの一階のメンバーを使う。関数値は、このプロファイルの静的な呼び出しグラフが追跡できない間接的な呼び出し先である。

```almide
@bounded
fn helper(x: Int) -> Int = x + 1

@bounded
fn uses_bounded(x: Int) -> Int = helper(x)

fn main() -> Unit = println("bounded")
```

この規則が適用されるのは `@bounded` 関数の内部だけであり、属性を取り除くと、この拒否もなくなる（プロファイルはサブセットであって方言ではない：ALS-B2）。
