# E003 — 未定义的变量

[![English](https://img.shields.io/badge/English-d0d7de?style=flat-square)](E003.md) [![日本語](https://img.shields.io/badge/%E6%97%A5%E6%9C%AC%E8%AA%9E-d0d7de?style=flat-square)](E003.ja.md) [![简体中文](https://img.shields.io/badge/%E7%AE%80%E4%BD%93%E4%B8%AD%E6%96%87-24292f?style=flat-square)](E003.zh-CN.md)



> 原文：[`docs/diagnostics/E003.md`](https://github.com/almide/almide/blob/9a95b28519b90ae535dc9918bfed04805dc4675c/docs/diagnostics/E003.md)，固定提交 `9a95b285`。这是面向读者的非规范性译文；CLI 诊断输出仍为英语。

作为值使用的名称未在当前作用域中绑定。

<a id="common-cases"></a>

## 常见情况

```almide
fn f() -> Int = x                      // x is not declared
match v { ok(value) => valeu }         // typo: 'valeu' instead of 'value'
let x = y                              // y is not bound at this point
json.stringify(v)                      // forgot `import json`
```

<a id="specialized-sub-patterns-with-try-snippets"></a>

## 特定子模式（附 `try:` 片段）

<a id="forgot-import-json--import-fs--etc"></a>

### 忘记 `import json` / `import fs` 等

对需要显式导入的 Tier 2 标准库模块，第一次使用 `<module>.<fn>` 时会输出：

```
error[E003]: undefined variable 'json'
  hint: Add `import json` (stdlib: JSON parsing and querying)
  try:
      import json
```

`almide fix` 会自动应用此修复（调用格式化器的 `auto_imports`）。无需用户操作——测试框架只需在重试前运行 `almide fix`。

<a id="typo-of-an-in-scope-name"></a>

### 作用域内名称的拼写错误

找到模糊匹配时：

```
error[E003]: undefined variable 'lenth'
  hint: Did you mean `length`?
  try:
      // lenth  →  length
      length
```

<a id="fix-general"></a>

## 修复（通用）

- 使用前通过 `let` 或 `var` 声明。
- 对照模式绑定的名称检查拼写（`match v { ok(value) => ... }` 绑定的是 `value`，不是 `val` 或 `valeu`）。
- 对表达式内的 let 绑定，确保它位于包含使用位置的 `Block { ... }` 中。顶层单独的 `let x = 1` 是 `TopLet` 声明；fn 体内需要 `{ let x = 1; x }` 或等价写法。
- 对 Tier 2 标准库：在顶部添加 `import <module>`（或运行 `almide fix` 自动完成）。
