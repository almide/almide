# E083 — コンパイラの所有権不具合：出力された終了処理が検査済み ExitPlan を実装していない

[![English](https://img.shields.io/badge/English-d0d7de?style=flat-square)](E083.md) [![日本語](https://img.shields.io/badge/%E6%97%A5%E6%9C%AC%E8%AA%9E-24292f?style=flat-square)](E083.ja.md) [![简体中文](https://img.shields.io/badge/%E7%AE%80%E4%BD%93%E4%B8%AD%E6%96%87-d0d7de?style=flat-square)](E083.zh-CN.md)



> 原文：[`docs/diagnostics/E083.md`](https://github.com/almide/almide/blob/9a95b28519b90ae535dc9918bfed04805dc4675c/docs/diagnostics/E083.md)、固定コミット `9a95b285`。読者向けの非規範的な翻訳であり、CLI の診断出力は英語のまま。

`--target wasm` の structural 経路は、関数フレームのすべての終了方法を一か所、検査済み `ExitPlan`（#1995）で決める。各辺で解放する参照カウント credit と、引き継ぐ credit を決める。関数を出力した後、ビルドはバイト列を読み戻し、各終了区間をその計画と照合する（#1996）。E083 はバイト列が計画を実装していないことを意味する。

- 解放する credit に転送前の decrement がない。
- 引き継ぐ credit、または計画外の値を decrement した。
- 転送命令が計画の継続先と異なる。
- フレームを置き換える末尾転送（または return）が未処理の credit を残す。

```text
error[E083]: tail exit leaves an ownership credit outstanding
  --> fn `helper`
   = value: local `x`
   = expected: transfer or release before tail transfer
   = emitted: neither
   = compiler contract failure; no artifact emitted (run `almide explain E083`)
```

**これはコンパイラの不具合であり、あなたのプログラムの不具合ではない。** これを露呈させる有効なソースは有効である。ビルドは回避のため別経路に振り替えない（#2761 以降第二の wasm renderer はなく、仮にあっても使わない。検査済み計画がリークすると示すプログラムを出荷してはならない）。また emitter がたまたま扱える形にプログラムを書き換えるよう求めることもない。プログラムを添えて報告すること。示された関数は、emitter の解放管理と実際のバイト列が食い違う箇所である。

この wasm 固有の verifier 失敗は、独立した `--target rust` ビルドの成否を立証するものではない。
