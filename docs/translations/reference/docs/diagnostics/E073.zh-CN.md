# E073 — bounded 配置内不得递归

`@bounded` 属性（ALS §B，bounded 配置）限制检查器在标注函数内允许的内容：静态有界的时间与存储、封闭无环的调用图、受能力约束的 effect。E073 拒绝从 `@bounded` 函数可达的自递归或相互递归调用；调用图必须是 DAG。

```
error[E073]: ... is not admissible in a @bounded function
```

```almide check-fail=E073
@bounded
fn fact(n: Int) -> Int = if n <= 1 then 1 else n * fact(n - 1)

fn main() -> Unit = println("bounded")
```

## 修复

将递归替换为计数循环；该配置的静态时间上限要求调用图无环。

```almide
@bounded
fn factorial_10() -> Int = {
  var acc = 1
  for i in 1...10 { acc = acc * i }
  acc
}

fn main() -> Unit = println("bounded")
```

此规则仅约束 `@bounded` 函数内部；移除属性就会取消这一拒绝（配置是子集而非方言：ALS-B2）。
