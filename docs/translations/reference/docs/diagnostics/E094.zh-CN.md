# E094 — 类型别名形成循环

[![English](https://img.shields.io/badge/English-d0d7de?style=flat-square)](E094.md) [![日本語](https://img.shields.io/badge/%E6%97%A5%E6%9C%AC%E8%AA%9E-d0d7de?style=flat-square)](E094.ja.md) [![简体中文](https://img.shields.io/badge/%E7%AE%80%E4%BD%93%E4%B8%AD%E6%96%87-24292f?style=flat-square)](E094.zh-CN.md)



> 原文：[E094.md @ 9a95b285](https://github.com/almide/almide/blob/9a95b28519b90ae535dc9918bfed04805dc4675c/docs/diagnostics/E094.md)。这是供读者参考的非规范性翻译。CLI 内嵌的诊断说明仍使用英文原文。

类型别名是其本体的另一个名称：`type Coord = Pos` 表示与 `Pos` 相同的含义。直接、经由其他别名或类型实参回到自身的别名，没有可代表的本体，因此不指代任何类型。过去这会静默通过 `almide check`（`type Tree = List[Tree]`），或让别名保持为不透明名称，使所有使用处随后以无关错误拒绝。E094 在循环中最先声明的别名处报告循环。

```almide
type Coord = Pos

type Pos = Coord                  // ← E094: type aliases form a cycle: Coord → Pos → Coord
```

经由类型实参的循环也是循环：

```almide
type Tree = List[Tree]            // ← E094: type alias 'Tree' refers to itself (Tree → Tree)
```

声明顺序不算循环：别名可以指向后面声明的类型（在 `type Pair2 = (Int, Int)` 上方写 `type First = Pair2`）。

<a id="fix"></a>

## 修复

为其中一个别名提供不会回到自身的本体，或者将递归类型改为名义类型——记录或变体可以引用自身：

```almide
type Tree = { kids: List[Tree] }

fn size(t: Tree) -> Int = list.len(t.kids)
```

<a id="fix-it-verdict"></a>

## Fix-it 判定

**not-fixable** — 循环本来需要记录、变体还是其他本体，属于作者意图；消息会列出循环中的别名。
