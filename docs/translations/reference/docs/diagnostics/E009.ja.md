# E009 — 不変束縛への再代入

[![English](https://img.shields.io/badge/English-d0d7de?style=flat-square)](E009.md) [![日本語](https://img.shields.io/badge/%E6%97%A5%E6%9C%AC%E8%AA%9E-24292f?style=flat-square)](E009.ja.md) [![简体中文](https://img.shields.io/badge/%E7%AE%80%E4%BD%93%E4%B8%AD%E6%96%87-d0d7de?style=flat-square)](E009.zh-CN.md)

`let x = ...` は不変の束縛を作ります。可変の束縛には `var` を使います。

## よくある例

```almide
let count = 0
count = count + 1            // E009: 'count' is immutable
```

## `try:` スニペット

```
error[E009]: cannot reassign immutable binding 'count'
  hint: Use 'var count = ...' instead of 'let count = ...' to declare a mutable variable
  try:
      // let count = ...  →  var count = ...
      var count = <initial value>
```

コンパイラは AST から実際の名前を取得します。再代入される束縛が**関数のパラメーター（仮引数）**（不変）である場合、スニペットが変わります。

```
  hint: 'count' is a function parameter (immutable). Use a local copy: var count_ = count
  try:
      // 'count' is a parameter — make a mutable copy:
      var count_ = count
      // ...then reassign count_ instead of count
```

## 修正

- 可変にするには `var` を使います（変更が実際の設計意図である場合に推奨）。
  ```almide
  var count = 0
  count = count + 1          // OK
  ```
- 関数型の書き方を優先し、新しい値を作って元の名前は不変に保ちます。
  ```almide
  let count = 0
  let count2 = count + 1
  ```
- 特にパラメーター（仮引数）の場合は、ローカルコピーを作ります。
  ```almide
  fn step(x: Int) -> Int = {
      var x_ = x
      x_ = x_ + 1
      x_
  }
  ```

## 既定で不変にする理由

不変性は LLM による変更の生存率を最大化します。読み手は、スコープ全体で `x` が同じ値を意味すると信頼できます。明示的な `var` は変更する意図を示し、通常は `effect fn`（副作用のあるコード）または局所的な集計変数のパターンと組み合わされます。

変更が必要に感じられる純粋な関数（ループ）では、再帰を優先します。

```almide
fn count_up(n: Int) -> Int =
    if n == 0 then 0
    else 1 + count_up(n - 1)
```
