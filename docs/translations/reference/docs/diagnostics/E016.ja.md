# E016 — 等値性またはハッシュが必要な場所に関数がある

[![English](https://img.shields.io/badge/English-d0d7de?style=flat-square)](E016.md) [![日本語](https://img.shields.io/badge/%E6%97%A5%E6%9C%AC%E8%AA%9E-24292f?style=flat-square)](E016.ja.md) [![简体中文](https://img.shields.io/badge/%E7%AE%80%E4%BD%93%E4%B8%AD%E6%96%87-d0d7de?style=flat-square)](E016.zh-CN.md)



> 原文：[`docs/diagnostics/E016.md`](https://github.com/almide/almide/blob/9a95b28519b90ae535dc9918bfed04805dc4675c/docs/diagnostics/E016.md)、固定コミット `9a95b285`。読者向けの非規範的な翻訳であり、CLI の診断出力は英語のまま。

関数（クロージャー）を含む型が、等値性またはハッシュが必要な位置にある。対象は `Set` の要素、`Map` の**キー**、`==` / `!=` / `assert_eq` / `assert_ne` のオペランド。関数型は決して Eq でもハッシュ可能でもなく（docs/specs/type-system.md）、関数を含む Result、Option、リスト、タプル、レコード、バリアントも同様である。そのため重複除去・検索・比較はできない。

これは**両方**のターゲットで必ずエラーとなる。以前は挙動が分かれ、Rust は拒否した（`Eq`/`Hash` を満たさない）が、WASM はコンパイルされてすべての insert を黙って捨てた（`Set[() ->
Unit]` の長さは常に 0）。型検査時に拒否することで両ターゲットを一致させる。

クロージャーは `Map` の**値**としては問題ない。制約されるのはキーだけである。

比較の形式は以前 `check` を通過し、生成された Rust で失敗していた（`binary operation == cannot be applied to type
Rc<dyn Fn(..)>`、#2606）。現在は検査時点でこのエラーとなる。

## よくある例

```almide
var handlers: Set[() -> Unit] = set.new()
set.insert(handlers, () => {})
// error[E016]: a `Set` element type cannot contain a function
```

```almide
var routes: Map[() -> Unit, String] = map.new()
// error[E016]: a `Map` key type cannot contain a function
```

```almide
fn make(n: Int) -> Result[(Int) -> Int, String] = if n > 0 then ok((x) => x + n) else err("neg")
test "t" { assert_eq(make(-1), err("neg")) }
// error[E016]: type 'Result[fn(Int) -> Int, String]' has no equality — assert_eq() cannot compare it
```

## 修正

比較では、タグ、エラー、関数の出力など、その値から観測できるものを比較する。

```almide
assert_eq(result.to_err_option(make(-1)), some("neg"))
assert(result.is_ok(make(2)))
```

`Set` または `Map` キーの場合、クロージャーを `List`（順序付け／ハッシュの要件がない）に保持する。

```almide
var handlers: List[() -> Unit] = []
list.push(handlers, () => {})
```

本当に set/map の意味が必要なら、比較可能な値（名前や id）をキーにし、それに添えてクロージャーを格納する。

```almide
var handlers: Map[String, () -> Unit] = map.new()  // closure as VALUE — allowed
handlers = map.set(handlers, "on_click", () => {})
```
