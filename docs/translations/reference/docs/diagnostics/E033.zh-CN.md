# E033 — 在定义模块之外构造不透明类型

[![English](https://img.shields.io/badge/English-d0d7de?style=flat-square)](E033.md) [![日本語](https://img.shields.io/badge/%E6%97%A5%E6%9C%AC%E8%AA%9E-d0d7de?style=flat-square)](E033.ja.md) [![简体中文](https://img.shields.io/badge/%E7%AE%80%E4%BD%93%E4%B8%AD%E6%96%87-24292f?style=flat-square)](E033.zh-CN.md)



> 原文：[`docs/diagnostics/E033.md`](https://github.com/almide/almide/blob/9a95b28519b90ae535dc9918bfed04805dc4675c/docs/diagnostics/E033.md)，固定提交 `9a95b285`。这是供读者参考的非规范性译文，CLI 诊断输出仍为英文。

从定义该不透明类型的模块之外调用了其构造器。不透明类型只能通过定义模块的公开 API 构造。

历史说明：直到 2026-08，此问题被报告为 E008（一个代码承载了两种无关含义）；E008 现在仅表示 fan 的可变捕获错误。

## 常见情况

```almide
// a.almd: mod type Token = String
// module b:
import self.a
let t = a.Token("raw")        // E033: constructing a.Token outside module a
```

## 诊断

```
error[E033]: cannot construct opaque type 'Token' outside its defining module
  hint: Use the module's public API to create 'Token' values
```

## 修复

- 调用定义模块导出的构造函数。
  ```almide
  let t = a.token_of("raw")
  ```

## 原因

不透明性是不变量边界：定义模块保证它交出的每个值都满足该类型的不变量。外部的构造器调用会绕过这一保证。
