# E420 — 函数可见性违规

[![English](https://img.shields.io/badge/English-d0d7de?style=flat-square)](E420.md) [![日本語](https://img.shields.io/badge/%E6%97%A5%E6%9C%AC%E8%AA%9E-d0d7de?style=flat-square)](E420.ja.md) [![简体中文](https://img.shields.io/badge/%E7%AE%80%E4%BD%93%E4%B8%AD%E6%96%87-24292f?style=flat-square)](E420.zh-CN.md)

调用触及了声明可见范围之外的函数。`local fn` 仅限定义它的文件，`mod fn` 仅限其项目。仅在名称中使用下划线并不是可见性声明。稳定代码是 E420；E014 已表示不可达的 match 分支。

## 常见情况

```almide
// my_module.almd
fn public_helper() -> Int = 42
local fn private_helper() -> Int = 0   // same file only

// main.almd
import self.my_module
fn main() -> Unit = {
    let n = my_module.private_helper()    // E420
    println(int.to_string(n))
}
```

## 诊断

```
error[E420]: function 'my_module.private_helper' is not accessible
  hint: 'private_helper' is declared as `local` (same-file only)
```

`hint:` 行说明被调用方实际拥有的可见范围。

## 修复

- 如果函数本应公开，请有意修改其可见性声明，或在定义文件内添加公开包装函数。
- 否则，将调用保持在已声明的文件／项目边界内。
- 重命名以下划线开头的函数，本身不会改变可见性。

## 为什么需要可见性

内部辅助函数应当能够重构，而无需向无关调用者暴露实现。边界由显式可见性设定，而非命名约定。
