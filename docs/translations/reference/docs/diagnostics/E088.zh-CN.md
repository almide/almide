# E088 — 递归调用保留当前 scoped activation

[![English](https://img.shields.io/badge/English-d0d7de?style=flat-square)](E088.md) [![日本語](https://img.shields.io/badge/%E6%97%A5%E6%9C%AC%E8%AA%9E-d0d7de?style=flat-square)](E088.ja.md) [![简体中文](https://img.shields.io/badge/%E7%AE%80%E4%BD%93%E4%B8%AD%E6%96%87-24292f?style=flat-square)](E088.zh-CN.md)



> 原文：[`docs/diagnostics/E088.md`](https://github.com/almide/almide/blob/9a95b28519b90ae535dc9918bfed04805dc4675c/docs/diagnostics/E088.md)，固定提交 `9a95b285`。这是面向读者的非规范性译文；CLI 诊断输出仍为英语。

最初的 `scoped` 子集接纳普通 worker 和**直接尾递归** worker。E088 拒绝两种在调用期间保持调用者 activation 存活的递归形态：单次自调用之后仍有工作，以及 scoped worker 之间的相互递归。

```
error[E088]: recursive call retains the current scoped activation
  = addition remains after the recursive call
  = required by the `scoped` declaration of `count`
  hint: carry the count in an accumulator and return the recursive call
```

注记指出调用后剩余的内容：`addition`、`a constructor`、`a binding`，让读者从消息中看出累加器改写方式。

```almide check-fail=E088
type Chain = Nil | Cons(Int, Chain)

scoped fn total(c: Chain) -> Int =
  match c {
    Nil => 0,
    Cons(h, t) => h + total(t),
  }

effect fn main() -> Unit = println(int.to_string(scoped { total(Cons(1, Cons(2, Nil))) }))
```

<a id="the-fix"></a>

## 修复

将待处理工作放入累加器，使递归调用成为 arm 的结果。

```almide check
type Chain = Nil | Cons(Int, Chain)

scoped fn total(c: Chain, acc: Int) -> Int =
  match c {
    Nil => acc,
    Cons(h, t) => total(t, acc + h),
  }

effect fn main() -> Unit = println(int.to_string(scoped { total(Cons(1, Cons(2, Nil)), 0) }))
```

相互递归（`even_steps` 调用 `odd_steps` 再调用 `even_steps`）因同一原因被拒绝，修复方式是将二者合并成一个直接递归的 worker。

**不拒绝**：一个 arm 进行两次或更多自调用的 worker，例如 `1 + count(l) + count(r)` 这样的树遍历。这种形态没有累加器改写，因此作为普通 worker 接纳；规则针对的是能通过累加器修复的单次非尾调用。

<a id="fix-it-verdict"></a>

## Fix-it 判定

**conditional** — 累加器参数及初始值由作者选择；诊断指出调用后剩余的工作，以及应写成的形态。
