# E089 — 值没有已定义的字符串形式

[![English](https://img.shields.io/badge/English-d0d7de?style=flat-square)](E089.md) [![日本語](https://img.shields.io/badge/%E6%97%A5%E6%9C%AC%E8%AA%9E-d0d7de?style=flat-square)](E089.ja.md) [![简体中文](https://img.shields.io/badge/%E7%AE%80%E4%BD%93%E4%B8%AD%E6%96%87-24292f?style=flat-square)](E089.zh-CN.md)



> 原文：[`docs/diagnostics/E089.md`](https://github.com/almide/almide/blob/9a95b28519b90ae535dc9918bfed04805dc4675c/docs/diagnostics/E089.md)，固定提交 `9a95b285`。这是面向读者的非规范性译文；CLI 诊断输出仍为英语。

`${…}` 片段通过两条路径之一呈现：`Display`（数字、`Bool`、`String`）或 Almide 字面量 repr（`List`、`Map`、`Set`、`Option`、`Result`、元组、记录、变体）。两者都没有的类型无法产生文本，而且从未能产生：这种片段过去能通过 `almide check`，随后 native 构建以 rustc `E0277` 失败（“未实现 `std::fmt::Display`”），而两条 wasm 路径都拒绝该形态。E089 将这一失败移到检查期，并指出修复。

没有字符串形式的类型：

| 类型 | 原因 | 改为插值 |
|---|---|---|
| `Bytes` | 八位字节，而非文本 | `${bytes.to_list(b)}`、`${bytes.to_string_lossy(b)}`、`${int.to_string(bytes.len(b))}` |
| `Unit` | 不携带内容 | 去掉片段；`println` 或其他返回 Unit 的调用没有文本 |
| `Matrix` | 数值块 | `${matrix.to_lists(m)}`、`${matrix.rows(m)}x${matrix.cols(m)}` |
| 原始指针 | 地址不是稳定文本 | 来源 `Bytes` 或长度 |
| 函数值 | 代码，而非数据 | 调用它：`${f(x)}` |

opaque newtype（`mod type Blob = Bytes`）具有目标类型的字符串形式，会在每个位置呈现其包装的值。因此包装上表某类型的 newtype 有相同缺口，消息会指出包装类型。

持有函数值或原始指针的容器、元组、记录或变体也没有字符串形式，因为 repr 必须呈现所持值。消息指出持有该值的字段或分支。容器内的 `Bytes`、`Unit`、`Matrix` 可以呈现（`[[1, 2]]`、`some(())`、`[matrix.from_lists([[0]])]`）；这三种仅在顶层存在缺口。

声明了 repr 的具名类型，即显式 `fn T.repr`，不论字段持有什么，都以该函数作为完整字符串形式：所有 renderer 都通过该声明打印值，不呈现任何字段。因此 `ffi.Region`（持有 Handle）及任意 `A` 的 `secret.Secret[A]` 可以插值；带函数字段的记录在声明 `fn T.repr` 后也可以插值。派生 repr（`deriving Repr`）会呈现字段，不算在内。E089 只适用于没有声明 repr 的类型。

```almide
effect fn main() -> Unit = {
  let u = ()
  println("u=${u}")            // ← E089: a Unit value has no defined string form
}
```

<a id="through-a-generic"></a>

## 经由泛型

泛型体在参数固定的情况下检查一次，因此片段类型为 `T`：对 `show(1)` 没问题，对 `show(bytes)` 却不可能。片段成为函数要求，每次调用在类型参数明确后接受该要求的判断：

```almide
fn show[T](v: T) -> String = "v=${v}"

effect fn main() -> Unit = {
  println(show(1))                          // fine
  println(show(bytes.from_list([1, 2])))    // ← E089, reported at this call
}
```

消息指出两端：泛型内的片段及实例化它的调用；若要求经过多次调用传播（`wrap` 调用 `show`），也指出中间调用。诊断锚定在当前检查文件中的那一端。

<a id="fix"></a>

## 修复

插值你想表达的内容：八位字节、行、长度或调用函数的结果。如果值本身确实是要展示的内容，且类型属于你，使用 `fn T.repr(v: T) -> String` 声明字符串形式，无论类型内部持有什么。
