# E073 — bounded プロファイルでは再帰不可

[![English](https://img.shields.io/badge/English-d0d7de?style=flat-square)](E073.md) [![日本語](https://img.shields.io/badge/%E6%97%A5%E6%9C%AC%E8%AA%9E-24292f?style=flat-square)](E073.ja.md) [![简体中文](https://img.shields.io/badge/%E7%AE%80%E4%BD%93%E4%B8%AD%E6%96%87-d0d7de?style=flat-square)](E073.zh-CN.md)



> 原文：[`docs/diagnostics/E073.md`](https://github.com/almide/almide/blob/9a95b28519b90ae535dc9918bfed04805dc4675c/docs/diagnostics/E073.md)、固定コミット `9a95b285`。読者向けの非規範的な翻訳であり、CLI の診断出力は英語のまま。

`@bounded` 属性（ALS §B、bounded プロファイル）は、属性を付けた関数内でチェッカーが受理する範囲を制限する。時間と記憶領域が静的に有界であること、閉じた非循環の呼び出しグラフ、ケイパビリティで制限されたエフェクトである。E073 は、`@bounded` 関数から到達可能な自己再帰または相互再帰の呼び出しを拒否する。呼び出しグラフは DAG でなければならない。

```
error[E073]: ... is not admissible in a @bounded function
```

```almide check-fail=E073
@bounded
fn fact(n: Int) -> Int = if n <= 1 then 1 else n * fact(n - 1)

fn main() -> Unit = println("bounded")
```

## 修正

再帰を回数指定ループに置き換える。このプロファイルの静的な時間上限には、非循環の呼び出しグラフが必要である。

```almide
@bounded
fn factorial_10() -> Int = {
  var acc = 1
  for i in 1...10 { acc = acc * i }
  acc
}

fn main() -> Unit = println("bounded")
```

この規則が適用されるのは `@bounded` 関数の内部だけであり、属性を取り除くと、この拒否もなくなる（プロファイルはサブセットであって方言ではない：ALS-B2）。

## Fix-it 判定

**conditional** — 診断のヒントは許容される形式を示す。拒否された形式をどの表記に置き換えるかは、そのコードが何をしていたかによる。
