# E058 — 无法哈希的 Map 键

[![English](https://img.shields.io/badge/English-d0d7de?style=flat-square)](E058.md) [![日本語](https://img.shields.io/badge/%E6%97%A5%E6%9C%AC%E8%AA%9E-d0d7de?style=flat-square)](E058.ja.md) [![简体中文](https://img.shields.io/badge/%E7%AE%80%E4%BD%93%E4%B8%AD%E6%96%87-24292f?style=flat-square)](E058.zh-CN.md)



> 原文：[E058.md @ 9a95b285](https://github.com/almide/almide/blob/9a95b28519b90ae535dc9918bfed04805dc4675c/docs/diagnostics/E058.md)。这是供读者参考的非规范性翻译。CLI 内嵌的诊断说明仍使用英文原文。

无法哈希的 `Map` 键类型：`Float`（IEEE-754 相等性使其不能用于查找）、`Map`，或字段中任何位置含有它们的记录／变体。

```
error[E058]: type 'Float' is not hashable — cannot be used as a Map key (it contains a Float)
```

```almide
fn main() -> Unit = {
  let m: Map[Float, Int] = [:]   // ← E058: Float keys have no stable equality
  println(int.to_string(map.len(m)))
}
```

该规则在前端触发，使两个目标保持一致。过去无法哈希的键会通过 `check`，随后原生在 rustc 的 `Hash` 约束处失败，而 wasm 会悄然将不同的键合并（#598）。

因类型中包含**函数**而被禁止的键（包括命名记录内的函数类型字段），会以 [E016](../../../../diagnostics/E016.md) 报告，即键中含闭包的类别，使用专门的描述。

修复方式：使用可哈希数据（`String`、`Int`、`Bool`，或由它们构成的记录／变体）作为键，将不可哈希数据放在值一侧：

```almide
fn main() -> Unit = {
  let m: Map[String, Float] = [:]   // Float as VALUE — allowed
  println(int.to_string(map.len(m)))
}
```

## Fix-it 判定

**not-fixable** — 此错误报告的是自动重写无法决定的语义／设计问题。（`mechanical` = 无人值守的修复器可以应用重写；`conditional` = 建议的修复需要审查；`not-fixable` = 不存在自动重写。遵循 #1486 的适用性原则。）
