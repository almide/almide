Function called by name is not in scope.

## Common cases

```almide
foo()                                  // foo is not defined
list.lengt(xs)                         // typo: should be list.len
my_module.something()                  // forgot to import my_module
```

## Cross-language idiom hallucinations (with `try:` snippets)

### An unresolved method-style call

Almide supports UFCS calls such as `s.to_upper()` when the receiver type
and an in-scope function resolve the call. An unknown or ambiguous method
name still needs repair. The explicit forms `string.to_upper(s)` and
`s |> string.to_upper` avoid relying on method lookup; bare `s.to_upper`
is not a call (see [E013](../../../../diagnostics/E013.md)).

### `int.gt(a, b)` / `int.lt` / `int.eq` / similar comparison functions

Almide uses operators for comparison; there is no `int.gt`.

```
try:
    // Almide uses operators, not comparison functions:
    //   int.gt(a, b)   →  a > b
    //   int.lt(a, b)   →  a < b
    //   int.gte(a, b)  →  a >= b
    //   int.lte(a, b)  →  a <= b
    //   int.eq(a, b)   →  a == b
    //   int.neq(a, b)  →  a != b
```

`almide fix` auto-applies this rewrite (`int.gt(n, 0)` → `n > 0`).

### `int.sqrt(n)` (doesn't exist — only `math.sqrt`)

```
try:
    // Almide has math.sqrt; int.sqrt doesn't exist.
    // Convert → sqrt → (optionally) convert back:
    let root_f = math.sqrt(float.from(n))          // Float
    let root_i = int.from_saturating(root_f)       // Int (truncates)
```

### Other common renames

| User wrote | Almide is | Auto-fixable? |
|---|---|---|
| `list.size` | `list.len` | review suggestion |
| `list.head(xs)` | `list.first(xs)` | review suggestion |
| `string.substring` | `string.slice` | review suggestion |
| `string.to_uppercase` | `string.to_upper` | review suggestion |
| `string.from_chars` | `list.join(chars, "")` | hint only |

## Fix (general)

- Check spelling. Fuzzy "Did you mean ...?" suggestions require review;
  they are not machine-applicable merely because the names are close.
- Check imports. The authoritative auto-import set is
  `AUTO_IMPORT_BUNDLED` in `crates/almide-types/src/stdlib_info.rs`.
  For example, `bytes` and `datetime` are auto-imported; `env`, `io`,
  `random`, `regex` and `testing` require explicit imports.
- `list.count` and `list.push` are real functions, not missing-name aliases;
  consult their signatures rather than rewriting them to `list.len` or `+`.
- For your own modules: `import self.<sub>` and call as `<sub>.fn()`,
  or selective import `import self.<sub>.{fn1, fn2}`.
- Run `almide ide outline @stdlib/<module>` to see the authoritative
  API list for a stdlib module.

## Fix-it verdict

**mechanical** — for a spelling a dialect epoch removed whose ledger rewrite keeps the call's argument list (`ffi.address(b)` → `ffi.region(b)`, `proofs/dialect-epochs.toml`), renaming the callee is the whole edit; every other E002 is **conditional** — the nearest-name suggestion is usually right but is a guess. (`mechanical` = an unattended fixer may apply the
rewrite; `conditional` = a suggested fix needs review; `not-fixable` = no
automatic rewrite exists. #1486's applicability doctrine.)
