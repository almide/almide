# E071 — 回数指定ループ内では割り当て不可

[![English](https://img.shields.io/badge/English-d0d7de?style=flat-square)](E071.md) [![日本語](https://img.shields.io/badge/%E6%97%A5%E6%9C%AC%E8%AA%9E-24292f?style=flat-square)](E071.ja.md) [![简体中文](https://img.shields.io/badge/%E7%AE%80%E4%BD%93%E4%B8%AD%E6%96%87-d0d7de?style=flat-square)](E071.zh-CN.md)



> 原文：[`docs/diagnostics/E071.md`](https://github.com/almide/almide/blob/9a95b28519b90ae535dc9918bfed04805dc4675c/docs/diagnostics/E071.md)、固定コミット `9a95b285`。読者向けの非規範的な翻訳であり、CLI の診断出力は英語のまま。

`@bounded` 属性（ALS §B、bounded プロファイル）は、属性を付けた関数内でチェッカーが受理する範囲を制限する。時間と記憶領域が静的に有界であること、閉じた非循環の呼び出しグラフ、ケイパビリティで制限されたエフェクトである。E071 は、`@bounded` 関数の回数指定ループ内でのリスト／マップ／文字列の構築、連結、push、クロージャー作成を拒否する。

```
error[E071]: ... is not admissible in a @bounded function
```

```almide check-fail=E071
@bounded
fn squares() -> List[Int] = {
  var xs: List[Int] = []
  for i in 0..<8 { xs = xs + [i * i] }
  xs
}

fn main() -> Unit = println("bounded")
```

## 修正

ループ前に割り当て、各反復では割り当てを行わない。スカラーを累積する、サイズを先に確保した記憶領域へ書き込む、または構築をループ外に移す。

```almide
@bounded
fn sum_of_squares() -> Int = {
  var acc = 0
  for i in 0..<8 { acc = acc + i * i }
  acc
}

fn main() -> Unit = println("bounded")
```

この規則が適用されるのは `@bounded` 関数の内部だけであり、属性を取り除くと、この拒否もなくなる（プロファイルはサブセットであって方言ではない：ALS-B2）。

## Fix-it 判定

**conditional** — 診断のヒントは許容される形式を示す。拒否された形式をどの表記に置き換えるかは、そのコードが何をしていたかによる。
