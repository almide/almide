# E044 — main() は Unit を返す

[![English](https://img.shields.io/badge/English-d0d7de?style=flat-square)](E044.md) [![日本語](https://img.shields.io/badge/%E6%97%A5%E6%9C%AC%E8%AA%9E-24292f?style=flat-square)](E044.ja.md) [![简体中文](https://img.shields.io/badge/%E7%AE%80%E4%BD%93%E4%B8%AD%E6%96%87-d0d7de?style=flat-square)](E044.zh-CN.md)



> 原文：[`docs/diagnostics/E044.md`](https://github.com/almide/almide/blob/9a95b28519b90ae535dc9918bfed04805dc4675c/docs/diagnostics/E044.md)、固定コミット `9a95b285`。読者向けの非規範的な翻訳であり、CLI の診断出力は英語のまま。

純粋な `main` は `Unit` を宣言する。プログラムの結果は出力であり戻り値ではない。C/Go 風の `fn main() -> Int` は構造上の型検査を通過するが、エントリーはそのまま出力される。ネイティブドライバーは `pub fn main() -> i64` を生成し、Rust が拒否していた（`main` が返せるのは `Termination` 型だけ）。言語が一度もサポートしていないシグネチャなのに、コンパイラを原因とするエラー（「codegen produced invalid Rust — this is an Almide bug」）として現れた。チェッカーは現在、最初の段階でこれを拒否する（#912 の診断不一致の観点で発見）。

```almide
fn add(x: Int, y: Int) -> Int = x + y
fn main() -> Int = add(1, 2)   // ← E044
```

エフェクト付き `main` は対象外。`effect fn main() -> T` は carrier ラッパーを通り、Result をアンラップして Ok のペイロードを破棄するため、任意の `T` が許される。

<a id="fix"></a>

## 修正

値を出力するか、プロセスの終了コードを明示的に設定する。

```almide
fn add(x: Int, y: Int) -> Int = x + y

fn main() -> Unit = println("${add(1, 2)}")
```

```almide
import process

effect fn main() -> Unit = {
  process.exit(3)
}
```
