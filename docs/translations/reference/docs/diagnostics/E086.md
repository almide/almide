# E086 — a value would outlive its scoped allocation

[![English](https://img.shields.io/badge/English-24292f?style=flat-square)](E086.md) [![日本語](https://img.shields.io/badge/%E6%97%A5%E6%9C%AC%E8%AA%9E-d0d7de?style=flat-square)](E086.ja.md) [![简体中文](https://img.shields.io/badge/%E7%AE%80%E4%BD%93%E4%B8%AD%E6%96%87-d0d7de?style=flat-square)](E086.zh-CN.md)

A `scoped { … }` block declares where its storage ends. E086 rejects a program
in which a value built inside the block would still be needed after it: the
block's own value, or a write to a binding declared outside it.

```
error[E086]: `tree` would outlive its scoped allocation
  = allocated at analysis.almd:8:16
  = scope ends at analysis.almd:10:3
  hint: compute and return the scalar summary inside the scope
```

The `allocated at` row names where the value was built (the `let` that bound
it, when the block's value is a name), and `scope ends at` names the closing
brace. Both are facts the reader needs to place the error; the `hint:` row is
the one action.

```almide check-fail=E086
type Tree = Leaf | Node(Tree, Tree)

scoped fn make(depth: Int) -> Tree =
  if depth == 0 then Leaf else Node(make(depth - 1), make(depth - 1))

fn analysis(depth: Int) -> Tree =
  scoped {
    let tree = make(depth)
    tree
  }

effect fn main() -> Unit = println("${analysis(2)}")
```

## The fix

Compute the summary inside the scope and let the scalar cross the boundary.

```almide check
type Tree = Leaf | Node(Tree, Tree)

scoped fn make(depth: Int) -> Tree =
  if depth == 0 then Leaf else Node(make(depth - 1), make(depth - 1))

scoped fn count(t: Tree) -> Int =
  match t {
    Leaf => 1,
    Node(l, r) => 1 + count(l) + count(r),
  }

fn analysis(depth: Int) -> Int =
  scoped {
    let tree = make(depth)
    count(tree)
  }

effect fn main() -> Unit = println(int.to_string(analysis(2)))
```

A write to an outer binding is the same rule seen from the other side: make
the write the block's value (`total = scoped { … }`) instead of writing from
inside it.

What may cross the boundary in stage 1: `Int`, `Float`, `Bool`, `Unit`.
`String` and `T!` are refused rather than silently copied — the design's
detach rule (a fresh String built from detached bytes may leave) is not
realized on the structural wasm leg yet, and a rule that only one leg honours
would be worse than a refusal (docs/specs/scoped.md).

## Fix-it verdict

**conditional** — the summary that should cross the boundary is the author's
choice; the compiler names the value and the boundary, never invents the fold.
