# E076 — `@bounded` のエフェクトはケイパビリティで制限される

[![English](https://img.shields.io/badge/English-d0d7de?style=flat-square)](E076.md) [![日本語](https://img.shields.io/badge/%E6%97%A5%E6%9C%AC%E8%AA%9E-24292f?style=flat-square)](E076.ja.md) [![简体中文](https://img.shields.io/badge/%E7%AE%80%E4%BD%93%E4%B8%AD%E6%96%87-d0d7de?style=flat-square)](E076.zh-CN.md)



> 原文：[`docs/diagnostics/E076.md`](https://github.com/almide/almide/blob/9a95b28519b90ae535dc9918bfed04805dc4675c/docs/diagnostics/E076.md)、固定コミット `9a95b285`。読者向けの非規範的な翻訳であり、CLI の診断出力は英語のまま。

`@bounded` 属性（ALS §B、bounded プロファイル）は、属性を付けた関数内でチェッカーが受理する範囲を制限する。時間と記憶領域が静的に有界であること、閉じた非循環の呼び出しグラフ、ケイパビリティで制限されたエフェクトである。E076 は、`@bounded` 関数内で、プロファイルの宣言済みケイパビリティ外のエフェクト（env/fs/http/net/process/random などのホストに到達するモジュール、または `fan.*` のスケジューリング）を拒否する。

```
error[E076]: ... is not admissible in a @bounded function
```

```almide check-fail=E076
import env

@bounded
effect fn which_os() -> String = env.os()

fn main() -> Unit = println("bounded")
```

## 修正

`@bounded` な effect fn の宣言済みケイパビリティは、標準出力のみ（`println` 関数群）である。

```almide
@bounded
effect fn report() -> Unit = println("bounded")

fn main() -> Unit = println("bounded")
```

この規則が適用されるのは `@bounded` 関数の内部だけであり、属性を取り除くと、この拒否もなくなる（プロファイルはサブセットであって方言ではない：ALS-B2）。
