# E117 — `http.typed` 接受没有安全模块拥有的字面量媒体类型

[![English](https://img.shields.io/badge/English-d0d7de?style=flat-square)](E117.md) [![日本語](https://img.shields.io/badge/%E6%97%A5%E6%9C%AC%E8%AA%9E-d0d7de?style=flat-square)](E117.ja.md) [![简体中文](https://img.shields.io/badge/%E7%AE%80%E4%BD%93%E4%B8%AD%E6%96%87-24292f?style=flat-square)](E117.zh-CN.md)



> 原文：[`docs/diagnostics/E117.md`](https://github.com/almide/almide/blob/9a95b28519b90ae535dc9918bfed04805dc4675c/docs/diagnostics/E117.md)，固定提交 `9a95b285`。这是供读者参考的非规范性译文，CLI 诊断输出仍为英文。

`http.typed(media_type, bytes)` 构造声明媒体类型的响应正文（ADR-0032）。媒体类型在此读取，因此必须是字符串字面量、格式正确的 `type/subtype`（参数位于 `;` 后），且不能是浏览器会在其中运行脚本的类型，即 `stdlib/html.almd` 声明为 `@script_capable` 的模式：`text/html` 和 XHTML（由 `html` 拥有）、`image/svg+xml`（由 almide/svg 等包在应用的 `[trust]
media` 授权下拥有）、所有 `*/xml` 和 `+xml` 子类型（尚无所有者，#4310）；也不能是标准库通过 `@media_owns(…)` 拥有的类型。将 `http.typed` 作为值具名引用也会产生 E117。

```almide
import http

fn page(s: String) -> HttpResponse =
  http.response(200, http.typed("text/html", bytes.from_string(s)))   // ← E117
```

```
error[E117]: `http.typed`: `text/html` runs script in a browser and is owned by `html`: build the body with the `html` builders, whose type serves it
```

<a id="fix"></a>

## 修复

```almide
import html
import http

fn page(s: String) -> HttpResponse = http.response(200, html.escape(s))
```

在运行时选择类型的程序，应在每个选择位置写出对应类型：`match ext { "css" => http.typed("text/css", b), … }`。

<a id="why"></a>

## 原因

字面量是检查器唯一能判定的实参，在此判定意味着运行时没有媒体类型清单；已拥有类型的集合是安全模块声明的并集。

<a id="fix-it-verdict"></a>

## Fix-it 判定

**not-fixable**：页面需要哪个构造器、程序提供哪些字面量类型，是有关程序的决策。（`mechanical` = 无人值守的修复工具可以应用改写；`conditional` = 建议的修复需要审查；`not-fixable` = 不存在自动改写。#1486 的适用性原则。）
