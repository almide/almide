# E020 — 类型声明冲突

[![English](https://img.shields.io/badge/English-d0d7de?style=flat-square)](E020.md) [![日本語](https://img.shields.io/badge/%E6%97%A5%E6%9C%AC%E8%AA%9E-d0d7de?style=flat-square)](E020.ja.md) [![简体中文](https://img.shields.io/badge/%E7%AE%80%E4%BD%93%E4%B8%AD%E6%96%87-24292f?style=flat-square)](E020.zh-CN.md)



> 原文：[`docs/diagnostics/E020.md`](https://github.com/almide/almide/blob/9a95b28519b90ae535dc9918bfed04805dc4675c/docs/diagnostics/E020.md)，固定提交 `9a95b285`。这是面向读者的非规范性译文；CLI 诊断输出仍为英语。

checker 在同一模块中发现了针对同一类型身份的冲突声明。不同包可以拥有名称相同但彼此独立的类型；canonicalizer 会限定它们的身份，局部类型可以遮蔽导入的非限定名称，而不会重新定义被导入的类型。

<a id="common-cases"></a>

## 常见情况

```almide
type Config = { name: String }
type Config = { host: String, port: Int }   // E020: 'Config' declared more than once

fn main() -> Unit = println("ok")
```

<a id="fix"></a>

## 修复

删除重复声明，或如果意图是不同类型，则重命名模块中的其中一个类型。

```almide
type AppConfig = { name: String }
type DepConfig = { host: String, port: Int }

fn main() -> Unit = println("ok")
```

<a id="fix-it-verdict"></a>

## Fix-it 判定

**not-fixable** — 错误报告的是自动改写无法判断的语义／设计问题。（`mechanical` = 无人值守的修复器可以应用改写；`conditional` = 建议的修复需要审查；`not-fixable` = 不存在自动改写。#1486 的适用性原则。）
