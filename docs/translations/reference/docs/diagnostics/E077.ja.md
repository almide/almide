# E077 — bounded プロファイルでは Float 演算不可（暫定）

[![English](https://img.shields.io/badge/English-d0d7de?style=flat-square)](E077.md) [![日本語](https://img.shields.io/badge/%E6%97%A5%E6%9C%AC%E8%AA%9E-24292f?style=flat-square)](E077.ja.md) [![简体中文](https://img.shields.io/badge/%E7%AE%80%E4%BD%93%E4%B8%AD%E6%96%87-d0d7de?style=flat-square)](E077.zh-CN.md)



> 原文：[`docs/diagnostics/E077.md`](https://github.com/almide/almide/blob/9a95b28519b90ae535dc9918bfed04805dc4675c/docs/diagnostics/E077.md)、固定コミット `9a95b285`。読者向けの非規範的な翻訳であり、CLI の診断出力は英語のまま。

`@bounded` 属性（ALS §B、bounded プロファイル）は、属性を付けた関数内でチェッカーが受理する範囲を制限する。時間と記憶領域が静的に有界であること、閉じた非循環の呼び出しグラフ、ケイパビリティで制限されたエフェクトである。E077 は、`@bounded` 関数内での Float 演算子（算術または比較）、または Float 引数を使って計算する標準ライブラリ呼び出しを拒否する。

```
error[E077]: ... is not admissible in a @bounded function
```

```almide check-fail=E077
@bounded
fn scale(x: Float) -> Float = x * 2.0

fn main() -> Unit = println("bounded")
```

<a id="the-fix"></a>

## 修正

このプロファイル内では Int 算術に限定する。Float 値の保持や受け渡しはできるが、計算はできない。この規則は、認証対象の基盤が Float 命令セットを備えるまでの暫定規則である（ALS-B10）。

```almide
@bounded
fn scale_deci(x: Int) -> Int = x * 2

fn main() -> Unit = println("bounded")
```

この規則が適用されるのは `@bounded` 関数の内部だけであり、属性を取り除くと、この拒否もなくなる（プロファイルはサブセットであって方言ではない：ALS-B2）。
