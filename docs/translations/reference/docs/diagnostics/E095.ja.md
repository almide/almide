# E095 — `http.serve` に渡すアプリがローカル変数を読む

[![English](https://img.shields.io/badge/English-d0d7de?style=flat-square)](E095.md) [![日本語](https://img.shields.io/badge/%E6%97%A5%E6%9C%AC%E8%AA%9E-24292f?style=flat-square)](E095.ja.md) [![简体中文](https://img.shields.io/badge/%E7%AE%80%E4%BD%93%E4%B8%AD%E6%96%87-d0d7de?style=flat-square)](E095.zh-CN.md)



> 原文: [E095.md @ 9a95b285](https://github.com/almide/almide/blob/9a95b28519b90ae535dc9918bfed04805dc4675c/docs/diagnostics/E095.md)。これは読者向けの非規範的な翻訳です。CLI に埋め込まれる診断解説は英語原文のままです。

`http.serve`（および `http.serve_with_limits`）の引数は**アプリ**であり、*インスタンス内で閉じている*必要があります。自分で束縛せずに読み取る名前はすべて、fn、トップレベルの `let`、型、コンストラクターといったトップレベル項目でなければなりません。`serve` を呼ぶ fn の `let`、`var`、引数（通常は main のローカル変数）は拒否されます。

アプリは複数インスタンスで動きます。ネイティブではワーカースレッドごと、wasi:http エクスポートホストではリクエストごとに1つで、後者は `main` を一度も実行しません。main のローカル変数はそのいずれにも存在しないため、main が `serve` の前に計算した値をリクエストから見せることはできません。

```almide
import http
import random

effect fn main() -> Unit = {
  let boot = random.int(1, 1000000)
  http.serve(8080, (req) => http.response(200, "boot=${boot}"))!   // ← E095: captures `boot`
}
```

main 内で作ったルーターもローカルです。

```almide
import http

effect fn main() -> Unit = {
  let app = http.router([http.route("GET /", (req) => http.response(200, "home"))])!
  http.serve(8080, app)!                                           // ← E095: captures `app`
}
```

ハンドラーの引数、本体内の `let`、入れ子 lambda 自身の引数など、アプリが自分で束縛する名前は問題ありません。トップレベルの fn と `let`、インポートした項目、標準ライブラリも同様です。自分の引数を `http.serve` に渡す fn（`effect fn serve_on(port: Int, h: HttpHandler) = http.serve(port, h)!`）は、この規則を呼び出し元へ移します。各呼び出し元が渡すアプリを、書かれた場所で検査します。

<a id="diagnostic"></a>

## 診断

```
error[E095]: the app passed to http.serve captures `boot`, a local of main
  in the app passed to http.serve
  hint: the app runs in several instances — one per worker natively, one per request on a wasi:http host — and main's locals do not exist there. Make `boot` a top-level `let`, or compute it inside the handler.
```

エラーは、アプリがキャプチャする各ローカル変数の最初の読み取りを指します。

<a id="fix"></a>

## 修正

- プログラムのテキストで固定される値はトップレベルの `let` にします。トップレベルの初期化式は effect fn を呼べないため、すべてのインスタンスで同じになります。
  ```almide
  import http

  let app = http.router([http.route("GET /", (req) => http.response(200, "home"))])

  effect fn main() -> Unit = http.serve(8080, app!)!
  ```
  `router` は `Result` を返し、トップレベルの初期化式では `!` が許されないため、main がサービスに渡す場所で `app!` と書きます。
- 実行に依存する値（乱数の取得、時刻の読み取り）は、リクエストごとにハンドラー内で計算します。

<a id="why"></a>

## 理由

ADR-0020 §5.2。C-367 は以前、main が `serve` の前に計算した値が、その実行のすべてのリクエストで同じだと約束していました。複数インスタンスでアプリを動かすホストはこの約束を守れないため、約束は廃止され、それに依存していた形がこのエラーになりました。

## Fix-it 判定

**conditional** — 値をトップレベルの `let` に移せるのは実行に依存しない場合だけです。実行依存の値はハンドラー内で計算する必要があり、これは作者の選択です。（`mechanical` = 無人の書き換え、`conditional` = 修正案にレビューが必要、`not-fixable` = 自動書き換えは存在しません。#1486 の適用可能性の原則。）
