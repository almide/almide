# E072 — no `break`/`continue` in a `@bounded` loop

The `@bounded` attribute (ALS §B, the bounded profile) narrows what the
checker admits inside the attributed function: statically bounded time and
storage, a closed acyclic call graph, capability-bounded effects. E072
rejects an early exit from a counted loop body in a `@bounded` function.

```
error[E072]: ... is not admissible in a @bounded function
```

```almide check-fail=E072
@bounded
fn first_over(limit: Int) -> Int = {
  var found = 0
  for i in 0..<100 {
    if i * i > limit then break
    found = i
  }
  found
}

fn main() -> Unit = println("bounded")
```

## The fix

A counted loop has a single exit (the MISRA discipline): run every iteration and select with a branch instead of exiting early.

```almide
@bounded
fn count_under(limit: Int) -> Int = {
  var found = 0
  for i in 0..<100 {
    found = if i * i > limit then found else i
  }
  found
}

fn main() -> Unit = println("bounded")
```

The rule binds only inside `@bounded` functions — removing the attribute
removes the rejection (the profile is a subset, not a dialect: ALS-B2).

## Fix-it verdict

**conditional** — the diagnostic's hint names the admissible form; which
spelling replaces the rejected one depends on what the code was doing.
