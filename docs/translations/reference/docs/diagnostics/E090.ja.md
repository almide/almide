# E090 — `@extern(c)` シグネチャに C 表現がない

[![English](https://img.shields.io/badge/English-d0d7de?style=flat-square)](E090.md) [![日本語](https://img.shields.io/badge/%E6%97%A5%E6%9C%AC%E8%AA%9E-24292f?style=flat-square)](E090.ja.md) [![简体中文](https://img.shields.io/badge/%E7%AE%80%E4%BD%93%E4%B8%AD%E6%96%87-d0d7de?style=flat-square)](E090.zh-CN.md)



> 原文：[`docs/diagnostics/E090.md`](https://github.com/almide/almide/blob/9a95b28519b90ae535dc9918bfed04805dc4675c/docs/diagnostics/E090.md)、固定コミット `9a95b285`。読者向けの非規範的な翻訳であり、CLI の診断出力は英語のまま。

`@extern(c, "lib", "fn")` は C 関数を束縛する。その境界を越えられるのは C 形式を持つ値だけ。表は `almide_lang::types::extern_abi` にあり、チェッカーと Rust renderer の両方が読む。

| Almide | C 側 | 注記 |
|---|---|---|
| `Int` | `int`（`i32`） | 双方向とも `as` で縮小 |
| `Int8`..`Int64`、`UInt8`..`UInt64` | `i8`..`i64`、`u8`..`u64` | 同じ幅 |
| `Float` / `Float64`、`Float32` | `double`、`float` | |
| `Bool` | `int` | 外向きは `1` / `0`、戻りは `!= 0` |
| `Handle` | `*mut u8` | 不透明な外部 token（`FILE*`、`sqlite3*`）。`@extern` fn に戻して渡すだけ |
| `Region`（パラメーター） | `uint8_t *buf, size_t len` | C 引数は二つ：基底と runtime が保持する長さ。呼び出し側が記述した長さではない（[ADR-0031](../../../../adr/0031-raw-pointers-carry-provenance.md) D3） |
| `Region`（戻り値） | `uint8_t *` | 宣言に `@region(len = …, release = "…")` がある場合のみ（D2）。`len` バイトの読み取り専用 Region。最後のコピーが drop されると `release` で解放する（D6） |
| `String`（パラメーターのみ） | `*const u8` | 最初の NUL までのテキストを NUL 終端でコピーし、呼び出し中有効 |
| `Unit`（戻り値のみ） | `void` | |

その他には C 形式がなく、`mut` パラメーターにもない（C は呼び出し元の `var` に新しい値を書き戻せない）。リスト、`Bytes`、map、set、record、variant、`Option`、`Result`、tuple、fn 値、および解放する所有者のいない `String` 戻り値が含まれる。以前はそのような宣言が `almide check` を通り、型を debug テキストとして記述したラッパーが native ビルドの rustc で失敗した。E090 は検査時にその失敗を報告する。

```almide
@extern(c, "c", "sum_all")
fn sum_all(xs: List[Int]) -> Int = _   // ← E090: parameter 'xs' has type List[Int]
```

```
error[E090]: @extern(c) fn 'sum_all': parameter 'xs' has type List[Int], which has no C representation
  hint: an @extern(c) parameter is one of Int, Int8..Int64, UInt8..UInt64, Float, Float32, Float64, Bool, String, Handle, Region;
        bind it through an `@extern(rust, "crate::host", "f")` fn in `native/*.rs` instead, …
```

表外の戻り値には、戻り値の一覧を示す。

```
  hint: an @extern(c) return is one of Int, Int8..Int64, UInt8..UInt64, Float, Float32, Float64, Bool, Handle, Unit, and Region with `@region(len = …, release = "…")`; …
```

<a id="a-region-return-needs-its-length"></a>

### `Region` 戻り値には長さが必要

プログラムが読み出す外部ポインターは `Region` であり、宣言は長さを示せる唯一の場所。`@region(len = …, release = "…")` がなければ戻り値は E090 となる。

```almide
import ffi

@extern(c, "z", "zbuf_new")
fn zbuf_new(n: Int) -> Region = _   // ← E090: a Region return needs its length
```

```
error[E090]: @extern(c) fn 'zbuf_new': a Region return needs the length the foreign function returns
  hint: state it on the declaration: `@region(len = n, release = "free_fn")`, with `n` a parameter or an integer, and `free_fn` the C function that frees the buffer — or return `Handle` and read it through accessor functions (ADR-0031 D2)
```

`len` は整数型パラメーターの名前、または非負整数リテラル。`release` は C 関数名の文字列。不正な句（`len` が存在しないパラメーターを指す、`release` の欠落、未知の引数、`Region` を返さない fn の `@region`）も E090 となる。

<a id="fix"></a>

## 修正

スカラー、`Handle`、`Region` を渡すか、Rust 経由で束縛する。プログラムが読む外部バッファーは長さ付きで宣言する。

```almide
import ffi

@extern(c, "z", "zbuf_new")
@region(len = n, release = "zbuf_free")
fn zbuf_new(n: Int) -> Region = _

@extern(c, "z", "zfill")
fn zfill(buf: Region, byte: Int) -> Unit = _   // C: void zfill(uint8_t *buf, size_t len, int byte)
```

不透明な外部オブジェクトは `Handle` とし、ライブラリ自身の関数に戻して渡す。

```almide
@extern(c, "sqlite3", "sqlite3_close")
fn db_close(db: Handle) -> Int = _
```

`@extern(rust)` fn は Almide 値を通常の Rust 型（`&[i64]`、`&[u8]`、`&str`、`&Record`、…）で受け取る。表は [module-system.md §11.1](../../../../specs/module-system.md) にある。`native/*.rs` 本体で変換し、C 関数を直接呼べる。

```almide
@extern(rust, "crate::host", "sum_all")
fn sum_all(xs: List[Int]) -> Int = _   // native/host.rs: pub fn sum_all(xs: &[i64]) -> i64
```

<a id="fix-it-verdict"></a>

## Fix-it 判定

**not-fixable**：修正は新しい `@extern(rust)` shim と `native/*.rs` 内のホスト関数、異なる C prototype、または外部バッファーの長さであり、分かるのは binding の作者だけ。宣言だけではどれも決まらない。コンパイラは問題の型と表を示し、シグネチャを書き換えない。

検査対象は native ビルドが束縛する属性、つまり `rust` / `rs` / `c` を指定する最初の `@extern`。

fixture：`tests/diagnostics/e090-*`。マトリクスゲート：`tests/extern_rust_abi_test.rs`（Region の行 `a_region_crosses_c_as_pointer_and_length_and_is_released_once`、`a_region_return_without_a_region_clause_is_e090` を含む）。
