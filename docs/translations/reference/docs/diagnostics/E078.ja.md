# E078 — 回数指定ループ内では早期脱出不可

[![English](https://img.shields.io/badge/English-d0d7de?style=flat-square)](E078.md) [![日本語](https://img.shields.io/badge/%E6%97%A5%E6%9C%AC%E8%AA%9E-24292f?style=flat-square)](E078.ja.md) [![简体中文](https://img.shields.io/badge/%E7%AE%80%E4%BD%93%E4%B8%AD%E6%96%87-d0d7de?style=flat-square)](E078.zh-CN.md)



> 原文：[`docs/diagnostics/E078.md`](https://github.com/almide/almide/blob/9a95b28519b90ae535dc9918bfed04805dc4675c/docs/diagnostics/E078.md)、固定コミット `9a95b285`。読者向けの非規範的な翻訳であり、CLI の診断出力は英語のまま。

`@bounded` 属性（ALS §B、bounded プロファイル）は、属性を付けた関数内でチェッカーが受理する範囲を制限する。時間と記憶領域が静的に有界であること、閉じた非循環の呼び出しグラフ、ケイパビリティで制限されたエフェクトである。E078 は、`@bounded` 関数の回数指定ループ本体内での `!` による伝搬、または `guard` を拒否する。

```
error[E078]: ... is not admissible in a @bounded function
```

```almide check-fail=E078
@bounded
effect fn sum_first(xs: List[Int]) -> Int! = {
  var acc = 0
  for i in 0..<3 { acc = acc + list.get(xs, i)! }
  ok(acc)
}

fn main() -> Unit = println("bounded")
```

<a id="the-fix"></a>

## 修正

伝搬や guard はループ外で行う。ループ内では `??` で既定値を与える。ループ途中の脱出は反復ごとの後処理を飛ばし、厳密な反復回数を弱めてしまう。

```almide
@bounded
fn sum_first(xs: List[Int]) -> Int = {
  var acc = 0
  for i in 0..<3 { acc = acc + (list.get(xs, i) ?? 0) }
  acc
}

fn main() -> Unit = println("bounded")
```

この規則が適用されるのは `@bounded` 関数の内部だけであり、属性を取り除くと、この拒否もなくなる（プロファイルはサブセットであって方言ではない：ALS-B2）。
