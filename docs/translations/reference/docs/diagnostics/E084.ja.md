# E084 — 終了ステータス範囲外の終了コードリテラル

[![English](https://img.shields.io/badge/English-d0d7de?style=flat-square)](E084.md) [![日本語](https://img.shields.io/badge/%E6%97%A5%E6%9C%AC%E8%AA%9E-24292f?style=flat-square)](E084.ja.md) [![简体中文](https://img.shields.io/badge/%E7%AE%80%E4%BD%93%E4%B8%AD%E6%96%87-d0d7de?style=flat-square)](E084.zh-CN.md)



> 原文：[`docs/diagnostics/E084.md`](https://github.com/almide/almide/blob/9a95b28519b90ae535dc9918bfed04805dc4675c/docs/diagnostics/E084.md)、固定コミット `9a95b285`。読者向けの非規範的な翻訳であり、CLI の診断出力は英語のまま。

`process.exit` は `0` から `255` までの POSIX 終了ステータスを受け取る。直接呼び出しがその範囲外の整数リテラルを渡すと、チェッカーは引数を指してプログラムを拒否する。

```almide
import process
effect fn main() -> Unit = process.exit(256) // E084
```

成功には `0`、失敗には `1` から `255` のコードを選ぶ。

```almide
import process
effect fn main() -> Unit = process.exit(1)
```

この検査はモジュール別名、選択 import、パイプ呼び出し、基数付きリテラル、括弧、単項マイナスを含む。計算した引数は実行時に検査する。範囲外なら `Error: exit code must be in 0..=255` で中止する。チェッカーは任意の式を評価せず、関数値変数に格納した別名も追わない。

検査は全ターゲットで同じ。WASI preview-1 ビルド（`almide build --target wasm`、標準 runtime で実行）が届けるのは `0..=125` だけである。126..=255 は検査時ではなく実行時に `Error: a WASI preview-1 build cannot exit with a code in 126..=255` と終了コード 1 で拒否する（C-350）。

Dialect 4（0.63）では `0..=125` の範囲でこの診断を導入した。#2780 以降は再び `0..=255` であり、受理するプログラムが増えるだけなので dialect 変更は不要だった。

<a id="fix-it-verdict"></a>

## Fix-it 判定

**conditional** — 適切な失敗コードはプログラムのプロトコルに依存するため、コンパイラは代替を自動選択しない。
