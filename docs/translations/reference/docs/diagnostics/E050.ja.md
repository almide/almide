# E050 — ローカル `fn` または `let` と選択 import 名の衝突

[![English](https://img.shields.io/badge/English-d0d7de?style=flat-square)](E050.md) [![日本語](https://img.shields.io/badge/%E6%97%A5%E6%9C%AC%E8%AA%9E-24292f?style=flat-square)](E050.ja.md) [![简体中文](https://img.shields.io/badge/%E7%AE%80%E4%BD%93%E4%B8%AD%E6%96%87-d0d7de?style=flat-square)](E050.zh-CN.md)



> 原文：[`docs/diagnostics/E050.md`](https://github.com/almide/almide/blob/9a95b28519b90ae535dc9918bfed04805dc4675c/docs/diagnostics/E050.md)、固定コミット `9a95b285`。読者向けの非規範的な翻訳であり、CLI の診断出力は英語のまま。

ファイルが宣言するトップレベル `fn` と同じ名前が選択 import（`import module.{name}`）でも導入されている。二つは別の関数であり、単独呼び出し `name(x)` は両方を意味できないため、衝突は必ずエラーとなる。トップレベル `let` も同様に衝突する。選択 import はモジュールのトップレベル `let` も束縛する（`import self.k.{LIMIT}`）ため、単独の `LIMIT` は両方の let を指せない（`error[E050]: local let 'LIMIT' collides with selective import
'k.{LIMIT}'`）。

```almide
import json.{parse, stringify}

fn parse(s: String) -> Int = string.len(s)   // ← E050: collides with `json.{parse}`

effect fn main() -> Unit = {
  let n = parse("hi")
  println("${n}")
}
```

この診断以前は、コンパイラが黙って分岐していた。型チェッカーは `parse("hi")` をローカルの `fn parse` として解決し、codegen は `json.parse` として解決した。ある関数で型検査しながら、別の関数を実行する呼び出しだった（edit-locality hunt V2、almide#1425）。ローカル `fn` の追加で既存の呼び出し先が黙って変わってはならない。

<a id="fix"></a>

## 修正

ローカル関数を改名する。

```almide
import json.{parse, stringify}

fn parse_len(s: String) -> Int = string.len(s)
```

または選択 import 一覧からその名前を取り除き、モジュール関数を修飾名で呼ぶ。

```almide
import json

fn parse(s: String) -> Int = string.len(s)

effect fn main() -> Unit = {
  let v = json.parse("[1]") ?? value.null()
  println("${parse(json.stringify(v))}")
}
```

<a id="diagnostic-shape"></a>

## 診断の形

```
error[E050]: local fn 'parse' collides with selective import 'json.{parse}'
  fn parse
  hint: Rename the local fn, or drop 'parse' from the import list and call
        'json.parse' qualified. A bare call must have exactly one meaning.
```

<a id="fix-it-verdict"></a>

## Fix-it 判定

**conditional** — ローカル名の変更と import の解除のどちらにするかは選択である。（`mechanical` = 無人の修正ツールが書き換えを適用できる。`conditional` = 提案された修正はレビューが必要。`not-fixable` = 自動書き換えが存在しない。#1486 の適用可能性の原則。）
