# E088 — 再帰呼び出しが現在の scoped activation を保持する

[![English](https://img.shields.io/badge/English-d0d7de?style=flat-square)](E088.md) [![日本語](https://img.shields.io/badge/%E6%97%A5%E6%9C%AC%E8%AA%9E-24292f?style=flat-square)](E088.ja.md) [![简体中文](https://img.shields.io/badge/%E7%AE%80%E4%BD%93%E4%B8%AD%E6%96%87-d0d7de?style=flat-square)](E088.zh-CN.md)



> 原文：[`docs/diagnostics/E088.md`](https://github.com/almide/almide/blob/9a95b28519b90ae535dc9918bfed04805dc4675c/docs/diagnostics/E088.md)、固定コミット `9a95b285`。読者向けの非規範的な翻訳であり、CLI の診断出力は英語のまま。

最初の `scoped` 部分集合は、通常の worker と**直接末尾再帰**の worker を認める。E088 は、呼び出し中も呼び出し元の activation を生存させる二つの再帰形を拒否する。後に処理が残る単一の自己呼び出しと、scoped worker 間の相互再帰である。

```
error[E088]: recursive call retains the current scoped activation
  = addition remains after the recursive call
  = required by the `scoped` declaration of `count`
  hint: carry the count in an accumulator and return the recursive call
```

注記は呼び出し後に残るもの（`addition`、`a constructor`、`a binding`）を示し、メッセージから accumulator への書き換えが分かるようにする。

```almide check-fail=E088
type Chain = Nil | Cons(Int, Chain)

scoped fn total(c: Chain) -> Int =
  match c {
    Nil => 0,
    Cons(h, t) => h + total(t),
  }

effect fn main() -> Unit = println(int.to_string(scoped { total(Cons(1, Cons(2, Nil))) }))
```

<a id="the-fix"></a>

## 修正

保留中の処理を accumulator に持たせ、再帰呼び出しを arm の結果にする。

```almide check
type Chain = Nil | Cons(Int, Chain)

scoped fn total(c: Chain, acc: Int) -> Int =
  match c {
    Nil => acc,
    Cons(h, t) => total(t, acc + h),
  }

effect fn main() -> Unit = println(int.to_string(scoped { total(Cons(1, Cons(2, Nil)), 0) }))
```

相互再帰（`even_steps` が `odd_steps` を呼び、それが `even_steps` を呼ぶ）も同じ理由で拒否し、二つを一つの直接再帰 worker にまとめて修正する。

**拒否しないもの**：arm が自己呼び出しを二回以上行う worker。`1 + count(l) + count(r)` のような木の走査が該当する。この形には accumulator 書き換えがないため、通常の worker として認める。規則の対象は accumulator で修正できる単一の非末尾呼び出しである。

<a id="fix-it-verdict"></a>

## Fix-it 判定

**conditional** — accumulator パラメーターと初期値は作者が選ぶ。診断は呼び出し後に残る処理と、書くべき形を示す。
