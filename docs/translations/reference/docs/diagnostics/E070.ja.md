# E070 — `@bounded` は回数指定ループを要求する

[![English](https://img.shields.io/badge/English-d0d7de?style=flat-square)](E070.md) [![日本語](https://img.shields.io/badge/%E6%97%A5%E6%9C%AC%E8%AA%9E-24292f?style=flat-square)](E070.ja.md) [![简体中文](https://img.shields.io/badge/%E7%AE%80%E4%BD%93%E4%B8%AD%E6%96%87-d0d7de?style=flat-square)](E070.zh-CN.md)



> 原文：[`docs/diagnostics/E070.md`](https://github.com/almide/almide/blob/9a95b28519b90ae535dc9918bfed04805dc4675c/docs/diagnostics/E070.md)、固定コミット `9a95b285`。読者向けの非規範的な翻訳であり、CLI の診断出力は英語のまま。

`@bounded` 属性（ALS §B、bounded プロファイル）は、属性を付けた関数内でチェッカーが受理する範囲を制限する。時間と記憶領域が静的に有界であること、閉じた非循環の呼び出しグラフ、ケイパビリティで制限されたエフェクトである。E070 は、`@bounded` 関数内の `while` ループ、コンテナーを走査する `for`、実行時の境界を持つ範囲を拒否する。

```
error[E070]: ... is not admissible in a @bounded function
```

```almide check-fail=E070
@bounded
fn count_down(n: Int) -> Int = {
  var k = n
  while k > 0 { k = k - 1 }
  k
}

fn main() -> Unit = println("bounded")
```

## 修正

回数指定範囲を使う。`for i in a..<b` / `for i in a...b` の境界をコンパイル時定数にする。その場合、反復回数は範囲の長さとして静的に分かる。入れ子では回数を掛け合わせる。

```almide
@bounded
fn count_down() -> Int = {
  var k = 3
  for i in 0..<3 { k = k - 1 }
  k
}

fn main() -> Unit = println("bounded")
```

この規則が適用されるのは `@bounded` 関数の内部だけであり、属性を取り除くと、この拒否もなくなる（プロファイルはサブセットであって方言ではない：ALS-B2）。

## Fix-it 判定

**conditional** — 診断のヒントは許容される形式を示す。拒否された形式をどの表記に置き換えるかは、そのコードが何をしていたかによる。
