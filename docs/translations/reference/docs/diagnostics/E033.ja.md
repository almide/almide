# E033 — 定義元モジュールの外で opaque 型を構築した

[![English](https://img.shields.io/badge/English-d0d7de?style=flat-square)](E033.md) [![日本語](https://img.shields.io/badge/%E6%97%A5%E6%9C%AC%E8%AA%9E-24292f?style=flat-square)](E033.ja.md) [![简体中文](https://img.shields.io/badge/%E7%AE%80%E4%BD%93%E4%B8%AD%E6%96%87-d0d7de?style=flat-square)](E033.zh-CN.md)



> 原文：[`docs/diagnostics/E033.md`](https://github.com/almide/almide/blob/9a95b28519b90ae535dc9918bfed04805dc4675c/docs/diagnostics/E033.md)、固定コミット `9a95b285`。読者向けの非規範的な翻訳であり、CLI の診断出力は英語のまま。

opaque 型を定義するモジュールとは別のモジュールから、その型のコンストラクターを呼び出した。opaque 型は、定義元モジュールの公開 API を通じてのみ構築できる。

履歴上の注意：2026-08 までは E008 として報告していた（1つのコードに無関係な2つの意味があった）。現在の E008 は fan の可変キャプチャーエラー専用である。

## よくある例

```almide
// a.almd: mod type Token = String
// module b:
import self.a
let t = a.Token("raw")        // E033: constructing a.Token outside module a
```

## 診断

```
error[E033]: cannot construct opaque type 'Token' outside its defining module
  hint: Use the module's public API to create 'Token' values
```

## 修正

- 定義元モジュールが公開する構築関数を呼び出す。
  ```almide
  let t = a.token_of("raw")
  ```

## 理由

不透明性は不変条件の境界である。定義元モジュールは、外へ渡すすべての値が型の不変条件を満たすことを保証する。外部からのコンストラクター呼び出しは、その保証を迂回してしまう。
