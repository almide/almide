# E087 — an operation is not permitted in a scoped region

[![English](https://img.shields.io/badge/English-24292f?style=flat-square)](E087.md) [![日本語](https://img.shields.io/badge/%E6%97%A5%E6%9C%AC%E8%AA%9E-d0d7de?style=flat-square)](E087.ja.md) [![简体中文](https://img.shields.io/badge/%E7%AE%80%E4%BD%93%E4%B8%AD%E6%96%87-d0d7de?style=flat-square)](E087.zh-CN.md)

Inside a `scoped { … }` block, or in the body of a `scoped fn`, only the
admitted fragment runs (docs/specs/scoped.md). E087 names the construct, says
what it could retain outside the allocation region, and names the declaration
that required the rule.

```
error[E087]: `cache.remember` is not permitted in a scoped function
  = may retain `tree` outside the allocation region (a call across the module boundary)
  = required by the `scoped` declaration of `count`
  hint: compute with scalar operators and `scoped fn` helpers inside the scope
```

What it refuses: a callee that is not declared `scoped`, a module-level
binding (a global), host resources (`println`, an `effect fn`), an unknown
indirect call (a lambda, a function value, a method call on a value), a heap
value captured from outside the block, a type outside the fragment
(`String`, `List`, `Map`, a Result), and the control transfers that leave the
region early (`!`, `?`, `guard`).

```almide check-fail=E087
type Tree = Leaf | Node(Tree, Tree)

scoped fn make(depth: Int) -> Tree =
  if depth == 0 then Leaf else Node(make(depth - 1), make(depth - 1))

fn remember(t: Tree) -> Int = 1

scoped fn summarize(depth: Int) -> Int = remember(make(depth))

effect fn main() -> Unit = println(int.to_string(scoped { summarize(2) }))
```

## The fix

Declare the callee `scoped` (its body is then checked by the same rules), or
do the work inside the scope and let a scalar leave.

```almide check
type Tree = Leaf | Node(Tree, Tree)

scoped fn make(depth: Int) -> Tree =
  if depth == 0 then Leaf else Node(make(depth - 1), make(depth - 1))

scoped fn remember(t: Tree) -> Int =
  match t {
    Leaf => 1,
    Node(l, r) => remember(l) + remember(r),
  }

scoped fn summarize(depth: Int) -> Int = remember(make(depth))

effect fn main() -> Unit = println(int.to_string(scoped { summarize(2) }))
```

For a global, read it outside the block and pass the value in as a parameter.
For output, return the value and print it after the scope.

## Fix-it verdict

**conditional** — the hint names the admissible form (declare the callee
`scoped`, pass the value in, move the effect out), but which of the three
applies depends on what the code was doing.
