# v0.68.0 — ドメイン kernel を stdlib 外へ移し、fan.race を fan.min に置き換える

予定されていた v0.68.0 正式版向けに準備したノートであり、[v0.69.0](../../../../releases/v0.69.0.md) に置き換えられた。準備済み v0.69.0 ノートは、v0.68.0 正式版のタグは作成されなかったと記している。この下書きは履歴として保持され、v0.68.0 正式版が公開された証拠ではない。

予定リリースは [rc1](../../../../releases/v0.68.0-rc1.md) と [rc2](../../../../releases/v0.68.0-rc2.md) の安定化確認に続くもので、**dialect epoch 14** を開く:

- ベンダー・モデル固有のドメイン kernel を stdlib から `almide/llm` と `almide-graphics/nn` パッケージへ移す。
- `fan.race` を `fan.min(clock)` にし、`fan.any` を削除する。代わりに `??` または `list.find_map` を使う。
- `testing.assert_throws` を `testing.assert_aborts` にする。

削除された各綴りには、代替を示す診断が用意された。rc1・rc2 ノートが機能面全体、正しさの修正、性能作業を説明する。以下はすべて rc2 後に取り込まれたもの。

リリースを妨げる問題は 0。v0.67.1 に対する公開 stdlib interface 差分は rc1・rc2 と同じく破壊的で、削除 34、追加 2。すべての削除は `proofs/dialect-epochs.toml` の epoch 14 に宣言されている。

<a id="correctness"></a>

## 正しさ

- **不変束縛を `bytes.as_mut_ptr` へ渡すと、検査時に拒否される**（#3975、issue #3966、C-062）。
  - 以前は `let` 束縛の `Bytes` を `bytes.as_mut_ptr` へ渡しても `almide check` が通った。返された pointer 経由で書くと native では束縛が変わるが wasm では変わらなかった。
  - checker は関数の `@mutating` 宣言を読むようになった。E032 を報告し、束縛を `var` で宣言するよう案内する。

<a id="tooling"></a>

## ツール

- **モジュール interface と stdlib シグネチャ index に `mut` 引数修飾子を表示**し、引数が可変になったことを interface 差分で確認できる（#3889）。
- **`almide build --print-release-rustflags`** がリリースの codegen フラグを出力する。両ビルド経路は一つのリストを使い、bench の比較対象も同じフラグでコンパイルする（#3882）。
- **リリースのタイトルと本文は `docs/releases/<tag>.md` から公開**し、そのファイルがないタグは拒否する（#3884）。

<a id="docs"></a>

## ドキュメント

- 全公開 stdlib 関数の生成済み一ページ index は `docs/stdlib/README.md`（#3884）。
- 三層 stdlib 再設計の設計記録は `docs/roadmap/stdlib-redesign/`（#3957、#3959）。計画のみであり、このリリースで stdlib の機能面は変更しない。

## ゲートと証拠

- benchmark 表は v0.68.0-rc2 の GCE 実行から再記録し、native 行はリリース対象 CPU 用にビルドした比較対象で再測定する（#3882）。
