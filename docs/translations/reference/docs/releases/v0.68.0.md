# v0.68.0 — domain kernels leave the stdlib, and fan.min replaces fan.race

Prepared notes for the planned v0.68.0 final, superseded by [v0.69.0](../../../../releases/v0.69.0.md).
The prepared v0.69.0 notes state that no v0.68.0 final was tagged. This draft
is retained as history, not evidence of a published v0.68.0 final.

The planned release followed the soak of [rc1](../../../../releases/v0.68.0-rc1.md) and [rc2](../../../../releases/v0.68.0-rc2.md). It opens **dialect epoch 14**:

- The vendor- and model-specific domain kernels move from the stdlib into the `almide/llm` and `almide-graphics/nn` packages.
- `fan.race` becomes `fan.min(clock)`, and `fan.any` is removed. Use `??` or `list.find_map` instead.
- `testing.assert_throws` becomes `testing.assert_aborts`.

Every removed spelling is now a diagnostic that names its replacement. The rc1 and rc2 notes describe the full surface, the correctness fixes and the performance work. Everything below landed after rc2.

Release blockers are 0. The public stdlib interface diff against v0.67.1 is the same as in rc1 and rc2: breaking, with 34 removed and 2 added. Every removal is declared in epoch 14 of `proofs/dialect-epochs.toml`.

## Correctness

- **Passing an immutable binding to `bytes.as_mut_ptr` is now rejected at check time** (#3975, issue #3966, C-062).
  - Before, a `let`-bound `Bytes` passed to `bytes.as_mut_ptr` passed `almide check`. A write through the returned pointer then changed the binding on native but not on wasm.
  - The checker now reads the function's `@mutating` declaration. It reports E032 and tells you to declare the binding with `var`.

## Tooling

- **The module interface and the stdlib signature indexes show the `mut` parameter modifier**, so an interface diff can see when a parameter becomes mutable (#3889).
- **`almide build --print-release-rustflags`** prints the release codegen flags. Both build paths take them from one list, and the bench references are compiled with the same flags (#3882).
- **Release titles and bodies are published from `docs/releases/<tag>.md`**, and a tag without that file is refused (#3884).

## Docs

- The generated one-page index of every public stdlib function is in `docs/stdlib/README.md` (#3884).
- The design record of the three-layer stdlib redesign is in `docs/roadmap/stdlib-redesign/` (#3957, #3959). It is a plan only; this release does not change the stdlib surface.

## Gates and evidence

- The nightly ledger-counts run re-measures the fuzz true-green streak, and it counts only completed fuzz nights (#3888).
- The benchmark tables are re-stamped from the v0.68.0-rc2 GCE run, and the native rows are re-measured with the references built for the release target CPU (#3882).
