# v0.68.0——领域 kernel 移出 stdlib，fan.min 替代 fan.race

这是为计划中的 v0.68.0 正式版准备的说明，已由 [v0.69.0](../../../../releases/v0.69.0.md) 取代。准备好的 v0.69.0 说明指出，并未给 v0.68.0 正式版打标签。保留此草稿作为历史，而不是 v0.68.0 正式版已发布的证据。

计划发布接续 [rc1](../../../../releases/v0.68.0-rc1.md) 和 [rc2](../../../../releases/v0.68.0-rc2.md) 的稳定观察期，开启 **dialect epoch 14**：

- 厂商及模型专用的领域 kernel 从 stdlib 移至 `almide/llm` 和 `almide-graphics/nn` 包。
- `fan.race` 改为 `fan.min(clock)`，移除 `fan.any`。改用 `??` 或 `list.find_map`。
- `testing.assert_throws` 改为 `testing.assert_aborts`。

每种被移除的拼写现在都有指明替代项的诊断。rc1、rc2 说明描述完整功能面、正确性修复和性能工作。下方内容均在 rc2 之后合入。

发布阻碍为 0。相对 v0.67.1 的公开 stdlib interface 差分与 rc1、rc2 相同：存在破坏性变化，移除 34 项、新增 2 项。所有移除均在 `proofs/dialect-epochs.toml` 的 epoch 14 中声明。

<a id="correctness"></a>

## 正确性

- **将不可变绑定传给 `bytes.as_mut_ptr` 现在会在检查时拒绝**（#3975，issue #3966，C-062）。
  - 之前，将 `let` 绑定的 `Bytes` 传给 `bytes.as_mut_ptr` 能通过 `almide check`。随后经返回的 pointer 写入会在 native 改变绑定，但 wasm 不会。
  - checker 现在读取函数的 `@mutating` 声明，报告 E032，并提示用 `var` 声明绑定。

<a id="tooling"></a>

## 工具

- **模块 interface 与 stdlib 签名 index 显示 `mut` 参数修饰符**，因此 interface 差分能看出参数何时变为可变（#3889）。
- **`almide build --print-release-rustflags`** 输出发布 codegen 标志。两条构建路径使用同一份列表，bench 参考实现也用相同标志编译（#3882）。
- **发布标题与正文从 `docs/releases/<tag>.md` 发布**，缺少该文件的标签会被拒绝（#3884）。

<a id="docs"></a>

## 文档

- 所有公开 stdlib 函数的生成式单页 index 位于 `docs/stdlib/README.md`（#3884）。
- 三层 stdlib 重设计的设计记录位于 `docs/roadmap/stdlib-redesign/`（#3957、#3959）。它只是计划，此发布不改变 stdlib 功能面。
