<a id="change-discipline"></a>

## 変更時の規律

- **観測可能な動作を変更する場合、同じ PR で契約文とその証拠の両方を更新しなければならない。**
- **新しい**動作 = 新しい `C-NNN` + 1個以上のフィクスチャ。
- **差異の解消** = 同じ PR で `status` を `active` に変えてフラグを外す。`flagged-for-revision` の件数はラチェットであり、**減らす**ことしかできない。
- ゲート（`scripts/check-contracts.sh`、CI + lefthook）は、すべての契約に実際の証拠があり、すべてのフィクスチャが対応する契約名を示し、そのリンクが双方向であることを強制する。
- **集計値はスタンプされ、PR ごとには再生成しない。** 以下の「N contracts」の合計（および生成文書が引用する他のすべての合計）は `proofs/ledger-counts.toml` から描画し、`counts:generated` ブロック内に日付を付ける。フィクスチャや契約の PR は各行を再生成し、ブロックはそのままにする。リリースの seal 前、または毎夜の `scripts/check-ledger-counts.sh` が乖離を報告したときに、`bash scripts/gen-ledger-counts.sh` で更新する。

証拠のクラス（弱い → 強い）：`doc-only` < `by-construction` < `fixture` < `fuzz` < `exhaustive` < `lean`。**active** な契約には、`fixture` 以上のクラスの証拠が1個以上必要である。
