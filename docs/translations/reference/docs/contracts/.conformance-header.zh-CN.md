> 从 [contracts.toml](https://github.com/almide/almide/blob/35297a612fb29e3f78f6587aba253aa91d51f466/docs/contracts/contracts.toml) 自动生成。
> 运行 `bash docs/contracts/generate-conformance.sh > docs/contracts/conformance.md` 更新。
>
> 每个规范性 ALS 小节对应一行，列出引用它的契约及执行验证它的可执行测试用例。下列每个用例都在 CI 中运行：`spec/wasm_cross` 用例做 native↔wasm 字节比较，`spec/` 测试文件在两个目标上运行，`tests/diagnostics` 通过检查器框架，`tests/*.rs` 在 cargo 下运行。
> 没有可执行用例的小节会使 `scripts/check-contracts.sh` 失败（每个 active 契约均要求 spec-coverage 及 evidence-class >= fixture），因此本页不可能合规地包含空的 Fixtures 单元格。
> 下方总计行已加盖数值记录（`proofs/ledger-counts.toml`，日期在其块内），仅由 `bash scripts/gen-ledger-counts.sh` 刷新；用例 PR 重新生成各行，但不改动总计行。
