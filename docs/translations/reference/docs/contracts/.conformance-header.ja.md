# ALS 適合性レポート

[![English](https://img.shields.io/badge/English-d0d7de?style=flat-square)](.conformance-header.md) [![日本語](https://img.shields.io/badge/%E6%97%A5%E6%9C%AC%E8%AA%9E-24292f?style=flat-square)](.conformance-header.ja.md) [![简体中文](https://img.shields.io/badge/%E7%AE%80%E4%BD%93%E4%B8%AD%E6%96%87-d0d7de?style=flat-square)](.conformance-header.zh-CN.md)

> 固定した生成用ヘッダーテンプレートの非規範的な参照コピーであり、生成済み適合性レポートでも生成器の入力でもない。原本テンプレートは不変更。引用した再生成コマンドは実行していない。以下の網羅性・CI の説明は原文の主張であり、新たな検証ではない。自動同期しない。 [Source](https://github.com/almide/almide/blob/35297a612fb29e3f78f6587aba253aa91d51f466/docs/contracts/.conformance-header.md)

> [contracts.toml](https://github.com/almide/almide/blob/35297a612fb29e3f78f6587aba253aa91d51f466/docs/contracts/contracts.toml) から自動生成する。
> 更新するには `bash docs/contracts/generate-conformance.sh > docs/contracts/conformance.md` を実行する。
>
> 規範的な ALS の各節につき1行とし、それを引用する契約と、それを実行して確かめるフィクスチャを示す。以下のすべてのフィクスチャは CI で動く。`spec/wasm_cross` のフィクスチャは native↔wasm のバイト比較、`spec/` のテストファイルは両ターゲット、`tests/diagnostics` はチェッカーハーネス、`tests/*.rs` は cargo で実行する。
> 実行可能なフィクスチャのない節は `scripts/check-contracts.sh` に失敗する（すべての active 契約について spec-coverage と evidence-class >= fixture を要求）。したがって、このページに空の Fixtures セルが正当に含まれることはない。
> 以下の合計行はスタンプ済みであり（`proofs/ledger-counts.toml`、ブロック内に日付あり）、`bash scripts/gen-ledger-counts.sh` だけで更新する。フィクスチャの PR は各行を再生成するが、合計行はそのままにする。
