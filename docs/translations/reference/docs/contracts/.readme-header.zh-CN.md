<a id="change-discipline"></a>

## 变更纪律

- **变更任何可观测行为，都必须在同一 PR 中同时更新契约陈述及其证据。**
- **新**行为 = 新 `C-NNN` + 至少1个用例。
- **消除差异** = 同一 PR 中将 `status` 改为 `active` 并移除标记。`flagged-for-revision` 数量是单向约束，只能**下降**。
- 门禁（`scripts/check-contracts.sh`，CI + lefthook）强制要求每项契约都有实际证据、每个用例都指明所属契约，且链接为双向。
- **汇总数量使用已记录值，不随每个 PR 重新生成。** 下方“N contracts”总数（及生成文档引用的其他所有总数）从 `proofs/ledger-counts.toml` 渲染，日期写在其 `counts:generated` 块内。用例或契约 PR 重新生成各行，不改动此块；在发布 seal 前，或每晚 `scripts/check-ledger-counts.sh` 报告偏移时，通过 `bash scripts/gen-ledger-counts.sh` 刷新。

证据类别（弱 → 强）：`doc-only` < `by-construction` < `fixture` < `fuzz` < `exhaustive` < `lean`。**active** 契约必须有至少1项类别不低于 `fixture` 的证据。
