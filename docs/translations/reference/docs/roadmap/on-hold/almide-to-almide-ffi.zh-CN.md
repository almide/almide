<a id="original-thesis"></a>

## 最初构想

almide-lander 可将 Almide 模块导出到 20 种语言。将 **Almide 自身**加入为第 21 个目标，使另一个 Almide 项目可以通过共享库调用已编译的 Almide 库。

```
almide-lander (today):
  mylib.almd → .so/.dylib → Python/Go/Swift/... から呼べる

almide-lander + Almide target:
  mylib.almd → .so/.dylib → Almide から呼べる（@extern wrapper 生成）
```

<a id="why"></a>

## 理由

1. **预编译包分发** — 无需分发源码，只共享二进制。适合企业内部专有库。
2. **有待验证的 capability 边界** — 仅独立编译共享库并不能建立 capability 隔离。同一进程中的原生代码是明确的信任边界；权限分离还需要另外设计并验证 host/process。
3. **复用 almide-lander 现有基础设施** — interface.json 提取、共享库构建、绑定生成机制均可复用。只有面向 Almide 的 codegen 是新增部分。
4. **通向 WASM Component Model 的踏脚石** — 当前是共享库 FFI，将来演进为 WASM 模块间调用。同一个 interface.json 是基础。

<a id="original-generated-code-sketch-not-current-compiler-syntax"></a>

## 最初的生成代码草图（不是当前编译器语法）

**原始 mylib.almd：**
```almide
type Point = { x: Float, y: Float }
type Shape = Circle(Float) | Rect(Float, Float)

fn distance(a: Point, b: Point) -> Float = {
  let dx = a.x - b.x
  let dy = a.y - b.y
  math.sqrt(dx * dx + dy * dy)
}

fn area(shape: Shape) -> Float = match shape {
  Circle(r) => math.pi() * r * r,
  Rect(w, h) => w * h,
}
```

**生成的 almide_mylib/mod.almd：**
```almide
// Auto-generated by almide-lander --lang almide
// Do not edit manually.

type Point = { x: Float, y: Float }
type Shape = Circle(Float) | Rect(Float, Float)

@extern(lib: "almide_mylib", "almide_mylib_distance")
fn distance(a: Point, b: Point) -> Float

@extern(lib: "almide_mylib", "almide_mylib_area")
fn area(shape: Shape) -> Float
```

**consumer 的 app.almd：**
```almide
import mylib

fn main() -> Unit = {
  let a = mylib.Point { x: 0.0, y: 0.0 }
  let b = mylib.Point { x: 3.0, y: 4.0 }
  println(float.to_string(mylib.distance(a, b)))  // 5.0
}
```

<a id="original-implementation-decomposition-generator-now-exists"></a>

## 最初的实现拆分（生成器现已存在）

在 almide-bindgen 中添加 `almide` 目标：

1. **类型映射** — 恒等映射（因为是 Almide → Almide，类型相同）。
2. **函数包装器生成** — 生成 `@extern(lib: "...", "...")` 声明。
3. **C ABI 边界类型转换** — 在以 `--repr-c` 编译的共享库与 Almide 类型之间编组（String ↔ C string、Record ↔ C struct）。

即使双方都是 Almide，C ABI、所有权、错误、buffer 长度边界也不会消失。实现工作量的排序尚未验证。

<a id="original-scope-estimates"></a>

## 最初的规模估计

- **almide-bindgen 侧**：新增 `bindings/almide.almd` 生成器（预计约 200 行）。
- **Almide compiler 侧**：在 `@extern(lib: "...")` 中指定共享库（已有 `@extern`，新增 `lib:` 参数）。
- **almide-lander 侧**：新增 `--lang almide` 选项（利用现有基础设施）。
