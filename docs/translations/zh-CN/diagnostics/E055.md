# E055 — 对 Result 使用 `?.`

[English](../../../diagnostics/E055.md) | [日本語](../../ja/diagnostics/E055.md) | [简体中文](./E055.md)

> 原文：[E055.md @ 9a95b285](https://github.com/almide/almide/blob/9a95b28519b90ae535dc9918bfed04805dc4675c/docs/diagnostics/E055.md)。这是供读者参考的非规范性翻译。CLI 内嵌的诊断说明仍使用英文原文。

可选链运算符按定义仅适用于 Option（ADR-0005：`o?.f ≡ option.map(o, (v) => v.f)`），而 Result 不是 Option：

```almide
type Item = { n: Int }
fn g(r: Result[Item, String]) -> Int? = r?.n   // ← E055
```

## 应改写为什么

先转换或解包——错误会给出以下选择：

```almide
(r?)?.n          // `r?` converts Result → Option (err → none), then chain
(r ?? { n: 0 }).n       // unwrap with a fallback, then access directly
match r { ok(v) => some(v.n), err(_) => none }
```

在此代码出现之前，这种误用只有一行不带代码的 `error:`，`almide explain`、夹具运行框架和覆盖率门禁都无法识别它（#1107 D2）。

## Fix-it 判定

**conditional** — 转换（`(r?)?.f`）还是解包（`?? fb`），取决于意图。（`mechanical` = 无人值守的修复器可以应用重写；`conditional` = 建议的修复需要审查；`not-fixable` = 不存在自动重写。遵循 #1486 的适用性原则。）
