# E032 — 将不可变绑定传给 `mut` 参数

[English](../../../diagnostics/E032.md) | [日本語](../../ja/diagnostics/E032.md) | [简体中文](../../zh-CN/diagnostics/E032.md)

> 原文：[`docs/diagnostics/E032.md`](https://github.com/almide/almide/blob/9a95b28519b90ae535dc9918bfed04805dc4675c/docs/diagnostics/E032.md)，固定提交 `9a95b285`。这是供读者参考的非规范性译文，CLI 诊断输出仍为英文。

调用在被调用方声明 `mut` 参数的位置，传入了不可变绑定（`let`、未声明为 `mut` 的参数）或临时表达式。修改需要一个以 `var` 绑定或 `mut` 参数为根的可变位置。

各类容器的原地写入函数都将接收对象声明为 `mut`：`list.push`、`string.push`、`map.clear`，以及整个 `bytes` 写入函数族——`bytes.push`、`append_*`、`put_*`、`fill`、`clear`、`copy_from`、`copy_within`（字节写入函数自 dialect epoch 5、#2466 起如此）。

历史说明：直到 2026-08，此类问题被报告为 E007（一个代码承载了两种无关含义）；E007 现在仅表示 effect 外的 fan 错误。

## 常见情况

```almide
fn grow(xs: List[Int]) -> Unit = {
  let ys = xs
  list.push(ys, 1)          // E032: `ys` is immutable
}

fn zero(b: Bytes) -> Unit =
  bytes.fill(b, 0)          // E032: parameter `b` is not `mut`

fn main() -> Unit = {
  bytes.append_u8(bytes.new(), 7)   // E032: a temporary has no binding to write back into
}
```

## 诊断

```
error[E032]: cannot pass immutable binding 'ys' to `mut` parameter of list.push()
  hint: Declare 'ys' with `var` instead of `let` to allow mutation (a helper that writes its caller's value takes it as a `mut` parameter instead)

error[E032]: cannot pass immutable binding 'b' to `mut` parameter of bytes.fill()
  hint: 'b' is a parameter, and parameters are immutable: declare it `mut b: Bytes` so the write reaches the caller's value (the caller then passes a `var`), or copy it into a local `var` if the caller must not see the write
```

## 修复

- 本地缓冲区：用 `var` 声明绑定。
  ```almide
  var ys = xs
  list.push(ys, 1)
  ```
- 填充调用方缓冲区的辅助函数：将参数声明为 `mut`，并在调用处传入 `var`。在每个目标上，写入都会传回调用方。
  ```almide
  fn zero(mut b: Bytes) -> Unit = bytes.fill(b, 0)

  fn main() -> Unit = {
    var b = bytes.from_list([1, 2])
    zero(b)
  }
  ```
- 不得修改调用方值的辅助函数：将参数复制到本地 `var`，然后写入副本。
- 对字段／元素而言，*根*绑定必须是 `var` 或 `mut` 参数（`var box` 允许 `list.push(box.items, x)`）。
- 临时表达式不能作为 `mut` 实参，必须先用 `var` 绑定。

## 原因

Almide 具有值语义：`let c = a` 会复制；被调用方只能通过自己声明为 `mut` 的参数触及调用方的绑定。`mut` 参数在生成的 Rust 中 lowering 为 `&mut`，在 wasm 中 lowering 为写回。允许不可变位置或临时位置，要么使 rustc 失败，要么在一个目标上静默修改副本、另一个目标上修改原值；两者都违反“读到什么就执行什么”的契约。#2466 之前，字节写入函数未声明 `mut`，因此写入普通 `Bytes` 参数的辅助函数能编译，native 会写回调用方，而 wasm 不会。
