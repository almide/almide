# E049 — `let ... in <expr>` 是 OCaml/Haskell 语法

[English](../../../diagnostics/E049.md) | [日本語](../../ja/diagnostics/E049.md) | [简体中文](../../zh-CN/diagnostics/E049.md)

> 原文：[`docs/diagnostics/E049.md`](https://github.com/almide/almide/blob/9a95b28519b90ae535dc9918bfed04805dc4675c/docs/diagnostics/E049.md)，固定提交 `9a95b285`。这是面向读者的非规范性译文；CLI 诊断输出仍为英语。

Almide 没有 `in` 关键字。绑定在块内通过换行串联，块的末尾表达式就是它的值，因此 OCaml、Haskell 和 F# 在绑定与主体之间放置的 `in` 在这里没有需要分隔的内容。

```almide
fn sum_digits(n: Int) -> Int =
  let abs_n = int.abs(n)
  in if abs_n == 0 then 0            // ← E049: `let ... in <expr>` is OCaml/Haskell syntax
     else (abs_n % 10) + sum_digits(abs_n / 10)
```

## 修复

删除 `in`。它后面的内容本来就是通过换行串联的后续部分：

```almide
fn sum_digits(n: Int) -> Int =
  let abs_n = int.abs(n)
  if abs_n == 0 then 0
  else (abs_n % 10) + sum_digits(abs_n / 10)
```

多个绑定也一样，一行一个，无需分隔符：

```almide
fn area(w: Int, h: Int) -> Int = {
  let width = int.abs(w)
  let height = int.abs(h)
  width * height
}
```

## 诊断形式

```
error[E049]: `let ... in <expr>` is OCaml/Haskell syntax
  in let ... in
  here: in if abs_n == 0 then 0
  hint: In Almide, multiple lets chain by newlines inside a block — no `in` keyword.
  try: delete the highlighted text (machine-applicable — `almide fix` applies it)
```

fix-it 属于 **machine-applicable**，锚定 `in` 关键字及其后的空白，因此 `almide fix <file>` 会机械地删除每一处，而不触碰其他内容。这是纯粹的写法变换：产出的程序就是 `in` 形式所表达的程序。

## Fix-it 判定

**mechanical** — `let x = e in b` → `{ let x = e; b }` 是精确的。（`mechanical` = 无人值守的修复器可以应用改写；`conditional` = 建议的修复需要审查；`not-fixable` = 不存在自动改写。#1486 的适用性原则。）
