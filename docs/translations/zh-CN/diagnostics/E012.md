# E012 — 重复定义

[English](../../../diagnostics/E012.md) | [日本語](../../ja/diagnostics/E012.md) | [简体中文](../../zh-CN/diagnostics/E012.md)

> 原文：[`docs/diagnostics/E012.md`](https://github.com/almide/almide/blob/9a95b28519b90ae535dc9918bfed04805dc4675c/docs/diagnostics/E012.md)，固定提交 `9a95b285`。这是面向读者的非规范性译文；CLI 诊断输出仍为英语。

模块内两个声明具有同一名称，或文件内两个 test 块具有同一名称。每个名称在其作用域中必须唯一。

## 常见情况

```almide
fn greet(name: String) -> String = "hi ${name}"
fn greet(who: String) -> String = "hello ${who}"    // E012: duplicate fn
```

```almide
test "basic" { assert(1 == 1) }
test "basic" { assert(2 == 2) }                     // E012: duplicate test
```

## 诊断

```
error[E012]: function 'greet' is defined twice in this module
  hint: Rename one of the definitions, or remove the earlier one. Almide requires each function name to be unique within a module.
```

辅助 `note` 指向首次定义，使两个位置都可见。

## 修复

- 重命名其中一个定义，使名称反映实际行为：
  ```almide
  fn greet(name: String) -> String = "hi ${name}"
  fn greet_formal(who: String) -> String = "hello ${who}"
  ```
- 如果其中一个是遗留代码，也可以删除旧的／过时的定义。
- 对于测试：合并为包含两个断言的一个 `test` 块，或以不同案例命名：
  ```almide
  test "basic — 1 equals 1" { assert(1 == 1) }
  test "basic — 2 equals 2" { assert(2 == 2) }
  ```

## 内置函数的名称

使用输出或中止内置函数名称（`println`、`eprintln`、`panic`、`assert`、`assert_eq`、`assert_ne`）的顶层 `fn` 或 `let` 也属于同一错误。内置函数已在所有地方定义，该名称的直接调用总是到达内置函数，因此该声明永远无法运行。

```almide
fn println(s: String) -> Unit = io.print(redact(s) + "\n")   // E012: redefines the builtin 'println'
```

```
error[E012]: top-level fn 'println' redefines the builtin 'println'
  hint: Every call to `println(…)` reaches the builtin, never this declaration. Give it another name (e.g. `my_println`) and call that
```

重命名包装函数（`log_line`、`say`），并使用新名称调用。与内置函数同名的局部 `let` 或参数仍会在自身作用域内遮蔽它，与所有局部绑定一样。

## 为什么不支持重载

Almide 有意拒绝名称重载。重载解析是其他语言中 LLM 混淆的重要来源：同一行源码可能因参数类型、import 和解析规则而指向不同实现。没有重载，每个调用点都没有歧义：`greet(x)` 始终表示作用域中唯一的 `greet`。

如果需要两种相关行为，请使用不同名称（`greet_en`、`greet_formal` 等），或显式接收用于区分的参数。
