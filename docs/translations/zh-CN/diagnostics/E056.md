# E056 — 对 Option 使用 `?` 没有作用（警告）

[English](../../../diagnostics/E056.md) | [日本語](../../ja/diagnostics/E056.md) | [简体中文](./E056.md)

> 原文：[E056.md @ 9a95b285](https://github.com/almide/almide/blob/9a95b28519b90ae535dc9918bfed04805dc4675c/docs/diagnostics/E056.md)。这是供读者参考的非规范性翻译。CLI 内嵌的诊断说明仍使用英文原文。

`?` 将 Result 转换为 Option（`r? ≡ result.to_option(r)`，err → none）。对于已经是 Option 的值，它什么也不转换——表达式是恒等操作——却看起来像做了某件事：

```almide
fn f(o: Int?) -> Int? = o?    // ← E056: `o?` is exactly `o`
```

在此警告之前，这种无操作会静默通过检查（#1107 D3），从而传授了 `?` 会“解包”的错误概括。它不会：解包使用 `?? fallback`、`match`，或 effect fn 内的 `!`。

## 应改写为什么

```almide
fn f(o: Int?) -> Int? = o          // the identity, spelled as one
let v = o ?? 0                     // if you meant to unwrap
```
