# E002 — 未定义的函数

[English](../../../diagnostics/E002.md) | [日本語](../../ja/diagnostics/E002.md) | [简体中文](../../zh-CN/diagnostics/E002.md)

> 原文：[`docs/diagnostics/E002.md`](https://github.com/almide/almide/blob/9a95b28519b90ae535dc9918bfed04805dc4675c/docs/diagnostics/E002.md)，固定提交 `9a95b285`。这是面向读者的非规范性译文；CLI 诊断输出仍为英语。

按名称调用的函数不在作用域中。

## 常见情况

```almide
foo()                                  // foo is not defined
list.lengt(xs)                         // typo: should be list.len
my_module.something()                  // forgot to import my_module
```

## 跨语言惯用法幻觉（附 `try:` 片段）

### 无法解析的方法式调用

当接收者类型与作用域内函数能够解析调用时，Almide 支持 `s.to_upper()` 等 UFCS 调用。未知或歧义的方法名仍需要修复。显式形式 `string.to_upper(s)` 与 `s |> string.to_upper` 不依赖方法查找；单独的 `s.to_upper` 不是调用（参见 [E013](../../../diagnostics/E013.md)）。

### `int.gt(a, b)` / `int.lt` / `int.eq` 等比较函数

Almide 使用运算符进行比较，没有 `int.gt`。

```
try:
    // Almide uses operators, not comparison functions:
    //   int.gt(a, b)   →  a > b
    //   int.lt(a, b)   →  a < b
    //   int.gte(a, b)  →  a >= b
    //   int.lte(a, b)  →  a <= b
    //   int.eq(a, b)   →  a == b
    //   int.neq(a, b)  →  a != b
```

`almide fix` 自动应用此改写（`int.gt(n, 0)` → `n > 0`）。

### `int.sqrt(n)`（不存在——只有 `math.sqrt`）

```
try:
    // Almide has math.sqrt; int.sqrt doesn't exist.
    // Convert → sqrt → (optionally) convert back:
    let root_f = math.sqrt(float.from(n))          // Float
    let root_i = int.from_saturating(root_f)       // Int (truncates)
```

### 其他常见名称差异

| 用户写法 | Almide 写法 | 能否自动修复？ |
|---|---|---|
| `list.size` | `list.len` | 需审查的建议 |
| `list.head(xs)` | `list.first(xs)` | 需审查的建议 |
| `string.substring` | `string.slice` | 需审查的建议 |
| `string.to_uppercase` | `string.to_upper` | 需审查的建议 |
| `string.from_chars` | `list.join(chars, "")` | 仅提示 |

## 修复（通用）

- 检查拼写。模糊匹配的“Did you mean ...?”建议需要审查；不能仅因名称相近就视为 machine-applicable。
- 检查 import。权威的自动导入集合是 `crates/almide-types/src/stdlib_info.rs` 中的 `AUTO_IMPORT_BUNDLED`。例如 `bytes` 和 `datetime` 会自动导入；`env`、`io`、`random`、`regex`、`testing` 需要显式导入。
- `list.count` 和 `list.push` 是真实函数，并非不存在名称的别名；应查阅签名，而不是将其改写为 `list.len` 或 `+`。
- 对自己的模块：使用 `import self.<sub>` 并以 `<sub>.fn()` 调用，或选择性导入 `import self.<sub>.{fn1, fn2}`。
- 运行 `almide ide outline @stdlib/<module>` 查看标准库模块的权威 API 列表。

## Fix-it 判定

**mechanical** — 对于某个 dialect epoch 移除的写法，如果台账中的改写保留调用的参数列表（`ffi.address(b)` → `ffi.region(b)`，`proofs/dialect-epochs.toml`），全部编辑就是重命名被调用方。所有其他 E002 都是 **conditional**：最近名称建议通常正确，但仍是猜测。（`mechanical` = 无人值守的修复器可以应用改写；`conditional` = 建议的修复需要审查；`not-fixable` = 不存在自动改写。#1486 的适用性原则。）
