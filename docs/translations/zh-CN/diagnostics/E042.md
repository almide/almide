# E042 — 此语句丢弃了 Result（must-use）

[English](../../../diagnostics/E042.md) | [日本語](../../ja/diagnostics/E042.md) | [简体中文](../../zh-CN/diagnostics/E042.md)

> 原文：[`docs/diagnostics/E042.md`](https://github.com/almide/almide/blob/9a95b28519b90ae535dc9918bfed04805dc4675c/docs/diagnostics/E042.md)，固定提交 `9a95b285`。这是供读者参考的非规范性译文，CLI 诊断输出仍为英文。

语句位置的 `Result` 类型表达式会丢弃该值，也随之丢弃错误。移除隐式传播后（ADR-0008、[E041](E041.md)），静默丢弃的 Result 将成为失败可以无迹可寻地消失之处，因此所有 fn 种类（effect、fallible、pure、test）都会将其作为检查错误。

## 常见情况

```almide
effect fn main() -> Unit = {
  cleanup(tmp)            // E042 — the err is silently dropped
  fs.write_text(p, s)          // E042
}
```

## 诊断

```
error[E042]: this statement discards a Result — the error would be silently dropped
  try: !          ← a suggestion, not a machine-applicable edit
```

## 修复

按意图选择两种写法：

```almide
cleanup(tmp)!             // propagate the err
let _ = cleanup(tmp)      // discard ON PURPOSE (the explicit-discard spelling)
```

通过兼容的 Result 通道返回的尾部 Result，不属于被丢弃的语句。返回 Unit 的 effect 尾部则可能需要显式传播。对 ok/err 进行 match 同样会消费该值。`let _ =` 与 `map_err` 的 `(_)` 属于相同的有意丢弃方式（ADR-0004 D3）。

## 原因

Rust 在 Result 上以警告形式提供 `#[must_use]`，其生态的 lint 将它提升为拒绝；Swift 要求每个抛出错误的调用前都带 `try`。默认报错是 ADR-0008 D2 选择的更严格方式：静默丢失错误属于 silent-loss 类问题，而滚屏后被忽略的警告会让这种问题随产品发布。
