# E070 — `@bounded` 要求计数循环

[English](../../../diagnostics/E070.md) | [日本語](../../ja/diagnostics/E070.md) | [简体中文](../../zh-CN/diagnostics/E070.md)

> 原文：[`docs/diagnostics/E070.md`](https://github.com/almide/almide/blob/9a95b28519b90ae535dc9918bfed04805dc4675c/docs/diagnostics/E070.md)，固定提交 `9a95b285`。这是供读者参考的非规范性译文，CLI 诊断输出仍为英文。

`@bounded` 属性（ALS §B，bounded 配置）限制检查器在标注函数内允许的内容：静态有界的时间与存储、封闭无环的调用图、受能力约束的 effect。E070 拒绝 `@bounded` 函数内的 `while` 循环、遍历容器的 `for`，或边界在运行时确定的范围。

```
error[E070]: ... is not admissible in a @bounded function
```

```almide check-fail=E070
@bounded
fn count_down(n: Int) -> Int = {
  var k = n
  while k > 0 { k = k - 1 }
  k
}

fn main() -> Unit = println("bounded")
```

## 修复

使用计数范围：`for i in a..<b` / `for i in a...b`，边界必须是编译时常量。迭代次数就是范围长度，可静态确定；嵌套时将次数相乘。

```almide
@bounded
fn count_down() -> Int = {
  var k = 3
  for i in 0..<3 { k = k - 1 }
  k
}

fn main() -> Unit = println("bounded")
```

此规则仅约束 `@bounded` 函数内部；移除属性就会取消这一拒绝（配置是子集而非方言：ALS-B2）。

## Fix-it 判定

**conditional** — 诊断提示指出了允许的形式；用哪种写法替换被拒绝的形式，取决于代码原本要做什么。
