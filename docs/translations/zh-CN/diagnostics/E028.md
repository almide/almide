# E028 — main() 不接受参数

[English](../../../diagnostics/E028.md) | [日本語](../../ja/diagnostics/E028.md) | [简体中文](./E028.md)

> 原文：[E028.md @ 9a95b285](https://github.com/almide/almide/blob/9a95b28519b90ae535dc9918bfed04805dc4675c/docs/diagnostics/E028.md)。这是供读者参考的非规范性翻译。CLI 内嵌的诊断说明仍使用英文原文。

`main` 是程序入口，不接受参数。带参数形式（`fn main(args: List[String])`）在结构上能通过类型检查，但没有任何代码生成路径会接入该参数：原生驱动以零参数调用入口，wasm 的 `_start` 胶水代码也一样。过去，两者都会在后续阶段对一种语言从未支持的签名报出归责于编译器的错误（“codegen produced invalid Rust — this is an Almide bug”）。检查器现在会提前拒绝。

```almide
effect fn main(args: List[String]) -> Result[Unit, String] = ok(())   // ← E028
```

## 修复

在函数体内用 `env.args()` 读取程序参数（`env` 是 Tier 2 标准库模块——请添加导入）：

```almide
import env

effect fn main() -> Result[Unit, String] = {
  let args = env.args()
  println(int.to_string(list.len(args)))
  ok(())
}
```

## Fix-it 判定

**not-fixable** — 此错误报告的是自动重写无法决定的语义／设计问题。（`mechanical` = 无人值守的修复器可以应用重写；`conditional` = 建议的修复需要审查；`not-fixable` = 不存在自动重写。遵循 #1486 的适用性原则。）
