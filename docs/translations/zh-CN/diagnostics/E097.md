# E097 — `type`、`protocol` 或 `test` 前的 `pub`

[English](../../../diagnostics/E097.md) | [日本語](../../ja/diagnostics/E097.md) | [简体中文](./E097.md)

> 原文：[E097.md @ 9a95b285](https://github.com/almide/almide/blob/9a95b28519b90ae535dc9918bfed04805dc4675c/docs/diagnostics/E097.md)。这是供读者参考的非规范性翻译。CLI 内嵌的诊断说明仍使用英文原文。

Almide 顶层声明默认公开，除非另有说明：`mod` 将范围缩小到项目，`local` 缩小到文件。`pub` 只在 `fn` 或顶层 `let` / `var` 前被接受，用来显式表达默认状态。`type` 和 `protocol` 不需要它就已公开，而 `test` 块根本没有可见性，所以这些位置的 `pub` 触发 E097。

```almide
pub type Point = { x: Int, y: Int }   // ← E097: `pub` does not apply to `type`
```

这是 Rust 或 TypeScript 作者导出类型时最先想到的声明。在 E097 之前，解析器会在 `type` 关键字处报“Expected Fn (got Type 'type')”，只指出词法单元，没有说明该如何修改。

## 修复

删除 `pub`。导入方仍可照常看到该类型：

```almide
type Point = { x: Int, y: Int }
```

若要将类型可见性缩小到默认范围以下，使用适用于它的修饰符：

```almide
mod type Pair = { a: Int, b: Int }    // this project only
local type Tag = { name: String }     // this file only
```

同一规则适用于 `pub protocol Shape { … }`（删除 `pub`）以及 `pub test "…" { … }`（删除 `pub`）。

## 诊断形式

```
error[E097]: `pub` does not apply to `type` — remove `pub`
  in pub type
  here: pub type Point = { x: Int, y: Int }
  hint: A `type` is public by default — importers see it without a modifier. Remove `pub`; to narrow it, write `mod type` (this project) or `local type` (this file).
  try: delete the highlighted text (machine-applicable — `almide fix` applies it)
```

fix-it 锚定到 `pub` 关键字及其后的空白，位置取自词法分析器的 token，因此 `almide fix <file>` 恰好删除该部分。随后解析器如同没有 `pub` 一样读取声明，所以文件其余部分仍被检查，该关键字只产生 E097 一个错误。

## Fix-it 判定

**mechanical** — `pub type T = …` 和 `type T = …` 声明相同的公开类型，`pub protocol` / `pub test` 去掉关键字后含义也相同。（`mechanical` = 无人值守修复器可应用重写；`conditional` = 修复建议需要审查；`not-fixable` = 不存在自动重写。遵循 #1486 的适用性原则。）
