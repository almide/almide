# E005 — 参数类型不匹配（构造器／函数调用）

[English](../../../diagnostics/E005.md) | [日本語](../../ja/diagnostics/E005.md) | [简体中文](../../zh-CN/diagnostics/E005.md)

> 原文：[`docs/diagnostics/E005.md`](https://github.com/almide/almide/blob/9a95b28519b90ae535dc9918bfed04805dc4675c/docs/diagnostics/E005.md)，固定提交 `9a95b285`。这是面向读者的非规范性译文；CLI 诊断输出仍为英语。

变体构造器、记录构建器或函数调用收到的参数类型与声明的形参不一致。

## 常见情况

```almide
type Point = Pt(Int, Int)
let p = Pt("x", "y")                  // expected Int, got String

type Box = { value: Int }
let b = Box { value: "abc" }          // record field type mismatch

fn gt2(n: Int) -> Bool = n > 2
let r = gt2("5")                      // expected Int, got String
```

## 修复——标准库中名称具有相同词干的同类函数（#2097）

如果实参是直接的标准库调用，并且该模块中存在名称词干相同、返回类型与预期完全一致的同类函数，提示会指出它，`try:` 行则给出仅重命名被调用方的相同调用。

```almide
fn at(i: Int?) -> Int = i ?? -1
fn main() -> Unit = {
  let hit = list.find(["a", "b"], (s) => s == "b") // Option[String]
  println(int.to_string(at(hit)))                  // ← E005: expects Option[Int]
}
```

```
hint: `list.find` returns Option[String] — `list.find_index`
      returns Option[Int], which is what this argument expects
try:
    // Try:
    list.find_index(["a", "b"], (s) => s == "b")
```

这是查找，不是猜测：相同词干（`find` / `find_index`）、相同参数数量、精确匹配的返回类型。没有这样的函数时，使用下方提示。

## 修复——转换辅助函数

如果预期类型仅需基本类型转换即可得到，插入标准库转换：

| 实际类型 | 预期类型 | 转换 |
|---|---|---|
| `Int` | `String` | `int.to_string(n)` |
| `String` | `Int` | `int.parse(s)!`（兼容的失败通道）或 `int.parse(s) ?? 0` |
| `Int` | `Float` | `float.from(n)` |
| `Float` | `Int` | `int.from_saturating(x)`（截断），或 `int.from(x)`（超出 Int 范围时中止）；若要舍入，先用 `float.round(x)` |
| `List[A]` | `Option[A]`（单个元素） | `list.first(xs)` |
| `Option[A]` | `A` | `x ?? default` 或 `x!`（兼容的失败通道） |
| `Result[A, E]` | `Option[A]` | `r?`（转换值，不传播） |
| `Result[A, E]` | `A` | `r!`（兼容的失败通道；传播 Err） |

当不匹配属于已知基本类型对时，诊断的 `hint:` 行通常会指出具体转换。

## 修复——结构

- 无载荷变体应写成 `MyVariant`（无括号）。`MyVariant()` 是零参数函数调用，不会匹配零参数变体。
- 记录必须包含所有必需字段。使用 `Record { ...old, changed_field: new_value }` 展开语法，可以复制现有记录并覆盖字段。
- 对泛型函数，`E005` 有时掩盖了 checker 的局限（推断未传播类型变量）。添加显式类型参数：`fn_call[TypeArg](args)`。
