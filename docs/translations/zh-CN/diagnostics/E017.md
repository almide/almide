# E017 — 在 enum 类型名上构造记录

[English](../../../diagnostics/E017.md) | [日本語](../../ja/diagnostics/E017.md) | [简体中文](../../zh-CN/diagnostics/E017.md)

> 原文：[`docs/diagnostics/E017.md`](https://github.com/almide/almide/blob/9a95b28519b90ae535dc9918bfed04805dc4675c/docs/diagnostics/E017.md)，固定提交 `9a95b285`。这是面向读者的非规范性译文；CLI 诊断输出仍为英语。

记录字面量 `{ field: value, ... }` 前缀使用了 **enum 类型**的名称（`type T = A | B { ... }` 声明），而非记录类型名或某个带记录的具体分支名。enum 类型本身没有字段，只有它的各个分支有，因此这种构造没有意义。

这在**两个**目标上都是硬错误。过去两者存在分歧：Rust 泄漏了 `rustc` 的 `error[E0574]: expected struct, variant or union
type, found enum`（包装为“Almide bug”），而 WASM 能编译，却静默构造错误的值（将具名字段读成垃圾值）。在类型检查时拒绝它，使两个目标保持一致，并产生可操作的消息。

## 常见情况

```almide
type V = Tag(Float) | Named { who: String }

let v = V { who: "x" }
// error[E017]: cannot construct enum type 'V' with record syntax
```

## 修复

构造带记录的具体分支，而不是 enum 类型：

```almide
let v = Named { who: "x" }   // the case, not the enum
```

如果 enum 没有带记录的分支，选择原本想用的分支，直接提供载荷（`Tag(1.0)`）。

## Fix-it 判定

**not-fixable** — 错误报告的是自动改写无法判断的语义／设计问题。（`mechanical` = 无人值守的修复器可以应用改写；`conditional` = 建议的修复需要审查；`not-fixable` = 不存在自动改写。#1486 的适用性原则。）
