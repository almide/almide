# E084 — literal exit code outside the portable range

`process.exit` accepts exit codes from `0` through `125`. When a direct call
passes an integer literal outside that range, the checker points to the
argument and rejects the program.

```almide
import process
effect fn main() -> Unit = process.exit(200) // E084
```

Choose `0` for success or a code from `1` through `125` for failure:

```almide
import process
effect fn main() -> Unit = process.exit(1)
```

This check includes module aliases, selective imports, pipe calls, radix
literals, parentheses, and unary minus. A computed argument is checked at
runtime; a value outside the range aborts with
`Error: exit code must be in 0..=125`. The checker does not evaluate arbitrary
expressions or follow aliases stored in function-valued variables.

Dialect 4 introduces this diagnostic. A file written for an earlier dialect
can therefore need an exit-code change when checked by this compiler.

## Fix-it verdict

**conditional** — the appropriate failure code depends on the program's
protocol, so the compiler does not select a replacement automatically.
