# E055 — `?.` on a Result

The optional-chain operator is Option-only by definition (ADR-0005:
`o?.f ≡ option.map(o, (v) => v.f)`), and a Result is not an Option:

```almide
fn g(r: Result[Int, String]) -> Int? = r?.abs   // ← E055
```

## What to write instead

Convert or unwrap first — the error carries the ladder:

```almide
(r?)?.abs          // `r?` converts Result → Option (err → none), then chain
(r ?? 0).abs       // unwrap with a fallback, then access directly
match r { ok(v) => some(v.abs), err(_) => none }
```

Before this code existed the misuse was a bare, codeless `error:` line —
invisible to `almide explain`, the fixture harness, and the coverage gates
(#1107 D2).
