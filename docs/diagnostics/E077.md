# E077 — no Float arithmetic in the bounded profile (provisional)

The `@bounded` attribute (ALS §B, the bounded profile) narrows what the
checker admits inside the attributed function: statically bounded time and
storage, a closed acyclic call graph, capability-bounded effects. E077
rejects a Float operator (arithmetic or comparison) or a stdlib call computing on Float arguments in a `@bounded` function.

```
error[E077]: ... is not admissible in a @bounded function
```

```almide check-fail=E077
@bounded
fn scale(x: Float) -> Float = x * 2.0

fn main() -> Unit = println("bounded")
```

## The fix

Keep to Int arithmetic inside the profile; Float values may be held and passed, not computed on. The rule is provisional (ALS-B10) until the certification seat carries a Float instruction set.

```almide
@bounded
fn scale_deci(x: Int) -> Int = x * 2

fn main() -> Unit = println("bounded")
```

The rule binds only inside `@bounded` functions — removing the attribute
removes the rejection (the profile is a subset, not a dialect: ALS-B2).

## Fix-it verdict

**not-fixable** — the diagnostic's hint names the admissible form; which
spelling replaces the rejected one depends on what the code was doing.
