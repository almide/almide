# E121 — a spread of a type parameter without a record shape

A spread (`{ ...x }`, `{ ...x, f: v }`) copies a record's fields. In a generic
fn whose type parameter has no record-shape bound, the fields of `x` are not
known where the body is checked, and the body is checked once, before any
instantiation. An instance could be a record whose fields are closed outside
its module, such as `Secret`, and the spread would copy it there, where a
direct spread is E033 (#4285).

```almide
import secret

fn copy[A](x: A) -> A = { ...x }   // ← E121

fn main() -> Unit = {
  let s = copy(secret.new("pw"))
  println("${s}")
}
```

```
error[E121]: cannot spread a value of type parameter 'A': its fields are not known here
  hint: a spread copies a record's fields, and an instance of 'A' may be a type whose fields are closed outside its module (an opaque type such as `Secret`): bound it with a record shape, `[A: { .. }]`, or take the record type itself
```

A protocol bound (`[A: Eq]`) gives no fields either, so it is refused the same
way.

## Fix

Bound the type parameter with a record shape. The bound is checked against
each instance at the call, and a record whose fields are closed here is E033
at that call:

```almide
type Point = { x: Int, y: Int }

fn copy[A: { .. }](x: A) -> A = { ...x }

fn main() -> Unit = {
  let p = copy(Point { x: 1, y: 2 })
  println("${p.x} ${p.y}")
}
```

Name the fields the body updates in the bound (`[A: { name: String, .. }]`),
or take the record type itself instead of a type parameter.

## Fix-it verdict

**not-fixable**: whether the fn is meant for records of one shape or for one
record type is a decision about the program.
