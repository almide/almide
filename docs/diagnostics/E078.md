# E078 — no early exit inside a counted loop

The `@bounded` attribute (ALS §B, the bounded profile) narrows what the
checker admits inside the attributed function: statically bounded time and
storage, a closed acyclic call graph, capability-bounded effects. E078
rejects `!` propagation or a `guard` inside a counted loop body in a `@bounded` function.

```
error[E078]: ... is not admissible in a @bounded function
```

```almide check-fail=E078
@bounded
effect fn sum_first(xs: List[Int]) -> Int! = {
  var acc = 0
  for i in 0..<3 { acc = acc + list.get(xs, i)! }
  ok(acc)
}

fn main() -> Unit = println("bounded")
```

## The fix

Propagate or guard outside the loop; inside it, default with `??` — an exit mid-loop skips per-iteration cleanup and weakens the strict trip count.

```almide
@bounded
fn sum_first(xs: List[Int]) -> Int = {
  var acc = 0
  for i in 0..<3 { acc = acc + (list.get(xs, i) ?? 0) }
  acc
}

fn main() -> Unit = println("bounded")
```

The rule binds only inside `@bounded` functions — removing the attribute
removes the rejection (the profile is a subset, not a dialect: ALS-B2).

## Fix-it verdict

**conditional** — the diagnostic's hint names the admissible form; which
spelling replaces the rejected one depends on what the code was doing.
