# E033 — opaque type constructed outside its defining module

A constructor call for an opaque type was made from a different module
than the one that defines the type. Opaque types can only be
constructed through the defining module's public API.

Historical note: emitted as E008 until 2026-08 (one code carried two
unrelated meanings); E008 is now exclusively the fan mutable-capture error.

## Common cases

```almide
// module a: type Token = opaque { ... }
// module b:
import a
let t = Token("raw")        // E033: constructing a.Token outside module a
```

## Diagnostic

```
error[E033]: cannot construct opaque type 'Token' outside its defining module
  hint: Use the module's public API to create 'Token' values
```

## Fix

- Call a constructor function exported by the defining module:
  ```almide
  let t = a.token_of("raw")
  ```

## Why

Opaqueness is an invariant boundary: the defining module guarantees
every value it hands out satisfies the type's invariants. A foreign
constructor call would bypass that guarantee.
