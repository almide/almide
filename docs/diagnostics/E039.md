# E039 — result.collect / collect_map are deprecated (warning)

`result.collect` and `result.collect_map` are in their removal window
(ADR-0007). Rust's `collect::<Result<_,_>>()` short-circuits at the
first `Err` (E stays E); almide's collected ALL errors into `List[E]` —
the same name for the opposite strategy. The name is retired to end
that ambiguity; `partition` is the substance for all-errors collection.

## Diagnostic

```
warning[E039]: result.collect is deprecated and will be removed —
               all-errors collection is spelled with partition
```

## Fix

```almide
let (oks, errs) = result.partition(rs)
if list.is_empty(errs) then ok(oks) else err(errs)
```

For the first-err strategy Rust users expect, short-circuit combinators
are the spelling (and after ADR-0006 lands, `list.map(f)!`).

## Why

A name that means the opposite of its strongest prior taxes every
reader. The two-line partition idiom states the strategy explicitly.
