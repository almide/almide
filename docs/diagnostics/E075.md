# E075 — no run-time-length heap construction

The `@bounded` attribute (ALS §B, the bounded profile) narrows what the
checker admits inside the attributed function: statically bounded time and
storage, a closed acyclic call graph, capability-bounded effects. E075
rejects a heap construction whose length is a run-time value (`string.repeat(s, n)`, `list.with_capacity(n)`, and family) in a `@bounded` function.

```
error[E075]: ... is not admissible in a @bounded function
```

```almide check-fail=E075
@bounded
fn pad(n: Int) -> String = string.repeat("x", n)

fn main() -> Unit = println("bounded")
```

## The fix

Give every constructed length a compile-time size — a literal, or a `let` bound to one.

```almide
@bounded
fn pad3() -> String = string.repeat("x", 3)

fn main() -> Unit = println("bounded")
```

The rule binds only inside `@bounded` functions — removing the attribute
removes the rejection (the profile is a subset, not a dialect: ALS-B2).

## Fix-it verdict

**conditional** — the diagnostic's hint names the admissible form; which
spelling replaces the rejected one depends on what the code was doing.
