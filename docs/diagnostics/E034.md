# E034 — error-channel operator on a non-Option/Result operand

`!`, `?`, or `??` was applied to a value that is neither `Option[T]`
nor `Result[T, E]`. These operators act on the error channel; a plain
value has none.

## Common cases

```almide
let n = 5!                  // E034: Int has no error channel
let o = "hi"?               // E034
let v = 3 ?? 0              // E034
```

## Diagnostic

```
error[E034]: operator '!' requires Option or Result type but got Int
  hint: Use '!' only on Option[T] or Result[T, E] values
```

## Fix

- Drop the operator — a plain value is already unwrapped:
  ```almide
  let n = 5
  ```
- If a fallible computation was intended, the operand should come from
  a `Result`/`Option`-returning call (`int.parse(s)!`).

## Why

Accepting the operator on plain values would make it a silent no-op,
hiding real mistakes (a refactor that removed the fallible call but
left the operator behind).
