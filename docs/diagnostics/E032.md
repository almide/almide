# E032 — immutable binding passed to `mut` parameter

A call passed an immutable binding — a `let`, a parameter that is not
declared `mut` — or a temporary expression where the callee declares a
`mut` parameter. Mutation requires a mutable place rooted in a `var`
binding or a `mut` parameter.

The in-place writers of every container declare their receiver `mut`:
`list.push`, `string.push`, `map.insert`, and the whole `bytes` writer
family — `bytes.push`, `append_*`, `set_*`, `write_*`, `fill`, `clear`,
`copy_from`, `copy_within` (the byte writers since dialect epoch 5, #2466).

Historical note: this family was emitted as E007 until 2026-08
(one code carried two unrelated meanings); E007 is now exclusively
the fan-outside-effect error.

## Common cases

```almide
fn grow(xs: List[Int]) -> Unit = {
  let ys = xs
  list.push(ys, 1)          // E032: `ys` is immutable
}

fn zero(b: Bytes) -> Unit =
  bytes.fill(b, 0)          // E032: parameter `b` is not `mut`

fn main() -> Unit = {
  bytes.append_u8(bytes.new(0), 7)   // E032: a temporary has no binding to write back into
}
```

## Diagnostic

```
error[E032]: cannot pass immutable binding 'ys' to `mut` parameter of list.push()
  hint: Declare 'ys' with `var` instead of `let` to allow mutation (a helper that writes its caller's value takes it as a `mut` parameter instead)

error[E032]: cannot pass immutable binding 'b' to `mut` parameter of bytes.fill()
  hint: 'b' is a parameter, and parameters are immutable: declare it `mut b: Bytes` so the write reaches the caller's value (the caller then passes a `var`), or copy it into a local `var` if the caller must not see the write
```

## Fix

- A local buffer: declare the binding with `var`:
  ```almide
  var ys = xs
  list.push(ys, 1)
  ```
- A helper that fills its caller's buffer: declare the parameter `mut`,
  and pass a `var` at the call site. The write reaches the caller on
  every target:
  ```almide
  fn zero(mut b: Bytes) -> Unit = bytes.fill(b, 0)

  fn main() -> Unit = {
    var b = bytes.from_list([1, 2])
    zero(b)
  }
  ```
- A helper that must NOT change its caller's value: copy the parameter
  into a local `var` and write the copy.
- For a field/element, the *root* binding must be `var` or a `mut`
  parameter (`var box` allows `list.push(box.items, x)`).
- A temporary expression can never be a `mut` argument — bind it first
  with `var`.

## Why

Almide has value semantics: `let c = a` copies, and a callee cannot reach
its caller's binding except through a parameter it declares `mut`.
`mut` parameters lower to `&mut` in generated Rust and to a write-back on
wasm. Allowing an immutable or temporary place would either fail rustc or
silently mutate a copy on one target and the original on another — both
violate the "what you read is what runs" contract. Before #2466 the byte
writers did not declare `mut`, so a helper writing a plain `Bytes`
parameter compiled, and native wrote through to the caller while wasm did
not.
