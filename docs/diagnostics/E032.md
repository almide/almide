# E032 — immutable binding passed to `mut` parameter

A call passed an immutable `let` binding (or a temporary expression)
where the callee declares a `mut` parameter. Mutation requires a
mutable place rooted in a `var` binding.

Historical note: this family was emitted as E007 until 2026-08
(one code carried two unrelated meanings); E007 is now exclusively
the fan-outside-effect error.

## Common cases

```almide
fn grow(xs: List[Int]) -> Unit = {
  let ys = xs
  list.push(ys, 1)          // E032: `ys` is immutable
}
```

## Diagnostic

```
error[E032]: cannot pass immutable binding 'ys' to `mut` parameter of list.push()
  hint: Declare 'ys' with `var` instead of `let` to allow mutation
```

## Fix

- Declare the binding with `var`:
  ```almide
  var ys = xs
  list.push(ys, 1)
  ```
- For a field/element, the *root* binding must be `var`
  (`var box` allows `list.push(box.items, x)`).
- A temporary expression can never be a `mut` argument — bind it first.

## Why

`mut` parameters lower to `&mut` in generated Rust. Allowing an
immutable or temporary place would either fail rustc or silently
mutate a copy — both violate the "what you read is what runs" contract.
