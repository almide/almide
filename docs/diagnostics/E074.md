# E074 — `@bounded` calls `@bounded` (or first-order pure stdlib)

The `@bounded` attribute (ALS §B, the bounded profile) narrows what the
checker admits inside the attributed function: statically bounded time and
storage, a closed acyclic call graph, capability-bounded effects. E074
rejects calling a non-`@bounded` user function, creating or calling a closure, or a higher-order stdlib call from a `@bounded` function.

```
error[E074]: ... is not admissible in a @bounded function
```

```almide check-fail=E074
fn helper(x: Int) -> Int = x + 1

@bounded
fn uses_plain(x: Int) -> Int = helper(x)

fn main() -> Unit = println("bounded")
```

## The fix

Mark the callee `@bounded`, or use a first-order member of a pure stdlib module. Function values are indirect callees the profile's static call graph cannot follow.

```almide
@bounded
fn helper(x: Int) -> Int = x + 1

@bounded
fn uses_bounded(x: Int) -> Int = helper(x)

fn main() -> Unit = println("bounded")
```

The rule binds only inside `@bounded` functions — removing the attribute
removes the rejection (the profile is a subset, not a dialect: ALS-B2).

## Fix-it verdict

**conditional** — the diagnostic's hint names the admissible form; which
spelling replaces the rejected one depends on what the code was doing.
