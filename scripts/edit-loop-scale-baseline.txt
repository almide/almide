# Both anchors are DIMENSIONLESS same-run ratios, not milliseconds. The
# milliseconds on this ladder are not anchorable: same commit, same corpus, same
# M4 Pro, one hour apart on 2026-08-13, the 10,151-line rung read p95 52.9ms at
# load average 6.0 and p95 332.4ms at load average 42.4. The observations are
# recorded at the bottom of this file for the record; the two lines the gate
# reads are `slope` and `ratio`.
#
# slope — log-log least-squares slope of MARGINAL `almide check` time against
#   project lines across the ladder (2k / 5k / 10k / 20k / 30k lines of real
#   stdlib source), from the MIN of 40 interleaved runs per rung. 1.0 = linear,
#   2.0 = quadratic. Anchored 2026-08-13 at the MEDIAN of eight 40-run
#   measurements taken across a 12x load swing on one M4 Pro (load average 3.4
#   to 42.4):
#     1.113  1.126  1.130  1.132  1.137  1.142  1.154  1.159   median 1.132
#   a 4.1% total spread, while p95 on the same ladder moved 6x over the same
#   swing. The highest reading sits 12% under the +15% ceiling. Budget +15%.
slope 1.132
# ratio — min(10,151-line rung) / min(4-line floor rung): what a 10k-line project
#   costs in units of what an empty one costs. Catches a uniform slowdown of the
#   per-line work, which `slope` by construction cannot see. Median of the same
#   eight runs:
#     4.298 4.351 4.362 4.403 4.424 4.435 4.454 4.690 (the 4.690 is load 42.4)
#   an 8.9% total spread. Budget +25%.
ratio 4.403
