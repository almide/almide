# proofs/check-shipped-loops.sh fails a run that accepts fewer than the
# floor: a change that takes a loop out of the shape (the count captured some
# other way, the test or the read rewritten) is lost evidence, and shows here
# instead of passing unseen. It fails a run with more than the first ceiling:
# a count captured before a loop that neither holds the block, nor leaves
# memory alone, nor keeps the block's local to itself is the shape of a stale
# count. It fails a run with more than the second: a read through the looped
# block by the tested counter that the kernel cannot place inside the block.
# The refusals the corpus holds are loops that count bytes and read 4- or
# 8-byte elements, in bounds because length and counter are multiples of the
# element size, which the rule does not know; a read one slot too far is
# refused the same way, and one more refusal than the ceiling fails.
#
# Raise a floor or lower a ceiling whenever a run allows it. Lower a floor or
# raise a ceiling only in its own commit, with the reason in the message.
