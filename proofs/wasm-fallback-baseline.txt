# ── WASM COVERAGE RATCHET (mission-critical arc: wasm is a FIRST-CLASS target) ──
#
# Every spec file the wasm leg of `almide test` does not pass, with its wall
# reason and class. Gate: proofs/check-wasm-fallback.sh — a file falling back
# that is NOT here fails (a coverage regression); an entry whose file now runs
# the wasm leg fails as STALE (prune it — the set only shrinks). Data feed:
# `ALMIDE_FALLBACK_NAMES=1 almide test`.
#
# Classes:
#   COMPILER_FRONTIER — the burn-down DEBT: the wasm pipeline cannot yet
#                       compile the shape; each entry names its brick.
#   HOST_CAPABILITY   — a host/API limitation recorded for this test-file
#                       invocation. This is not a universal availability table:
#                       an API may be served on another embedded/component route.
#                       See proofs/target-availability.toml for per-route scope.
#   HARNESS_LIMITATION— the TESTING harness needs a mechanism wasm lacks.
#                       None since ADR-0029: testing.assert_aborts runs its
#                       closure in a fresh instance, so no catch is needed and
#                       the two assert_throws files run the wasm leg.
#
# The current test lane uses structural_test_render in src/cli/test_wasm.rs.
# Historical compiler-frontier note: the incumbent test lane lacked list-rest /
# as-pattern binds (#1461), while the structural leg served them (C-332/C-333).
# Those two rows are no longer present. The current fallback set is exactly the
# non-comment rows below; historical counts are not current coverage totals.
